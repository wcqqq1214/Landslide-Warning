## 1. 问题与范围

v1.19 的 IN/OOF 均未稳定超过 B+。612 日 OOF 初始 paired/anchor 损失比约 127，
一个种子的拟合块损失增加约 13.7%；损失比不能证明梯度失衡或目标冲突。本版检查
两块在固定参数位置的梯度大小、方向及共同下降方向的局部影响，区分这条线索与
跨教师/跨时间预测困难。负结果和四点精度、概率指标保持，不按诊断选新模型。

固定三个 h=342/432/612、IN/OOF、seed=0/1/2，以及全部 e0/25/50/75/100，
共 90 checkpoint；不只检查失败种子。复用 v1.19 的原始两类样本、日期权重、
教师、当前 h scaler 和 100 mm 损失归一化。只解析各 h 日训练观测，最大 612 日；
物理特征复用保存轨迹，已知驱动可读至 h+180，不解析其未来位移。

## 2. 固定计算与解释

LA、LP 为两个块各自归一化的加权平方损失，原总目标 LT=(LA+LP)/2。
计算完整参数梯度 gA、gP，以及 gT=(gA+gP)/2；保存全部梯度向量与参数名称/位置。
分别在全部参数、gates 和 output 三组报告损失、范数、gP/gA 范数比、点积、cosine、
共同梯度范数，以及沿组内单位共同负梯度 d=−gT/||gT|| 的 gA·d、gP·d。
组内方向不等于整体方向；正方向导数只表示该局部方向使对应块上升。

范数 <=1e-12 时不计算相应比值/cosine/单位方向，存缺失及明确零梯度标记。
零输出头使 e0 gates 梯度为零，不能把未定义 cosine 当成无冲突或同向。
cosine <−1e-6 标记局部反向；范数比 >=10 或 <=0.1 标记数量级失衡；单位方向
导数 >1e-10 标记对应块局部上升。这些只是预定描述标记，不是显著性、最佳权重
或训练是否有效的门限。全部原值保留，不能只汇报达到标记的样本。

原 Adam 有动量和逐参数缩放，本版没有其逐轮状态，不把 −gT 当成已发生的 Adam
更新。原总梯度裁剪是共同缩放，不改变非零原梯度方向；本版不模拟优化器或据局部
反向推断它造成了原预测失败。梯度大小依赖既有参数坐标与损失尺度。

## 3. 数值核验与预算

- 主计算按块 batch=128、autograd.grad 累加；独立核验使用标量日期重建原样本、
  batch=53、backward 累加。输入指纹必须与 v1.19 完全相同，权重/基准/标签逐值
  对齐；梯度 atol=1e-9、rtol=1e-9，损失 atol=1e-10、rtol=1e-10。
- e0/25/50/75 的总损失及范数与下一轮更新前原日志对应，共 72 组；e100 两块
  损失与原 model_summary 对应。日志范数沿用 atol=1e-8、rtol=1e-9。
- 18 个 e100 使用整体 d，在参数副本上作 epsilon=1e-4、1e-5 的正负中心差分，
  每次重算两块，72 个块/步长导数；atol=1e-8、rtol=1e-3。主参数始终逐值不变，
  副本扰动只用于导数检验，不训练/保存新模型/形成新预测。独立核验以 batch=53
  重算同一扰动；若整体梯度为零，明确记录跳过而不伪造通过。
- 主梯度 480 次网络前向和反向；主差分 384 次前向；首次独立核验 960 次梯度
  前向/反向及 768 次差分前向。正常总计 2,592 次前向、1,440 次反向，0 更新。
  封存后只读复核允许再 1,728 前向/960 反向；无差分跳过时按精确计数核验。
- 0 B+ 前向/拟合、0 scaler/概率尺度拟合、0 新训练，单进程 CPU 一线程，科学
  进程 600 秒硬上限，单次执行，不自动重试或调门限。失败保存原日志/源码/产物。
- 合成测试在实测求值前验证解析线性梯度、两个块归一化、批次一致性、冲突/零向量
  处理、方向导数、参数不变、预算拒绝及未来标签边界；不进行实测预运行。

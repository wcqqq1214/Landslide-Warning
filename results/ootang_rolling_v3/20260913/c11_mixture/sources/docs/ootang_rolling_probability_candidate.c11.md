## 要检验的方向变化

已有均值学习优于 B+，但 FULL 不如 DATA，且概率覆盖不足。C9 修正拟合尺度仍未解决预测覆盖，C10 更快减弱旧监督反而退步。直接给现有 Ridge 添加同方差几何不确定性因子也缺少优先依据：后期 ATU1/ATU5 最大杠杆量很小，见[不读取新标签的筛查](../results/ootang_rolling_v3/20260913/c11_geometry_screen.json)；这不排除一般贝叶斯方法。

本次把 B+ 的作用放在**概率参照**：当物理预测与学习均值不一致时，为较大偏差提供一个较宽的候选分布；其权重必须由过去真正发出的预测及已兑现标签学习。不能人为增加固定尾部概率、按覆盖率选择倍率或删困难日期，也不声称这种分量代表已验证的失稳机制。

## 均值和归因边界

核心分布固定采用已有 `C8_ONLINE_DATA` 的均值和高斯尺度，它只使用位移变化特征，属于机器学习。此次**全四点、全日期统一使用这一固定核心**，不是拼点或重新选择 C8 参数；它原有的均值收益不能记作 C11 新学到的收益。将其作为新方案核心的理由是此前多次 FULL/DATA 对照未证实 B+ 对均值的额外价值，因此本次直接隔离 B+ 在概率部分的作用。

原 C4 主候选、C8 FULL/DATA 及其负结果不改名或改判。C11 必须与同均值的 C8 DATA 及下述同均值、同复杂度的趋势参照对照比较；不能只与 C8 FULL 比较，再把更换均值带来的差异归功概率混合。

## 两个固定分布与学习公式

在每个起点、步长和测点，核心为 `N(mu,s_core^2)`，其中 `mu` 和 `s_core` 是已经因果生成的 C8 DATA 输出。给定一个原参照分布 `N(mu_ref,s_ref^2)`，构造同中心宽分量：

```text
s_wide = max(s_core, sqrt(s_ref^2 + (mu_ref-mu)^2))
F(y) = (1-w) * Phi((y-mu)/s_core) + w * Phi((y-mu)/s_wide)
```

它保留原学习均值，只使用参照分布相对该均值的二阶距离，不等同于直接抽样原 B+，不称力学约束成立。主候选 **C11_PHYS** 的参照固定为 `B_ANCHOR` 的原概率扩展；配对对照 **C11_TREND** 的参照为原 `DRIFT14` 概率扩展，两者均来自相同 C8 保存起点、使用相同信息条件。趋势对照不包含 B+ 输出，因此用于直接检查物理参照在新概率层是否有增益。原 B_RAW 的概率指标继续不适用。

每点每步长使用最近 **90 个**已成熟目标，初始权重固定为 0，不补造阶段外尚未保存的历史预测。概率参数使用当时实际发出的核心/宽分量尺度，不能用当前尺度回算过去样本。原 C8 RMS/反馈是冻结核心的生成规则，本次不把新的混合区间反向写入 C8 反馈状态。

令 `A(d,s)=2*s*phi(d/s)+d*(2*Phi(d/s)-1)`，`C=s_core/sqrt(pi)`、`D=s_wide/sqrt(pi)`、`E=sqrt(2/pi)*sqrt(s_core^2+s_wide^2)`。混合 CRPS 为 `A(y-mu,s_core)-C + L*w + Q*w^2`，其中：

```text
L = A(y-mu,s_wide)-A(y-mu,s_core) + 2*C-E
Q = E-C-D
  = (s_wide-s_core)^2 / (sqrt(pi)*(sqrt(2*(s_core^2+s_wide^2))+s_core+s_wide))
w = clip(-sum(L)/(2*sum(Q)), 0, 1)
```

稳定的非负 Q 公式避免等尺度时相消；没有样本或 `sum(Q)==0` 时权重为 0。使用这个封闭解，不搜索窗口、惩罚或权重先验；权重在目标成熟后更新，不能使用当前未兑现误差。模型记忆/均值参数不再更新，新的在线学习仅限分布混合权重。

混合分布和 CRPS 闭式计算参考 [scoringrules 官方公式](https://scoringrules.readthedocs.io/en/latest/generated/scoringrules.crps_mixnorm.html)；上述同中心二次式与权重解由该公式直接展开。预测分布组合的校准/离散程度并非自动改善，参见 Gneiting、Ranjan [原始研究摘要](https://arxiv.org/abs/1106.1638)。本次只核读其摘要及官方评分公式，未全文审阅该论文，不借用其场景效果或覆盖保证。

## 评价、保存与退出

均值误差沿用完整 h30 347/264 个目标；h1—30 全部报告，原四点、数据 SHA、驱动条件、27 项标准及 DRIFT1 身份保持。两阶段按同一冻结算法执行；后期是已暴露探索，不能称新的独立迁移。另直接比较同均值核心与趋势参照：若物理分量没有超过趋势参照，就不宣称新增物理价值。

80/90/95% 区间由真实混合 CDF 求分位数，正半轴以 `max(s_core,s_wide)*normal_quantile` 为上界，固定 60 次二分，再利用对称性得到上下界。CRPS 按混合公式，不能用矩匹配高斯代替；保存的 sigma 若作为矩标准差，须与实际 CDF/分位数分开解释。完整核心/宽尺度、权重、真实区间、逐日锁与成熟监督、最终 90 项系数池均保存，旧分布原样保留。

两候选、两阶段合计 **153,600 次**点位混合权重成熟更新，单独计数；零新均值拟合、Ridge 系数更新、尺度优化、神经或物理调用。初始 w=0，首次分布等于 C8 DATA。核心旧预测原件保留。

检查独立 CDF 积分 CRPS、分位数和对称均值、封闭权重与独立数值最优解、成熟目标/未来扰动边界；实际核验须重建所有权重与全部评分，比较旧均值和对照精确不变。仅当完整数值标准与核验通过，才做原配对成块/非重叠统计和完整图件并判断是否提前收尾。失败就停止这个组合，不改宽度倍率、加入尾部概率下限或把 TREND 换成主模型。每步 docs 和 commit，未要求 push。

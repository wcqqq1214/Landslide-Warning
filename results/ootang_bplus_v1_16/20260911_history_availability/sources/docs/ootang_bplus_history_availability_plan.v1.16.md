## 2. 当前起点与历史接口

起点固定为 c=252/342/432/612；第一个预测日索引为 c，历史最后一日为 c−1。
每组构建 `[c−30,c)` 的四点位移及日增量；日增量还需读取 c−31 日，因此输入
来源仅为前 c 行，绝不读取第 c 行或未来标签。日增量单位 mm/日，称物化序列差分。

接口显式命名为 `materialized_history`，返回日期、位移、增量与来源角色。缺日、
乱序、重复、非有限或不足前缀报错，不插值、平滑、填补、拟合 scaler 或平移预测。
原始观测当时可用性保留为 `unknown`，不能转换为 true；历史日期检查只能证明
下游接口没有额外取用未来行。所有未来输出和旧模型保持。

将四个起点对应的自然月、起点前同月行数、月内剩余日数与既有逐月指纹相连接，
保存四点完整记录。该连接只描述物化序列的跨边界结构，不新拟合月内多项式，
不把它计作模型预测成绩。

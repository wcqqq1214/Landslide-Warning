## 2. 固定分解与范围定义

沿用源 scaler 得到 z 和源回归系数 beta。逐日修正为
`C = 100*beta[0] + sum_j 100*z[j]*beta[j+1]`，输出轴仍为 ATU1/ATU5/MJ3/MJ1。
分组固定为截距、当前水文 [0,12)、30 日历史 [12,24)，以及 s/p/rb/rc/rE/background
六组，每组四域，依次覆盖 [24,48)。H 只有截距/水文，HH 再有历史，HHS 包括全部。
不将物理域当作测点，不跨模型混用系数，也不以组均值除总均值报告贡献百分比。

范围同时报告两种参照：原 scaler 的 [0,c)，以及回归实际拟合行 [30,c)。各维
保存参照最小/最大 z、forward 最小/最大/均值 z、低于/高于范围的天数、比例和
最大超出距离。不拟合新 scaler；单维在范围内不意味着联合分布或条件关系不变。
各组另报告至少一维越界的天数，另列 H/HH/HHS 全部输入的联合“任一维”计数。

仅针对实际拟合行范围 [lo,hi]，把每一项代数拆为两部分：
`z = clip(z,lo,hi) + (z-clip(z,lo,hi))`。
乘以原系数后分别称边界内项和超范围项；截距全计入边界内项。所有原输入和
原预测保持，不保存、评价或采用剪裁后的新预测，不将该分解解释为干预/因果效应。
训练评分行 [30,c) 的超范围项必须为零；forward 两部分之和必须等于原修正。

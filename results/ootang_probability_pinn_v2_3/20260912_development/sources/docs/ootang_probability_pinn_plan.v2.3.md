## 3. 单一模型合同（拟议，尚非运行配置）

### 3.1 水文蠕变关系

记原雨致水头为 `h_tj`，含水率为 `m_tj`，原滞后库水位为 `H_t`，给定库水位为 `R_t`。
共享网络 G 的输入为 `[m_tj, h_tj/S_hj, (H_t-R_t)/S_HR, ΔR_t/S_dR]`，结构 `4→8→1`，
隐藏层 tanh，输出再取 tanh，得到 `r_tj∈[-1,1]`。尺度只用拟合前缀驱动的 RMS，
数值下限 1e−6（对应输入原单位）；首日 `ΔR=0`。

对每域令 `c_j = mean_fit(r_tj)`、`a_tj=(r_tj-c_j)/2`；这里拟合驱动前缀包含索引 `0:h`，
不同于排除首 30 日的标签评分掩码。训练中对中心项保留梯度，
预测时冻结训练得到的中心，不在预测窗重新居中。定义

```text
v_B,tj = theta[24+j] + theta[47+j] * m_tj
v_*,tj = v_B,tj * exp(log(2) * a_tj)
b_*,tj = sum_{k=1..t} v_*,kj
         + theta[28+j] * (1-exp(-t/exp(theta[32+j])))
```

修正倍数在 `[0.5,2]`，拟合段的倍数几何平均为 1；这不保证算术平均速率不变。
常数网络输出被中心项消去，避免把候选直接变成四个常数倍率；零末层使蠕变关系退化到 B+。
**倍数 2 是本次拟议的正则化范围，不是已证实的材料参数界限。**
保留原指数瞬态项，包括其原符号；正倍率仅保留原蠕变速率的符号，不承诺总背景增量永远为正。
本候选明确修改背景演化关系，不得写成“物理模型完全不变”或隐藏在观测残差中。

### 3.2 神经塑性增量与完整记忆

共享网络 H 的输入为 `[t/T, G的4项输入, 域one-hot的4项]`，结构 `9→16→16→1`，隐藏层 tanh。
`T` 为该阶段最后一天的索引，日内按子步给时间坐标；水文驱动按原 C 的当天数值保持。
输出 `Δp_nj = dt * S_pj * softplus(H_nj)`，`dt=1/64`，
`S_pj` 为冻结 B+ 在拟合前缀的平均塑性速率，数值下限 1e−6 mm/day。
H 末层权重置零、偏置 `softplus^{-1}(1)`；这只是初值，**不等于 B+ 原轨迹**。
softplus 可接近停滑但不产生数学上的精确零，相关逼近误差必须接受下面的独立检查。

从零初始状态累计 `p_n=p_(n-1)+Δp_n`。日背景 `b_*` 按原 C 线性插值到子步，
雨致弹性项 `e_n`、刚度、其他力与时间常数不改。逐子步严格计算：

```text
β = dt / (tau_motion + dt)
ar = 1 / (1 + dt/tau_rest)
ac = 1 / (1 + dt/tau_contact)
aE = 1 / (1 + dt/tau_bulk)
s_n  = (1-β)*s_(n-1) + β*(p_n + e_n)
u_n  = s_n + b_*,n
Δu_n = u_n - u_(n-1)
rb_n = ar*(rb_(n-1) + hardening*Δp_n)
rc_n = ac*(rc_(n-1) + Kc*Δu_n)
rE_n = aE*(rE_(n-1) + KE*Δu_n)
mu_n = y0 + observation_matrix*u_n
```

域内运算按元素，刚度和观测映射按矩阵运算；只导出日末测点均值。
原依据为 ZIP `physical_solver.c:21–24,37–42,55–60`，与
[`equations.py`](../code/physics_guided_pinn/equations.py)的运动和三类记忆残差一致。
整个历史参与可微递推，不截断梯度、不在预测起点重置，不借用 B+ 的旧反力替代神经路径反力。
实现可用稳定的可微线性递推；是否采用加速扫描属于实现选择，必须与显式递推核对，不能用截断历史换速度。

仍需用残差约束的原互补条件为

```text
dx_n = β*Δp_n >= 0
gap_n = eta_B*Δp_n/dt + rb_n + rc_n + rE_n - force_B,n >= 0
dx_n*gap_n = 0
```

均值损失、物理残差和最终报告必须使用上述同一条神经路径。
这里只把运动、背景定义和反力记忆关系通过构造满足；不能由此声称互补条件也自动成立。

### 3.3 概率输出和固定优化建议

每个种子再用一个 `3→4` 线性尺度头，输入
`xi_t=[mean_j(m_tj), (H_t-R_t)/S_HR, ΔR_t/S_dR]`，定义
`sigma_tj=0.001 mm + S_y*softplus(A_j + V_j*xi_t)`。
`S_y=max(1 mm, B+拟合有效日合并RMSE)`；初始 `V=0`，偏置使初始尺度为 `S_y`。
它描述有效预测残差尺度，不将其直接命名为测量噪声或完整物理不确定性。

三种子固定为 0/1/2，各自产生全轨迹高斯边际，最终等权混合；一个种子的权重在全历史保持相同。
每种子 G/H/尺度头分别 49/449/16 参数，合计 **514**。不是贝叶斯后验，不单独随机抽日力，
不把三个种子当独立观测样本；不声称逐日边际区间同时覆盖整条轨迹或已建模完整跨点协方差。

拟议一次固定优化：Adam，学习率 1e−3，梯度范数上限 1，最多每种子 300 次全轨迹更新，
只取第 300 次，失败或时间不足不选较早的好看轮数。先开发三种子，通过才进入最终三种子，
总上限 1800 次更新；不加种子、轮数或模型变体。
标签损失仅在拟合有效日使用，物理残差覆盖全模拟历史及给定驱动的预测区间。
建议固定目标为：

```text
L = mean(|mu-y|)/S_y + mean(Gaussian_CRPS(mu,sigma,y))/S_y
    + mean((relu(-gap)/S_F)^2)
    + mean((dx*gap/(S_D*S_F))^2) + 1e-3*mean(a^2)
```

前两项对拟合点日平均，物理项对全部子步/域平均，正则项对拟合日/域平均。
`S_Fj=max(1,拟合前缀原force的RMS)`，`S_Dj=max(1e−8 mm,拟合前缀原dx的RMS)`，
各在原量纲下固定；这些归一化和权重是待检验的工程选择，不代替原始量纲残差的验收。
不存在 KL 项、后验声明、按最终标签自适应的物理权重或事后概率校准。

## 4. 独立数值验收与效果判据

**原求解器的数值门槛与神经逼近质量分开。** 不借 PDF 的时间步长差异放宽旧容差。
未来参考重放可使用原 C 已有的背景数组接口，输入冻结学得的 `b_*`，从零状态独立求解同一修改后的方程，
得到 `mu_ref`；不得调用原 Python `forward` 后又悄悄恢复为原背景。
先确认零修正背景通过原求解器一致性检查，保留原 v1.8 位移、反力、舍入界和互补检查定义。
网络的所有原始残差分别报告，不把加权 loss 当作物理可行性证明。

参考重放只检验神经近似，**不能在效果不好时用它替换主输出**。
对每个拟声称均值改善的测点，以三种子等权均值计算 `G_j=MAE_B+,j-MAE_PINN,j`，提出可信度条件：
`(1/3)*sum_seed mean(|mu_seed-mu_ref,seed|)_j <= 0.1*G_j`。
先对每个种子的近似差取绝对值，避免种子间误差抵消；并用各自同一背景的重放组成等权参考混合。概率比较保留同一尺度，
要求 CRPS、90% 区间评分的重放评分差不超过相应正改善量的 10%。
这把数值近似对所声称增益的影响限制在事前声明的比例内，不声称其等于观测误差水平。
10% 是新候选的拟议可信度条件，不是导师给出的物理阈值；未过则停止，不能据此否定整个 PINN 家族。
这项验收限定四点位移近似，不证明每个不可观测状态准确；神经路径若超出原力学容差仍须标出，
不得因位移近似检查通过就声称神经路径也满足全部原物理门槛。

**以下是新候选的拟议效果标准，不是导师已确认的验收，也不追溯用于旧实验：**

1. 以完整预测窗的四点 MAE 分别小于同窗 B+ 为主要均值标准；拟合有效日四点 MAE 分别不劣于 B+。

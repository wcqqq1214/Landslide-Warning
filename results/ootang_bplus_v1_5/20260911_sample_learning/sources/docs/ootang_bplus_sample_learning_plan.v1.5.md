## 1. 问题及本次改动

假设：使用物理模型在更早截止时产生的外推误差训练修正器，可能比使用其拟合误差更符合
后续预测任务。诊断显示偏差、增长率和驱动相关方向会跨窗变化，所以该假设有明确失败风险。

固定同一 v1.1 M1 ConvLSTM 均值网络，做 IN（拟合误差）/ OOF（过去外推误差）配对。
两组使用完全相同的标签日期、日期权重、标准化、结构、种子、优化器和更新次数。
仅改变提供基准位移和物理特征的教师：IN 用均值训练截止时的教师，OOF 用更早教师。
这是样本构造策略的整体对照；包含教师拟合长度和输入分布差异，不视为根因的因果识别。

本次仍输出累计位移残差，不同时改为增量网络或改变损失。受限增量修正保留为待评估的
后续结构选择。原 M2 方程内蠕变修正记录保持；本版没有经典全场 PINN 或新的 M2 训练。

## 3. 同一均值模型与有限优化

- 直接复用冻结 M1：20 通道，30 日窗口，16 个隐藏通道，1×3 门控卷积和 1×1 输出，
  共 6,993 个均值参数，float64；相同种子初始化完全相同，输出层零初始化。
- 修正为 M1 原输出（100 倍线性头），加到各自教师的累计位移。首 29 日为预热缺值，
  全部正式计分从第 30 个索引起。每个预测日只读取截止该日的 30 日物理/驱动窗口。
- 本次没有硬幅度约束或新的物理方程约束；保留原头是为隔离样本对照。报告修正幅度、
  变化幅度和预测段负日增量比例，不剪裁、不重新对齐实测，也不把物理基线的约束保证
  自动赋予相加后的曲线。
- 损失为 `sum_(k,t,j) w(t)*((mu_teacher+r-y)/100)^2 / (4*不同日期数)`。
  不加增量项、末日权重或数据驱动的正则参数。批块 128 行，累积梯度后每轮只更新一次。
- Adam：lr=1e-3、betas=(0.9,0.999)、eps=1e-8、weight_decay=0，梯度范数上限 1。
  固定种子 0、1、2；每组每种子恰好 100 轮，无调参、选种子、早停或按外层分数选轮数。
- 保存第 0、25、50、75、100 轮 checkpoint 和全部训练损失/梯度日志；外层只评分固定
  第 100 轮及零修正基线，不检查其他 checkpoint 的外层成绩。
- 先冻结两组均值模型和共同 scaler，再交付尺度期标签。尺度数据不回传修改均值。

## 4. 概率层与物理重拟合迁移边界

尺度期 [c,n) 使用教师 c 的真实过去外推。每组每种子用其已冻结均值预测计算每点 RMS
误差，`sigma_j=max(0.001 mm, sqrt(mean((y-mu_j)^2)))`。这是高斯均值固定时的常尺度估计，
不是时变尺度网络；不做神经尺度训练、事后覆盖扩张或均值平移。每种子预测一个边际高斯，
三个种子等权混合，保留全部组件。尺度有 4 个估计值，但不属于 6,993 个梯度训练参数。

P0 为“零神经修正 + 同一尺度期规则”的概率参照。它不同于原 M0 的概率指标 NA；原 M0
仍保留为确定性 B+ 均值基线。P0 不冒充原物理模型学到了不确定性。

在均值和尺度全部锁定后，两组和 P0 均换用既有教师 n 生成整个 [0,n+180) 曲线，并按固定
窗口计分。更换物理教师是本实验共同的部署转移，神经权重和 scaler 不随 n 重新训练。
**尺度是在教师 c 上估计，最终使用教师 n，物理重新拟合可能改变误差分布**；这是一项必须
报告的迁移局限，不提供 split-conformal 或其他有限样本覆盖保证。预留时间顺序可以防止
标签混入，但不能消除该分布变化。

预测期不能以实测位移重锚或反馈。均值学习 API 只接收 c 长度标签，尺度 API 只接收
[c,n) 标签；外层 [n,n+180) 标签在最终预测/参数锁定后才进入评分函数。
字节完整性检查不等于允许提前数值解析外层标签。

## 5. 比较、验收与停止

每组固定采用三种子混合均值，另报种子分散；不择优保留种子。
分别报告教师 n 下训练 [30,n) 和预测 [n,n+180) 的四点 RMSE/MAE。
严格均值成功仍要求同一点训练 RMSE、训练 MAE、预测 RMSE、预测 MAE 均比确定性 B+
降低 >1e-6 mm，报每窗 k/4、合计 k/8；不以平均改善代替四点验收。

样本策略的主要对照是 OOF−IN 的逐点训练/预测差值；同时报告各自相对 B+ 的差值。
模型训练目标下降但外推变差，应原样记为负结果。尺度期的成绩是拟合诊断，不是独立测试。
概率报告每点 CRPS、80%/90%/95% 覆盖率、宽度和 interval score，主区间 90%。
概率比较以 P0 为参照，单报改善点数与覆盖偏差，不把宽区间的高覆盖写成成功，也不在
结果出现后增设综合分数或放宽均值门槛。

总预算：2 个外层 × 2 种样本 × 3 个种子 × 100 轮 = **1,200 次均值参数更新**；
0 神经尺度更新、0 新物理 nfev、0 物理前向。单进程、CPU 单线程、确定性算法、20 分钟
硬上限（包括训练和预测）；数值异常或超时保留失败记录，无自动重试或加预算。
必要的合成单元测试和读取 checkpoint 的验证不作为新的科学拟合，但须单列记录。

到达固定预算即结束本版，完整报告成功或失败。负结果不触发自动扩大网络、追加 PINN
或继续训练到达标；后续决定须基于明确的新问题另版记录。

## 6. 实施、核验与交付

- 独立代码 `code/physics_guided_sample_learning/`，配置
  `config/ootang_bplus_sample_learning.v1_5.json`；原 M1、特征和概率工具只读复用并记录哈希。
- 入口：`PYTHONPATH=code .venv/bin/python -m physics_guided_sample_learning.run --run-id <new_id>`。
  使用现有 `.venv`；结果写入新的 `results/ootang_bplus_v1_5/<run_id>/`，拒绝覆盖。
- 保存源文件/配置/本协议、教师选择/来源、日期及权重、scaler、均值锁、尺度锁、checkpoint、
  学习曲线、三组件预测、P0、逐点指标/对照、诊断图、计数/耗时、验证和完整性清单。
- 必要检查：未来标签/驱动扰动不改变更短训练输入；OOF 教师早于每个标签；同日权重合计 1；
  IN/OOF 标签日期一致；零头复现 B+；批块梯度与全批一致；尺度隔离；预测期无位移反馈。
- 实验后从 checkpoint 重新构造均值、复算尺度和概率指标，核验锁定顺序及来源；不重新
  训练来伪装独立复现。图表与逐点数据一致；验证完成后分步 commit 结果及解释文档。

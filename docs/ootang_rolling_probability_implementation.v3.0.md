## 已完成的实现步骤

代码位于 `code/rolling_probability/`：

- `data.py`：逐日释放位移；训练查询记录每个物理教师的标定前缀、起点与目标末行。早期四教师对上前次审计哈希，保留原优化器状态。必要的物理轨迹扩展使用冻结参数从零历史重放，不重新标定。
- `models.py`：25 个历史通道、8 个未来条件通道，16 隐通道的卷积 LSTM 编码器和直接高斯解码器，8,370 个参数。四点跨点卷积并不等于联合概率分布；当前只评价逐点边际区间。预测为 B+ 当前观测锚定输出加学习修正，网络初始化严格等于该锚定均值。
- `scoring.py`：Gaussian CRPS、区间评分与成熟误差校准。概率校准使用原始模型标准差计算误差比值；只有目标已经观测到才可用于下一起点，不循环使用已校准标准差。末端不足 30 日时只生成并评分合法步长。
- `run.py`：训练、内部选轮、开发、后期迁移分阶段；每起点锁定预测哈希后释放下一位移。模型、训练记录、所有步长/种子输出、来源快照和运行退出状态保留。全局截止和局部一小时上限都有效；实际执行成功与效果门槛分开。

为保持数组键与数学对照一致，内部 CSV 的 `B_ANCHOR`、`B_TREND14`、`PERSIST`、`DRIFT14` 表示本轮附加高斯分布的对照，呈现时写为 `…_G`；它们不是旧 M0 的概率成绩。`B_RAW` 的概率字段为空，NPZ 中其尺度只是未参与评分的占位数。原始和校准后的候选尺度均保存。

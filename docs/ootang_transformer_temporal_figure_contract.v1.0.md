# 跨起点验证图件合同 v1.0

本合同只规定呈现，不更改冻结实验。复用既有 Python / Matplotlib、中文字体与导师风格；原图及未跟踪制图规则不改。

- 问题：历史选定的收缩/正则能否在后续完整预测中保持收益；四点与种子差异是否限制结论。效果方向由保存结果决定，不事前宣称成功。
- 跨起点图为 quantitative grid：a 展示实际历史选择；b 比较四点平均 RMSE 与 B+、DRIFT1、岭回归；c 保留 λ 对 α 的同种子配对差；d 展示 λ 选择版逐点概率覆盖的保护条件。四个窗口部分重叠，不画独立实验置信区间。
- 最终图为两组四点分层轨迹：历史选择的 α 与 λ 各导出导师固定纵轴版、完整区间范围版，共四张。全 1461 日拟合/实测，最后293日一次发出；80/95%为历史90条误差RMS形成的高斯逐日边际预测区间，不是种子置信区间。
- 数据映射：`origin_1168/{alpha,lambda}_means.npz` 的选择别名为均值，`*_sigmas.npz` 为固定校准尺度；原CSV四点首日位移仅作为绘图零点。其他图取 `analysis/phase_summary.csv`、`metrics_by_point.csv`、`seed_summary.csv` 和各起点选择JSON。
- 始终保留完整日期、全部三种子、全部四点；不平滑、不删除尾段、不给区间乘视觉缩窄系数。导师版超框数须记录，并提供完整范围版。
- 240×170 mm，PNG 300 dpi、SVG可编辑文本；正文至少7.6 pt。黑色实测、灰虚线B+、蓝色候选，横纵浅灰网格，无三角标记。最终面板顺序 ATU1/O3、ATU5/O2、MJ3/O1-up、MJ1/O1-down。
- 量纲：位移/MAE/RMSE/CRPS/区间评分/宽度为mm，比例和覆盖以图注明确。跨起点RMSE比值仅在全部正值检查后使用对数轴，0%配对差线及80%逐点覆盖门显示；种子点不冒充独立数据集。
- 导出前使用实际渲染面板对齐门1.5pt、文本边界和数据线/注释碰撞检查。导出后核对SVG曲线/区间与源数组、PNG尺寸/DPI、字体、图中RMSE和覆盖数值，再目视全部五图20面板。
- 用户已明确本阶段不制作PDF，因此不执行要求PDF输入的字体/碰撞工具，不声称其通过；以实际SVG/PNG和Matplotlib几何审查记录交付。源静态检查与实际数值/目视检查分开记录。

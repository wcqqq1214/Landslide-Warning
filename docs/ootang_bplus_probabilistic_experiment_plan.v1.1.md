## 1．依据、责任与范围

导师当前要求是：仅研究藕塘剖面 MJ3、MJ1、ATU5、ATU1，以改进 B+ 引导智能概率位移预测，
改善训练段和预测段均值误差并量化不确定性。导师允许 ConvLSTM、推荐 PINN，并未指定具体
网络、概率分布、损失权重或优化器。用户已同意有限的三组比较、连续预测协议和 90% 主区间。

| 组别 | 本阶段实施对象 | 评价定位 |
| --- | --- | --- |
| M0 | 导师冻结的改进 B+；开发阶段使用相同方程的前缀标定版本 | 确定性物理基线 |
| M1 | B+ 引导的轻量 ConvLSTM 概率残差模型 | 物理输出辅助的统计修正 |
| M2 | B+ 离散方程嵌入的小型概率模型 | 有限蠕变修正参与动力反馈 |

M2 是物理与神经网络混合模型，不冒称经典全场 PINN。两条学习路线同时改变了编码器和物理
结合方式，因此只能比较完整方案，不单独宣称“PINN 优于 ConvLSTM”或证明物理因果。
本阶段不开展预警、新案例、SHAP、完整二维场重建或另一个全场 PINN 分支。

**执行默认分工：**导师交付的物理方程、最终参数和结果作为冻结来源；我方负责接口、平台
复现、按原方程进行的开发段辅助标定、机器学习与评价。此前待讨论的辅助标定责任在本计划
中按此默认安排落实，这是本次计划补全的责任建议，不是导师已确认或已交付的事实。若后续
明确由导师提供前缀版本，则按同一协议验收后接入，不改变评价日期或模型选择规则。

### 3.2 干净的前缀标定协议

训练只接收前 792 日位移和驱动。禁止导入 `model_wet.initial()`、旧模型 A 的拟合参数、
`best53_archive.json`、完整拟合候选、旧 `theta` 或自动续跑文件。参数顺序和上下界直接
按最终 `physical_model.NAMES/LO/HI` 构建；仅 `log_` 前缀参数取自然对数存储，
`creep`、`wet_creep` 为线性存储，不能误取对数。

固定以下两个独立起点；数值是物理坐标中的计算初值，不是新物性估计。同组数值用于该组
所有代表域，先做原边界检查，再按存储规则转换。

| 参数组 | 起点 A | 起点 B |
| --- | ---: | ---: |
| 四域 `tauP` / d | 7 | 30 |
| 四域 `margin` / kPa | 0.01 | 0.001 |
| 四域 `eta` / (kPa·d/mm) | 0.01 | 0.1 |
| 四域 `hardening` / (kPa/mm) | 0.001 | 0.01 |
| 四域 `tauRest` / d | 365 | 1000 |
| 四域 `tauMotion` / d | 7 | 30 |
| 四域 `creep` / (mm/d) | 0.02 | 0.05 |
| 四域 `initial_relaxation` / mm | 0 | 0 |
| 四域 `tauKelvin` / d | 30 | 90 |
| `tauR` / d | 30 | 60 |
| `reservoir_gradient_gain`、`reservoir_support_gain` | 0.3 | 1 |
| `k32`、`k21` / (kPa/mm) | 0.00001 | 0.0001 |
| `E_MPa` / MPa | 0.1 | 1 |
| `tauContact` / d | 150 | 500 |
| `tauBulk` / d | 100 | 500 |
| 三滑体 `rain_compliance` / (mm/m) | 1 | 5 |
| 四域 `wet_creep` / (mm/d) | 0.1 | 0.2 |
| 三滑体 `tauMoisture` / d | 30 | 90 |

采用两个低强度储备起点，避免仅用原边界中点产生滑移完全不启动的平坦区域；这不保证
优化收敛。记录初始滑移活动情况，但不根据开发段成绩增加起点或调整初值。

每个起点独立顺序执行三阶段：

1. 轨迹目标，`lambda_T=0, max_nfev=900`。
2. 末态约束，`lambda_T=792, max_nfev=800`。
3. 强末态约束，`lambda_T=79200, max_nfev=800`。

令 `r=(mu_B-y_obs)/(100 mm)`，各阶段目标为 `sum(r²)+lambda_T*sum(r_last²)`。
每个起点只继承自身上一阶段参数；不使用另一候选或完整训练段的结果。
统一使用 SciPy `least_squares(method='trf', loss='linear', x_scale='jac')`，原边界，
`ftol=1e-9, xtol=1e-10, gtol=1e-7`；参数扰动 Jacobian 沿用
`calibrate_boundary.py` 的 `2e-6*max(1,abs(theta_j))` 单边差分及边界换向规则。
差分、边界保护和求解精度在三阶段保持一致，记录实际调用及失败情况。

按第三阶段的训练目标选择候选；绝对差不超过 `1e-12` 时选 A。达到评估上限但轨迹有限、
边界和数值检验合格的候选可以保留，明确记录 `success=false`，不称全局最优。
两个候选均无有效最终结果时停止依赖开发教师的训练，不回退到完整拟合参数。
`max_nfev` 不包括全部数值 Jacobian 前向调用，另行记录 `total_forward_calls`、耗时与
每阶段终止原因，不把预算误写成总共 5000 次物理求解。

## 4．M1/M2 输入、前向更新与概率头

### 4.1 公共派生量及固定缩放

当天特征包括 `P_t,R_t,delta_R_t,rain_sum7_t,rain_sum30_t,H_t`；雨量和截止当天，
起始不足窗口使用已有日期，`delta_R_0=0`。这些是给定环境驱动下的条件预测特征，
不表示未来降雨已可提前预报。原 B+ 首日不额外加载降雨的规则保持不变。

每阶段仅用该阶段训练段的**未修正 B+ 参考轨迹**拟合输入均值和总体标准差，三个种子共享。
变换为 `(x-mean)/max(std,floor)`；静态坐标和 one-hot 不标准化。下限为：位移状态
`1 mm`，日位移增量 `0.01 mm/d`，雨量及其和 `1 mm`，`R/H/delta_R` 为 `0.1 m`，
水头 `0.01 m`，含水量 `0.01`，反力/分担长度为 `0.01 kPa`。
不裁剪标准化状态，也不按 epoch、预测期或新轨迹重估统计量。

### 4.2 M1：固定 30 天窗口的残差编码

对目标日 `t>=29`，窗口严格为 `[t-29,...,t]`，包含当天允许获得的物理/环境信息。
每个窗口内部 `h/c` 从零初始化并完整编码 30 步；不同窗口不传递 `h/c`。训练和预测使用
同一规则，不把它实现成跨全时段持续状态的第二种网络。物理教师状态跨分界连续推进。

输入张量为 `[batch,30,20,1,4]`；固定点轴为第 2 节顺序，20 个通道依次为：

| 通道 | 内容与映射 |
| --- | --- |
| 1–2 | 该点 `u_B(t)`、`u_B(t)-u_B(t-1)`；仅位移按完整 `B_o` 投影 |
| 3–8 | 六个公共环境/水文派生量，按同样数值广播到四点 |
| 9–12 | `rain_head[O3,O2,O1_up,O1_down]`，作为四个全局特征广播，不能按点号误配 |
| 13–16 | `moisture[O3,O2,O1_up,O1_down]`，同上；O1 两值相同仍保留固定通道 |
| 17–20 | 该点归一化剖面里程 `(x-295)/(1680-295)`，以及 `O3/O2/O1` 三维 one-hot |

首日位移增量设为 0；不加入任何观测残差或实测位移历史通道。一维卷积表示点序邻接，
不把不等间距四点假装成等间距物理网格，坐标通道也不等于物理空间微分算子。

均值网络为单层 ConvLSTM、隐藏通道 16、卷积核 `(1,3)`、宽度方向 padding=1，
标准 sigmoid 门控和 tanh 候选；最终 `(1,1)` 线性卷积输出标量 `r_theta`。
`mu_1=y0+u_B+100 mm*r_theta`。门控矩阵 Xavier uniform、偏置 0，输出层权重/偏置为 0。
零修正在全部有效日期返回 B+。窗口内反向完整保留，窗口之间没有被人为截断的递归依赖。

### 4.3 M2：每天一次的方程内修正

所有 54 个物理参数冻结。均值网络为 `38→16→16→4` 的 MLP，两层 tanh，隐藏矩阵
Xavier uniform、偏置 0，最终层权重/偏置为 0；无 dropout。

每天 `t>=1` 先按原版更新当天水文量，再构造以下 38 维输入，顺序固定：

1. 六个公共环境/水文派生量。
2. 当天 `h_t[4],m_t[4]`，按代表域轴排列。
3. 前一日末 `z,p,r_b/L,r_c/L,r_E/L,b`，每项 4 维；`z=q-b`，`L` 为冻结几何分担长度。

反力除以 `L` 仅形成等效应力输入，不声称它是测得的局部应力。输入前日力学量使用 **M2
自身递推状态**，不是每次替换回未修正 B+；标准化用第 4.1 节冻结统计，保留该路径梯度。
不得读取当天尚未求出的修正后位移，也不加入隐式同日迭代。

每天仅调用一次网络，四域慢速率为：

\[
c^{NN}_{j,t}=(c_{d,j}+c_{w,j}m_{j,t})
\exp\{\log(2)\tanh[f_{\theta,j}(x_t)]\}.
\]

倍数限定在 0.5—2 范围内，零网络输出对应倍率 1。保留原初始 Kelvin 项：

\[
b_{j,t}=\sum_{s=1}^{t}c^{NN}_{j,s}
+a_j(1-e^{-t/\tau_{K,j}}).
\]

当天速率不在子步重新预测；`b_(t-1)→b_t` 按原 C 求解器在 64 个子步中线性推进。
`delta_b→k0→rhs→位移增量→反力` 的反馈链保留；最终 `mu_2=y0+B_o*q_NN`，
不能改成物理求解完成后再添加位移残差。首日仍为原参考状态，不调用修正网络。

倍率限制是第一版的表达能力边界，不保证足以消除所有偏差；记录趋近上下限的频率，
不依据最终预测误差放宽范围。若某个前缀系数为零，乘法修正不能创造该分量，须如实报告。

### 4.4 完整历史梯度

M2 每次前向从首日推进完整训练轨迹，一个 epoch 的损失依赖所有有效训练日。
固定物理参数后可预计算 16 个活动集线性映射；沿原规则选择可行活动集，对选中分支传播
梯度。允许日级自定义反向或检查点保存，但不能静默 `detach` 力学状态或改成截断反向。
在分段不可微的活动集切换点单独检验连续性和单侧导数，不能伪称处处光滑。

### 4.5 两条路线共用的概率尺度头

均值选定后，冻结全部均值参数和运行状态；供尺度头使用的模型输出/状态停止梯度。
尺度网络统一为按测点共享的 `20→16→1` MLP，隐藏层 tanh。输入使用第 4.2 节的
20 通道当前日特征，但前两项换为该均值模型的 `mu(t)-y0` 和 `mu(t)-mu(t-1)`。
其余环境/水文/静态特征及缩放仍为该阶段冻结版本，不重新拟合统计量。

每种子、每天、每点定义 `Y~Normal(mu,sigma²)`，
`sigma_mm=0.001+100*softplus(a)`。隐藏层 Xavier uniform、偏置 0；最终层权重为 0，
偏置经 softplus 逆变换，使初始 sigma 等于 `max(该种子训练段合并RMSE,0.002 mm)`。
数值下限仅用于保护，不解释为传感器精度。禁止残差裁剪、NLL 截断或按预测段扩大区间。

这只建立逐日逐点边际分布，不宣称已建立完整空间误差协方差或整条轨迹的同时覆盖保证。

## 5．训练、轮数选择与最终重训

### 5.1 固定执行设置

全程 CPU float64；Adam，`lr=1e-3, betas=(0.9,0.999), eps=1e-8, weight_decay=0`，
梯度范数上限 1。均值种子固定 `0,1,2`，尺度初始化种子为对应值加 `10000`。
记录实际依赖版本和确定性设置，不通过挑选种子决定主线。

一个 epoch 定义为：完整有效训练日期和四测点产生一次平均损失、完成一次优化器更新。
M1 可以为节省内存分块累积同一平均损失的梯度，但不能每块分别更新；M2 保留完整历史。
不打乱日期、不随机抽取历史片段、不使用真实位移重置状态。

### 5.2 均值阶段

损失为所有有效训练日、四点等权的 `mean(((mu-y_obs)/100 mm)²)`。物理参数不参加 Adam。
三个种子各训练到 200 轮，保存 `0,10,...,200` 轮；即使候选轮数为 0，也须如实保留。
同一候选轮数下，先对三模型均值等权平均，再计算开发段“四点各自 RMSE 的算术平均”。
选择最小值对应的共同 `e_mu`；绝对分差不超过 `1e-12 mm` 时取较早轮数。
不得为每个种子各选最优轮数后再组合。

### 5.3 尺度阶段

加载三种子的 `e_mu` 并冻结均值；训练 Gaussian NLL：
`mean(log(sigma/100 mm)+0.5*((y_obs-mu)/sigma)²)`，忽略常数项。
三个尺度头各训练到 100 轮，保存 `0,10,...,100` 轮；以三个高斯的等权混合分布在开发段
的平均 CRPS 选择共同 `e_sigma`，分差不超过 `1e-12 mm` 时取较早轮数。
不能用不随尺度变化的 RMSE 选择该阶段轮数。

均值与尺度阶段均只使用训练标签进行梯度优化，开发标签只用于上述预定 checkpoint 选择。
开发评分是模型选择依据，不另称独立校准结果。

### 5.4 最终重训和失败记录

锁定每路线的 `e_mu/e_sigma` 及全部配置后，切换到导师最终 B+；在前 1168 天重新拟合
输入统计，用同三个种子从头训练，分别只运行选定轮数。最终 293 天只统一评分，不再选
checkpoint、种子、区间放大系数或网络大小。

任何种子失败均记录为失败，该路线不能静默降成两种子混合。可以修复可复现的工程错误，
记录新代码哈希与重跑原因，并使受影响结果按同一实现重算；不能借数值失败换架构或增加
候选数。M2 完整反向若无法在现有资源上完成，报告资源阻碍，不偷偷采用截断算法。

## 6．评分、排序与科研结论

### 6.1 概率分布与指标

对 M1/M2，主结果是三分量等权高斯混合；同时保留各种子结果用于稳定性说明。
混合均值为均值平均，总方差为 `mean(sigma_k²+mu_k²)-mean(mu_k)²`，仅允许对浮点误差
造成的微小负值做数值保护。80%、90%、95% 区间分别取混合 CDF 的
`(0.10,0.90)、(0.05,0.95)、(0.025,0.975)` 分位数，不平均单种子上下界。
分位数用单调 CDF 的二分/Brent 求根，按需扩展尾部边界，位移绝对容差 `1e-6 mm`。

CRPS 采用高斯混合解析公式。令
`A(d,s)=2*s*phi(d/s)+d*(2*Phi(d/s)-1)`，则：

\[
CRPS=\frac13\sum_k A(y-\mu_k,\sigma_k)
-\frac1{18}\sum_{k,l} A(\mu_k-\mu_l,\sqrt{\sigma_k^2+\sigma_l^2}).
\]

区间评分为 `IS_alpha=(U-L)+(2/alpha)*(L-y)*I(y<L)+(2/alpha)*(y-U)*I(y>U)`。
逐点先按有效日期平均，再四点等权平均，单位 mm。覆盖按闭区间 `L<=y<=U` 计数。
不把强时间相关日数据当作独立重复试验，不由三个初始化种子推断跨案例泛化能力。

M0 没有概率分布：`sigma/quantiles/PICP/width/interval_score/CRPS` 均记为空值和
`not_applicable`，不是 0。M0 只参与均值比较，本阶段不临时为其添加误差带或退化分布评分。

### 6.2 候选主线排序

本节排序只使用开发段。首先要求三种子完整且各项数值检查通过。对合格 M1/M2：

1. 主评分为混合均值的四点平均 RMSE；差距超过较小 RMSE 的 1% 时选较小者。
2. 若落入上述接近范围，比较混合 CRPS，取较小者。
3. CRPS 绝对差不超过 `1e-12 mm` 时，取均值和尺度网络可训练参数总数较少者；仍同分则选 M1。

单种子指标不替代混合评分，不能临时以某个种子的最好成绩排序。1% 是工程接近容差，
不是统计显著性门槛。开发段先选候选，最终段只报告其是否保持优势；若两条路线均不改善
B+，保留 M0 为当前基线并报告本次未得到更好的学习模型。

### 6.3 对导师目标的逐点验收

训练、预测均采用共同日期掩码，逐点同时报告 RMSE、MAE 和相对 M0 的差值；合并指标
同时列“四点 RMSE 平均”与“全部点日合并 RMSE”，不能混称。
对每一点，只有训练和预测两段的 RMSE、MAE 均低于 M0 超过 `1e-6 mm` 的数值容差，才记
为该点均值目标满足。报告 `k/4`：4/4 才称全部达到，1–3/4 为部分改善，0/4 为未完整改善
任何一点。该容差只排除数值同值，不构成有实用意义或统计显著的提升门槛。

90% 区间是名义水平，报告逐点覆盖率、宽度、CRPS 和区间评分，不设置靠任意拉宽即可
达成的验收门槛。以误差尺度解释剩余不确定性，不保证覆盖必达 90%，也不据此声称量化了
固定物理参数、未来气象和几何的全部不确定性。

## 7．验收检查与停止条件

| 检查 | 明确要求 |
| --- | --- |
| 原 B+ 复现 | 全逐日位移对冻结结果最大绝对差 `<=0.001 mm`；单独重算原完整口径指标 |
| M2 零修正 | 对同平台 B+ 的位移、q/p/b 最大差 `<=1e-5 mm`；M1 在有效日期零残差返回 B+ |
| 水文保持 | 水头差 `<=1e-10 m`、含水量差 `<=1e-12`；含水量在 `[0,1]` 内允许 `1e-12` 余量 |
| 力学约束 | 沿用原活动集对 x 的 `1e-8`、净力的 `1e-7` 原生单位容差；检查全部子步，不只检查日末 |
| 不可逆滑移 | 检查 `delta_p=x/beta`，容差按原 x 容差传播；超出该数值余量的倒滑失败，不裁切结果掩盖 |
| 互补残差 | 记录 `w=A*x-rhs`、可行性和 `max|x*w|/(1+max|x|*max|w|)`，归一化残差 `<=1e-7` |
| 前缀拟合隔离 | 改变第 792 日之后的位移，不改变前缀物理参数、输入统计、初值或物理标定 A/B 候选选择 |
| 神经选模隔离 | 开发标签可影响 e_mu/e_sigma 和路线选择；最终 293 日标签不得影响拟合、选择或预测，仅可改变评分 |
| 前缀一致性 | 相同物理/神经参数下，只输入过去驱动与输入更长驱动产生相同过去预测，误差 `<=1e-8 mm` |
| 时间与分母 | 固定轴顺序、日期、y0、预热状态及 762/1138/376/293 计分日数；分界处没有额外校准 |
| 概率输出 | 三分量均有限且 sigma 为正；各水平分位数有序、嵌套，NA 不参与 M0 概率均值 |

梯度检验使用预先固定的小幅非零神经权重，避免输出层全零造成前层零梯度的空检验。
至少包含一段有活动集变化的多日轨迹，以及完整 792 天训练损失的四个固定随机方向
（检验种子 `31415`）。在非切换点，以 `h=1e-4,1e-5,1e-6` 中相邻两个稳定步长检查：

\[
|D_{AD}-D_{FD}|\le10^{-5}+10^{-3}\max(|D_{AD}|,|D_{FD}|).
\]

切换点另比较前向连续性和各侧导数，不要求不存在的唯一中心导数。检查点/分块开关前后
必须保持同一完整轨迹和相同梯度依赖；失败不得用只测单步代替。

第一版预算完成后，交付完整结果或明确失败记录，不自动增加模型分支、种子和物理起点。
局部失败只暂停依赖它的工作，继续完成可独立的数据、接口、评分和另一条路线。
后续消融或模型扩展另记版本，不在当前回测上反复试到达标。

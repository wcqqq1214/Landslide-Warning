## ConvLSTM 与物理信息方法分别决定什么

ConvLSTM 是用卷积门控和循环状态提取时空信息的网络结构。PINN 通常通过物理方程残差、
初边值或相应离散时间关系约束网络训练。结构与物理约束不是完全互斥的选择，但组合方式必须
实际实现，不能只凭名称认定符合 PINN。[1,2]

| 实际实现 | 准确表述 | 能说明的物理作用 |
| --- | --- | --- |
| B+ 位移/状态作为 ConvLSTM 输入，学习输出误差与分布 | B+ 引导的概率 ConvLSTM | 物理信息参与统计预测，不保证修正轨迹满足动力方程 |
| ConvLSTM 输出有限的状态/本构修正，修正进入 B+ 动力计算 | 物理方程嵌入的概率 ConvLSTM 混合模型 | 方程约束修正后的演化；更接近混合动力模型/UDE 思路 [3] |
| 网络输出状态，训练包含真实 B+ 方程残差、初值与互补约束 | 基于 B+ 降阶方程的 PINN | 物理关系作为显式训练约束，需报告约束误差与外推行为 |

仅令神经网络贴近 B+ 输出的损失属于教师轨迹约束，不能据此声称实现了真实力学方程约束。
若完全固定 B+ 方程、参数和初值并严格求解，神经网络没有独立改善均值的自由度；必须明确
引入可学习模型差异，或采用有边界且可检验的软约束。

## 保留 ConvLSTM 需要哪些实质改动

代码依据：`code/convlstm/model.py` 的 `ConvLSTMCell`、`ConvLSTMForecast`、`make_windows`
和预测重构；`code/convlstm/grid_interp.py` 的 4×7 网格及 IDW 插值。

| 当前实现 | 本轮要求下的改动 |
| --- | --- |
| 8 点输入经 IDW 映射到 4×7 平面网格 | 收窄到四点剖面；若保留卷积，以沿剖面的一维序列作为候选表示，显式保留坐标/间距 |
| 过去 7 日预测下一日位移增量 | 改为能在整段预测期连续运行的模型；所有依赖位移的输入只能由允许的历史或模型自身状态构造 |
| 每个预测日加上真实 `U(t-1)` | 取消逐日实测锚定；模型与 B+ 使用相同起点、驱动与状态推进规则 |
| P10/P50/P90 有序分位数头 | 明确均值与预测分布，生成中心 90% 区间；P50 仍是中位数，不能改名为均值 |
| 普通分位数损失，无 B+ 状态关系 | 根据所选路线加入 B+ 特征，或将可学习修正嵌入真实动力方程 |
| 原一步预测评价日期与校准方式 | 为本轮另建配置与产物，严格使用 1168/293 天协议；重新设计时间开发与区间校准 |

物理点位顺序为 ATU1—ATU5—MJ3—MJ1，近似剖面里程为 295、1000、1250、1680 m。
四点不是等间距格点；一维卷积只能先表示沿剖面邻接，不是空间微分算子。加入坐标也不自动
解决不规则采样问题。B+ 的四个运动坐标为 O3、O2、O1 上端、O1 下端，不等同于四个测点；
MJ3、MJ1 必须通过同一 O1 场及观测矩阵读取，不能直接把两点当成两个独立滑体。

能够复用的是门控单元和部分数据/评价函数。旧权重、旧输入契约、旧预测循环与旧评分不能
直接沿用。因此保留网络名称也仍然是一个需要训练和验证的新版本。

## 当前技术建议与下一步

优先保留 B+ 原版作为冻结基线，把小型方程嵌入模型作为主候选，ConvLSTM 作为可替换的神经
编码器候选。没有证据表明四点任务必须依赖卷积；B+ 已提供时间记忆与空间耦合，额外循环
记忆是否有益需要实验检验。这是复杂度取舍，不是已验证的网络优劣结论。

第一候选修正位置仍为含水状态控制的慢速蠕变分支：用小网络学习速率的有限修正，保留
水力更新、运动迟滞、不可逆滑移和界面/土体松弛，并使零修正严格返回 B+。代码核对表明
慢分量增量会改变互补求解及反力更新，能够构成方程内修正。修正范围、损失权重和网络
结构尚未冻结，不根据已知后 293 天结果反复扩大自由度直至达标。

下一阶段的独立准备与验证顺序：

1. 明确区分冻结 B+ 基线、允许信息构成的编码器输入、动力修正接口、均值/区间输出及独立
   评分器；预测接口不接受预测期实测位移。
2. 在当前平台复现原 B+。交付包含 Windows DLL，需使用其 C 源码建立独立平台适配，核对
   全轨迹和可比较的内部状态；不改原物理方程、参数或冻结文件。
3. 对候选修正位置做零修正回归及梯度/数值可行性检查，再锁定神经编码器。每天 64 子步的
   可微物理递推是潜在计算成本，不能仅凭网络小就承诺训练便宜。
4. 正式训练前确定时间开发方案、区间校准方式与配置。先前用户选择的主协议和 90% 区间
   保留；物理重标定责任与最终编码器仍作为讨论事项，不能记录成导师或用户已批准。

无论采用哪个编码器，最低检验都包括：同条件 B+ 比较；改变预测期位移文件不改变输出；
初值及分界连续；零修正返回 B+；O1 观测映射正确；内部滑移非减但不强制地表位移单调；
均值误差与区间覆盖/宽度分别报告。均值优于 B+ 是待检验目标，不是训练完成的同义词。

  物理标定；固定教师下的开发评价不能称为完整混合模型的独立验证。严格时间验证需要相应
  截止日期的物理版本，单独换一个划分日期不能解决。
- 90% 区间针对逐日逐点未来实测值，需报告覆盖率、宽度和区间评分；不等于四点或整段
  同时覆盖 90%。固定物理参数和实测外部驱动时，不能宣称完整传播所有物理与环境不确定性。

# 藕塘 v2.0 结果：直接多步 ConvLSTM 未达标，停止本候选

日期：2026-09-11。用户限定只使用 ConvLSTM/PINN；本次完成其中一个 ConvLSTM 候选，
未采用此前已撤回的非神经状态空间模型建议。

**结论：严格均值改善 5/8，但两个预测窗均未通过完整概率判据，整体目标未完成。
停止本候选，保留 B+；不继续派生诊断、增加训练或自动开启下一版。**
实现完成、核验通过与导师要求的效果达标分别判断；没有新增用户或导师对效果的接受记录。

  核验没有训练、重新拟合或实际数据梯度诊断。

## 解释边界与下一步

只保留这个候选的局部收益与完整失败证据，当前继续采用 B+ 基线；本次不提出或启动下一组改法。
若后续决定新实验，仍只能在用户明确限定的 ConvLSTM/PINN 内，先另行确定具体依据与投入。
本候选不证明整个 ConvLSTM/PINN 家族无效，也不支持认定历史梯度问题是唯一瓶颈。

按 academic-research-suite 的 11 项统计解释检查：

| 检查项 | 本次处理或限制 |
| --- | --- |
| 辛普森悖论、生态谬误（2 项） | 同时报逐点与两窗算术平均，不从 5/8 或平均数推断所有测点、整座滑坡有效 |
| Berkson 选择偏差、碰撞变量偏差（2 项） | 固定单案例/四点不是随机样本；不作总体关联或混杂控制的因果结论 |
| 基率忽略（1 项） | 本次没有预警分类、事件发生概率或诊断敏感度，不作基率相关主张 |
| 回归均值（1 项） | 不按极端误差挑点或挑日期，全部与固定同期 P0 比较；跨期收益不称机制效果 |
| 幸存者偏差（1 项） | 三种子及全部点窗、失败结果都保留，没有剔除不利模型 |
| 多重寻找、分析分叉（2 项） | 旧窗口已多次暴露，无法恢复盲测；本次方案先提交，仅一个候选，不报告显著性或事后选优 |
| 相关不等于因果、反向因果（2 项） | 输入/网络依赖不等于滑坡机制因果，已知未来驱动也不是实时可用性的证明 |

原始日值 as-of 未知、当前 h 预处理、旧教师迁移、给定未来降雨/库水位、尺度跨时期迁移的限制保留。
432 日尺度只见 90 日误差却应用于 180 日是额外外推限制；tanh 特征会饱和。
概率输出是逐点逐日边际分布，不含整条轨迹同时覆盖或已验证的联合时空分布。
三种子、四点与两窗不是独立现场重复，本次只能是已暴露历史窗口的探索证据。

## 4. 一个候选、一个必要对照

| 角色 | 标识 | 核与拟合 |
| --- | --- | --- |
| 唯一主候选 | `ADD` | `K_T(t,t') + K_H(z,z') + WhiteKernel`，每点联合拟合一个GP |
| 必要对照 | `TIME_ONLY` | `K_T(t,t') + WhiteKernel`，每点独立拟合一个GP |
| 固定均值参照 | `M0` | 原B+保存均值，概率指标不适用 |
| 固定概率参照 | `v1.1-e0` | 原同窗三分量保存分布 |
| 历史结果参照 | `BPLUS_GP_V1` | 原 `BPLUS_GP` 保存输出的报告别名，不改原产物 |

每点ADD一次联合边际似然优化，不能先拟合时间残差、再把剩余误差另拟合为物理GP。
TIME_ONLY是重新独立拟合的必要对照，不能用ADD内部的时间分量冒充。

### 4.1 核定义

标准化后令

$$
M_{3/2}(d)=(1+\sqrt{3}d)\exp(-\sqrt{3}d),
\quad d_T=|t-t'|/\ell_T,
\quad d_H=\sqrt{\sum_{q=1}^{4}[(z_q-z'_q)/\ell_{H,q}]^2}.
$$

$$
K_T=A_T M_{3/2}(d_T),\qquad K_H=A_H M_{3/2}(d_H).
$$

只按“时间”和“四维物理条件”分两组；不把四个物理输入各拆成单核，也不增加时间×物理交互核。
旧五维Matérn使用包含时间的联合距离；它并不是本稿两个Matérn的乘积，不能把二者代数等同。

加性核允许日期远离时仍通过物理状态相似性建立相关性，但是否具有预测价值需要上述对照检验。
仅借鉴 [Duvenaud等，Additive Gaussian Processes，第2—3节](https://arxiv.org/pdf/1112.4394)
的低维函数和核相加思想，不复用其全部交互项或把其数据集收益当作藕塘证据。
Matérn与ARD含义以 [scikit-learn 1.7原文](https://scikit-learn.org/1.7/modules/generated/sklearn.gaussian_process.kernels.Matern.html) 为依据。

| 参数 | ADD | TIME_ONLY |

| `A_H` 初值 / 边界 | 1 / [1e-3,1e3] | 无该核，不保留可优化的伪零幅度 |
| `ell_T` 初值 / 边界 | 1 / [0.01,1000] | 相同 |

## 5. 概率计算：完整模型一次条件化

以下省略点下标，`r`为归一化训练残差，`eta`为jitter，`k_T,k_H`为某查询点到训练点的列向量。

$$
C=K_T(X,X)+K_H(X,X)+(\sigma_\varepsilon^2+\eta)I,\qquad
\alpha=C^{-1}r.
$$

$$
m_T=k_T^\top\alpha,\quad m_H=k_H^\top\alpha,\quad
\mu_y=B+s(m_T+m_H).
$$

$$
v_f=K_T(x_*,x_*)+K_H(x_*,x_*)-(k_T+k_H)^\top C^{-1}(k_T+k_H),
\qquad
v_y=s^2(v_f+\sigma_\varepsilon^2).
$$

数值实现用分解/线性求解，不显式求逆。TIME_ONLY从自己的训练协方差重新计算，不沿用ADD的`C`。
噪声只计一次，jitter不额外加入观测预测方差；库若已经返回包含WhiteKernel的方差，不能再次加噪声。

为了核对分量，另外保存：

$$
v_T=K_T(x_*,x_*)-k_T^\top C^{-1}k_T,\quad
v_H=K_H(x_*,x_*)-k_H^\top C^{-1}k_H,\quad
c_{TH}=-k_T^\top C^{-1}k_H.
$$

$$
v_f=v_T+v_H+2c_{TH}.
$$

先验分量独立不代表它们在给定同一组残差后仍独立；交叉项一般不为零。
以上按 [GPML第2章式2.23—2.24及观测方差说明](https://gaussianprocess.org/gpml/chapters/RW2.pdf)
作分块条件化推导，是本稿明确写出的计算约定，不声称抄自未收到的审查附件。
分量均值/方差只是该模型条件下的分解，不解释为实测水文贡献；时间与物理摘要相关可能影响分量可辨识性。

不修改被冻结v1配置、核心源码或产物以迁就新任务。

| 检查 | 必须证明的内容 |
| --- | --- |
| 列选择 | 时间核只读第0列，物理核只读第1—4列；TIME_ONLY不访问物理核 |
| 核/解析梯度 | 合成输入上对照独立公式和固定中心差分；不使用真实开发数据调容差 |
| 对照退化 | 合成测试把物理核移除后，与相同时间核及参数的TIME_ONLY相符；这不是新增真实拟合臂 |
| 残差与隔离 | 符号、RMS单位、零残差回到B+、仅训练标准化、8组锁定前不可评分 |
| 后验方差 | 完整式与分量+交叉项相符；至少一个合成例交叉项非零，能抓出简单相加错误 |
| 噪声与jitter | 观测方差减潜在方差等于噪声方差；jitter不作为额外观测噪声 |
| 重载 / 矩阵 | 8模型保存重载；独立核公式及另一线性求解途径核对均值/方差 |
| 分数 / 来源 | 同窗同掩码复算全部参照和ADD/TIME_ONLY；M0概率字段不适用 |
| 停止计数 | 每臂每点最多1次拟合、全体8次；异常不重启、不补点，原始失败记录保留 |

本轮提议核验容差：

- 核梯度合成检查：对数参数中心差分步长1e-5，`atol=1e-5, rtol=1e-4`；固定小型有限输入，不触碰边界。
- 模型重载：均值和潜在/观测方差绝对差≤1e-10，单位分别mm、mm²。
- 独立矩阵与分解恒等式：均值1e-6 mm、方差1e-6 mm²，另加相对容差1e-8。
- 分数复算：误差/评分1e-9 mm，覆盖率1e-12；旧B+到e0均值核对1e-8 mm。
- 归一化潜在方差负值只允许≥`-1e-10*max(1,A_T+A_H)`的舍入误差归零并记录；
  TIME_ONLY取`A_H=0`。交叉协方差可为负，不能把它裁成零。越界停止，不放宽容差。

旧运行的matmul警告及其有限值/逐项和核对保持可追溯。新运行若再次出现，完整记录并依固定数值检查裁定；
非有限结果或超过容差即停止，不能用“上次是警告”自动放行。

## 7. 评价与明确的去留规则

### 7.1 共同评分

全部五组按相同的762日拟合与376日预测日期评分。
均值报告每点及四点平均MAE/RMSE；四点RMSE算术平均和全部点日合并RMSE分列。
有概率分布的四组均报告CRPS，80%/90%/95%覆盖率、宽度、区间评分。
模型主输出使用观测预测区间，不作事后放大、校准或逐点替换。

下文`eps=1e-6 mm`只处理浮点并列；覆盖比较容差为1e-12。
无显著性检验，不把762个连续日值当作762个相互独立的重复试验。

### 7.2 实质增益的本稿提议

**本稿将0.5 mm与1%明确列为研发去留阈值提议，避免把浮点级下降叫作实质改善。**
当前没有现场噪声或任务成本依据来证明它们是工程最小重要差异；它们不是6pro给出的原值，
不是导师验收标准，也不追溯改判GP v1。若采用本计划，应在实施配置中原样固定；
如需修改，只能在本轮实际拟合前形成明确新记录。

对四点平均MAE和RMSE，ADD相对参照`R`的实质改善定义为：

$$
\bar E_R-\bar E_{ADD}\ge \max(0.5\ {\rm mm},0.01\bar E_R).
$$

比较时仅允许1e-6 mm数值容差。分别对`R=B+`和`R=TIME_ONLY`要求MAE、RMSE两项成立。

对平均CRPS和90%区间评分，相对`R=e0`和`R=TIME_ONLY`均要求至少降低1%，
并且绝对降低严格大于1e-6 mm；参照为零时不以除零或NaN判为通过。

### 7.3 所有条件同时满足

| 层次 | 固定通过条件提议 |
| --- | --- |
| 拟合均值 | ADD对B+四点平均MAE/RMSE降低超过eps，每点两项≤B++eps |
| 预测均值 | ADD对B+、TIME_ONLY分别满足第7.2节的0.5 mm及1%双条件 |
| 逐点预测均值 | ADD每点MAE/RMSE均≤B+与TIME_ONLY各自对应指标+eps |

| 逐点预测概率 | ADD每点CRPS、90%区间评分均≤e0与TIME_ONLY各自对应指标+eps |
| 覆盖偏差 | 每点ADD的90%覆盖距0.9的偏差≤各概率对照偏差+1/376+1e-12；分别检查e0、TIME_ONLY |
| 加宽保护 | 对上述每个概率对照，ADD某点宽度增加超过eps时，该点90%区间评分必须降低超过eps |
| 保存的GP v1参照 | ADD预测四点平均MAE/RMSE/CRPS/90%区间评分均不劣于保存GP v1超过eps，防止丢掉已有平均正结果 |

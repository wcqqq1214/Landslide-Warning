## 1. 唯一研究问题

原残差网络的训练拟合误差很小，开发及最终预测未稳定超过 B+。本轮只检验：**在相同 Transformer 上惩罚训练期残差修正幅度，能否提高跨时段均值预测和概率评分？**
这是假设，不把过拟合预先认定为失败原因，也不保证正则化有效。以往残差学习已多次尝试，本轮的新变量仅为下面明确的训练目标。

令 `q=fθ(X)`、`r=(y−B+)/s`，原输出保持 `μ=B+ + s q`。新目标为：

`L = mean((q−r)^2) + λ mean(q^2)`，固定 **λ=1**。

两项按训练前缀所有天和四点等权，均在原训练段单位 s 中计算。选择1是事前规定两项同权的单次强度探针，不是内部/开发/最终搜索的最优值。代数上等于 `2 mean((q−r/2)^2) + mean(r²)/2`；无函数限制时目标最优修正为原残差的一半，神经模型未必精确达到此解。它是输出幅度软惩罚，不是参数 weight decay、硬限幅或满足 B+ 方程的保证。

仅新增 `TRANSFORMER_BRES_REG1`。对照为同协议原 `TRANSFORMER_BRES_COND`（λ=0）、B+、DRIFT1、普通岭回归；原版及对照权重/预测直接按哈希复用，新增旧模型拟合和物理调用均0。没有 DIRECT、Mamba、新架构、概率头或额外正则强度搜索。

开发按MAE→RMSE、CRPS→IS90在五个预定方法中分别锁定名单；完整293日全部评价，名单不改。即使内部/开发很差，也完成预算内全部预定训练和评分。

沿用旧条件：平均MAE/RMSE各较B+改善≥1%，逐点两均值指标不退步超过1e-6 mm；平均CRPS/IS90各改善≥1%，逐点两概率评分退步≤5%，90%覆盖平均≥85%、逐点≥80%。这些是研究工作条件，不是导师逐条指定门槛。

正则化额外收益与超过B+分别报告：新REG1相对原版的平均MAE/RMSE同时降低、且≥2/3同种子同向，才记该阶段均值配对改善；概率同时降低CRPS/IS90且≥2/3同种子同向才记概率配对改善。分别列开发、最终、四点、全部种子；只有两阶段均通过才描述跨阶段一致。另报DRIFT1和普通岭回归。无显著性或因果推断，不按点/种子拼接最优，不删尾段。

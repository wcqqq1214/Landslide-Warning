# 藕塘夜间小型尝试：结果简报

**预定实验已全部跑通，整体仍未达到“均值和概率同时优于B+”的目标。** 新增全历史GRU本点版与固定图版，各1241参数，完成24次拟合、4800次更新、全部三种子及完整293日评价；没有因成绩不好中断。残差诊断未满足事前条件，因此没有启动双头模型。

**[查看六页PDF对比图](../output/pdf/ootang_overnight_graph_v1/v2/ootang_spatial_pilot_figures.pdf)**：第1页跨时段对比，第2—3页两版GRU四点曲线，第4页残差诊断，第5—6页完整区间范围。[PNG/SVG和图件源数据](../figures/ootang_overnight_graph_v1/20260915/README.md)。

单位mm，为四点各自RMSE的等权平均；每个窗口均保留完整293日。神经主输出为三种子预测均值的评分，旧对照直接复用保存结果。[完整33组指标](../results/ootang_overnight_graph_v1/20260915/analysis/phase_summary.csv)。

1. **原起点条件化尝试失败。** 完整历史注意力、去显式历史位移和均匀池化均未建立稳定收益，最终误差明显高于B+；结果没有被新GRU覆盖。
2. **换成全历史GRU后，仍只有972历史窗通过B+均值门。** 792和最终未过，最终四点RMSE均高于B+。最终也未同时超过DRIFT1或普通岭回归的平均MAE/RMSE；旧半残差的局部正结果继续保留，不能据最终成绩重新选模。
3. **固定图没有足够的额外收益。** 相同输入、参数量、种子与训练，仅允许MJ3—MJ1传递信息。最终RMSE只由14.284降到14.257mm；三窗图相对本点的均值/概率门均未过，同种子MAE与RMSE同时改善分别为1/3、2/3、1/3。这支持“此固定小图增量不足”，不证明所有空间网络无效。

**残差分解为什么没有接着训练**

前1152日分四个固定教师块，因果EMA30分出慢/快残差。ATU1/ATU5的快速方差比在后两块均低于0.1，MJ3/MJ1在四块均低于0.1；没有点在同一驱动、滞后和符号上满足至少3/4块的相关与方差条件。事前要求至少两个点共同支持，实际符合点0，所以GRU_GRAPH_DUAL拟合0。这只是该诊断缺乏跨段支持，不等于所有分解无效。[16组方差](../results/ootang_overnight_graph_v1/20260915/diagnostic/variances.csv) · [96组相关](../results/ootang_overnight_graph_v1/20260915/diagnostic/correlations.csv) · [触发记录](../results/ootang_overnight_graph_v1/20260915/diagnostic/decision.json)。

**借鉴原论文与创新边界**

Wang等原文使用GRU、空间图及分量预测；四点沿用分区内连边时，主要留下MJ3—MJ1这条边。本轮借鉴这种信息组织，用固定等权小图隔离点间传递的作用，没有复现原文八点加权图或借用其成绩。[原论文方法与讨论](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2025JH000592)。

我们保留B+完整状态和合法历史教师，检验神经残差的空间增量与概率表现。这是研究问题和验证方式上的区别；GRU、图卷积、EMA或它们的组合本身不宣称原创。当前结果也不能证明“充分保留历史”已经解决，更没有确定记忆长度就是误差瓶颈。

**怎样理解、怎样收尾**

本轮给定未来逐日降雨/库水位，每条293日路径无实测位移反馈；612日前缀只用于校准启动，主要比较792/972/1168。972教师沿用792日参数；窗口部分重叠、日期已有暴露，全部属于探索性条件预测。训练归一化只用当前前缀，90条成熟误差校准后整条路径区间固定；原数据as-of、预处理及物理优化未收敛限制保持。历史图只画实测和B+，没有伪造GRU训练重构。

301项来源、96检查点和11110304项数值独立核对通过；六页24面板、70346图形值、PDF字体/对齐/碰撞与逐页目视通过。初版图件注释碰撞及修订记录保留，科研训练未重跑。实现核验、效果判断和用户/导师验收分开：前两项已完成，尚未获得用户/导师验收。

本轮到此收尾，不继续增加网络、λ或RL搜索。下一次讨论应围绕一个能区分原因的新假设，而不是仅凭模型名称更换架构；当前证据不足以推荐新主模型。已在北京时间09:00截止前提前结束，各步本地commit，未push。详细[冻结计划](ootang_overnight_graph_plan.v1.0.md)、[实现与核验](ootang_overnight_graph_validation.v1.0.md)、[最终回执](../results/ootang_overnight_graph_v1/20260915/final_receipt.json)保留复盘依据。

## 3. 固定计算及验证预算

主诊断及一次封存只读复核**各自**最多且预期恰为：36 次完整网络调用、72 个
编码/预测序列段、30,240 cell 样本步、25,920 读出样本步、30,240 独立 NumPy
cell 样本步；0 梯度/更新/物理/拟合。每次使用 CPU 单线程、float64，硬超时 120 秒，
无自动重试。主诊断在这一次计算中完成原 CARRY 回放、NumPy 参考及代数核验，
不另增一轮网络核验；封存复核再完整执行一次，预算单独记录。

原均值、两条修正及独立 NumPy 递推采用 atol=1e−8 mm、rtol=0；两条差值的
参考误差上限为 2e−8 mm。该上限只用于数值核验，不能当作预测有效性门限。
保留实际小量与零，低于此参考门限的差异不宣称已得到独立实现分辨。
保存表格使用 float64 往返读取及严格比较，不用绝对容差把极小状态影响吞成零。

输入/权重/旧产物哈希保护，检查原成功终态及其封存核验记录，不重跑旧训练。
主诊断与封存复核核对全部 18 组数组、18 checkpoint、输入身份、输出锁/标签时间、
逐日/分段记录、均值指标及代数恒等式。相关合成检查包含同权重 S0 边界、未来
递推保持、基线加法消去小量、完整覆盖/组件平均、方向零值、独立标量误差、
时间锁、预算提前拒绝和微小值篡改拒绝。科研记录、日志、源码和图表全部保留。

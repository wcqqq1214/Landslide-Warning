## 明确假设

从 `ridge.fit_distribution` 源码可见，当前尺度目标使用均值模型自身训练查询上的误差。这不是实现错误，但可能低估真正预测误差。C3 开发曾在均值改善的同时覆盖不足，足以支持检验这一训练目标差异；不把后期缺少几个覆盖日作为调尺度的目标。

唯一主要变化：**均值和全部概率反馈规则保持，尺度改用按历史前缀拟合模型产生的预测误差训练。** 不增加尺度参数、不修改下限/边界、不扩大反馈步长、不搜索超参数。

内部阶段（训练截止 612）使用前两折，共 212 个查询；开发阶段（截止 792）使用三折，共 363 个查询。查询不跨折终点，29 日起点空缺由固定完整步长约束产生，不由误差或覆盖决定。四点全部保留，每个查询等权。

342/432 日的 FULL/DATA 辅助均值模型各拟合一次；612 日复用 C3 已保存的 alpha=0.001 模型。辅助模型沿用现有拟合接口，会保存其同时产生但不用于本候选的尺度及优化记录，所有调用计数，不将该尺度混入新目标。辅助模型只见其前缀标签，物理教师前缀也必须早于起点。

alpha 统一固定 0.001，沿用既有内部选择，不重新挑 alpha。这是条件于已确定超参数的均值系数交叉拟合，**不是额外完成了一次嵌套、完全未暴露的超参数验证**。该限制需随结果保留。

内部/开发的主均值分别完整复用 C3 的 612/792 日选中模型，beta、特征尺度、目标尺度保持精确相等。仅用对应历史预测误差重新估计原两个尺度参数：

`sigma² = (a_point * target_scale_h,point)² + (b_point * q_h,point)² + 0.01²`。

NLL 目标、初值、边界和优化容差沿用 C3；误差和 q 按当前主均值模型的目标尺度规范化。另保留同均值、原样本内尺度的 IN_SAMPLE 对照，双方都使用 C4 的 RMS + 已兑现覆盖反馈；同阶段固定基线分布也保持一致。

# 统一接口骨干×起点表达：图件约定 v1.0

制图前形成，训练及评分已锁定；全部图仅绘制保存数组。沿用本任务Python/Matplotlib，不更换后端。只输出PNG/SVG；同源临时PDF仅作字体/碰撞QA，不交付或提交。

1. 问题与核心结论：起点表达能否迁移，以及统一条件下GRU/Transformer有何差异？已核验结果支持平均误差的跨骨干改善；A开时本轮GRU优于TF，但最终仍未过B+联合目标。旧半残差最终局部优势必须可见。
2. 总览为2×2定量网格：a全293日RMSE说明收益和B+差距；b起点表达在两个骨干内的配对RMSE差说明迁移；c TF−GRU在原样/起点表达下的配对差说明骨干差异及条件；d全窗CRPS约束概率结论。主点为三种子平均预测后评分，浅色小点保留所有种子及同种子差，不画虚假的独立重复置信区间。
3. 总览方法预定为B+、仅起点校正B+、DRIFT1、旧半残差、G00/G10/T00/T10；其余旧对照在完整36行结果表及逐点表保留，不是删除候选。四组各提供最终8:2完整时间轴四点图，80/95%边际区间和三种子均显示。历史两个窗口完整指标/数组另存，不制造神经训练段拟合。
4. 采用导师式2×2测点排列、实测黑、B+灰虚线、浅蓝历史/浅橙预测背景、网格、无图顶箭头。四组均提供导师固定纵轴版及共同完整范围版；固定范围引用既有测点显示规则，所有均值/观测/区间越界日数明确计数，评分不裁剪。同一点完整范围在四组间相同，包含所有种子与完整95%区间。
5. 每幅240×170mm，300dpi PNG、可编辑SVG，字形≥7pt。数据只减初始位移、不平滑/删尾/挑种子。字段映射method=冻结模型身份，origin=实际预测起点，seed=算法随机种子，mean=种子平均预测，sigma=本方法上一条已发出路径91—180日误差RMS。统计解释与预测协议不继承旧B采样因素标签。
6. 导出前每图1.5pt面板对齐/文字边界门；导出后从原CSV/数组到实际SVG路径逐项核验、渲染字体/碰撞核验，并逐面板和整图目视。旧曲线模板仅结构适配；总览配对面板按新网络×A问题重建，不继承旧因子定义。若显示越界，固定版不能代替完整范围版。

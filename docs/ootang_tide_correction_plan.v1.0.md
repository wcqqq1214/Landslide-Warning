## 固定比较

- `TiDE_KIN`：精确复用原四起点、三种子e400的均值/种子路径，模型/标准化均冻结，不进入校正器优化器。
- `TiDE_CAL`：原KIN加小校正器；校正器仅使用相对预测距离、known标记和点ID，H三列在标准化后清零。
- `TiDE_HCAL`：与CAL同结构/初始化/样本/目标/单位/预算/上界，额外读取合法H三列（含水状态、两类水头）。共同K/降雨/水位仍在冻结KIN内，CAL不等于无水文信息。

校正器沿用上轮H支：特征5→8→1，474时刻展平及4维点ID后478→8→8，解码8→8→294，4×4点嵌入，共13179可训练参数；冻结基模型110392参数。seed+10000初始化末端两仿射为零，e0精确回退原KIN。h0起点化，最终输出`KIN_mm + cap_mm*tanh(q(h)/cap_norm)`，其中q为单位归一化的起点化校正、cap_norm=cap_mm/unit。每点cap仍为当前前缀全部30日位移变化RMS、下限1mm，不扫描上界。只限制附加项，不能保证总位移、单调性或B+方程。

固定float64/CPU单线程，Adam .001，种子0/1/2，8起点/批，400更新，保存0/50/100/200/400，无选模。监督为每个种子对应的训练外KIN预测误差，293日/四点等权后再按起点等权；同seed两个校正器使用完全相同抽样。原B+、起点B+、DRIFT1、RR_COND、G_CACHED、DATA/HYD/PHYS/SPLIT/BOUND十个对照完整保留，共十三方法。

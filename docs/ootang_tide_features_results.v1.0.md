# TiDE物理特征分组研究记录 v1.0

固定2×2消融、全部训练和独立核验已完成。**TiDE仍有可研究的改进空间，但物理特征的收益依赖时段与组合，尚未找到四点跨窗稳定优于B+的版本。** 本轮保存研究记录和曲线，不制作导师汇报。所有窗口均属探索性，内部核验与用户/导师验收分开。

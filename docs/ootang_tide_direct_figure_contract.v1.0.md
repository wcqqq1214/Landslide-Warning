# TiDE小试图件合同

用途为保存可核查的研究曲线和失败模式，不制作导师汇报或投稿包。沿用已经确定的Python/matplotlib工作流和nature-figure数值/布局核验；240×170mm，300dpi PNG与可编辑文字SVG，不交付PDF。临时同源PDF只作字体/碰撞检查。

问题：物理输入能否使此TiDE适配跨时段稳定改善？主结论是平均误差收益与逐点/概率达标仍有差别。三张quantitative grid图：比较图a列三个完整293日窗口的七方法平均RMSE；b列物理减纯数据的集成差和全部配对种子，检验方向稳定性；c列最终逐点RMSE，定位均值保护失败；d列逐点90%覆盖，防止只谈均值。另两张四点图展示两个候选完整路径、三个种子及原80/95%高斯边际区间，保留末段偏差。

沿用既有研究曲线脚本的结构，字段映射为origin→固定612/792/972/1168、method→本轮七方法、seed→0/1/2、point→ATU1/ATU5/MJ3/MJ1、metric→原mm/覆盖评分。原教师配对变量改为TiDE_PHYS减TiDE_DATA；既有G_CACHED单独保留为对照。全部数据来自已发报锁定的数组与独立核验CSV。共享纵轴完整容纳两臂种子和95%区间，不抽样、平滑、裁剪或补画神经训练重建。累计位移显示仅减原首日观测，误差不改变。

保留全部点/日期/种子，无独立重复或显著性声明；窗口重叠且已暴露。较高覆盖须结合区间宽度，区间不是同时覆盖。三图分别验证科学数组、实际SVG坐标、1.5pt轴对齐、最小5pt字形、碰撞与逐面板目视，失败初稿保留并只修绘图。用户/导师验收与内部核验分开。

## 1. 执行结论

1. **高程可以增加模型结构的物理合理性，但不能仅因模型是 ConvLSTM 就自动增加预测可信性。** 当前静态高程通道向网络提供了坡体上下部和测点位置的地形先验，能够与位移及水位、降雨通道共同参与卷积门控；它不增加新的位移观测，不解决上游日序列血缘，也不等同于力学约束。
2. **当前结果没有证明高程改善预测。** 在完全相同的 `11,400` 个 `(date, station, split)` 键、观测值和 persistence 基线下，单种子 test 总体 RMSE 由无高程快照的 `0.3182 mm` 增至高程版本的 `0.3378 mm`，MAE 由 `0.1585 mm` 增至 `0.1743 mm`。8 个测点中没有一个 RMSE 改善，只有 ATU1、MJ9 的 MAE 微幅改善。
3. 以 14 日非循环重叠日期块进行 `1,000` 次配对重采样，高程版相对无高程版的 RMSE 差值中位数为 `+0.0185 mm`，95% 百分位区间为 `[+0.0102, +0.0274] mm`；MAE 差值中位数为 `+0.0154 mm`，区间为 `[+0.0067, +0.0246] mm`。这是**已查看 test、单种子、事后审查**，不能当作确认性显著性检验，但足以否定“当前高程版已经显示性能提升”的表述。
4. **400 个 `candidate_not_site_confirmed` 均不是测点缺失。** 这些日期全部具备 8/8 测点、3/3 分区和四项有效指标；它们都因 yellow 及以上证据只出现在 O1，未达到“至少 2 点且至少 2 个空间分区”的滑坡体门槛。
5. 400 日中有 `189` 日同时不足 2 个 yellow+ 测点，另有 `211` 日已经达到至少 2 点但仍只位于 O1，纯粹受跨区门槛阻断。候选严重度为 yellow `196`、orange `94`、red `110`。
6. **400 日的高等级完全由区间偏离指标决定。** 对应 `755` 条 O1 yellow+ 测点记录中，候选等级 `755/755` 与区间等级相同，`0/755` 由运动学等级决定。它们不能被解释为“速度已经达到相同的黄/橙/红等级”。
7. 当前 514 个滑坡体日期中 green 为 `0`。这不是代码漏行，而是“任一测点 blue 即滑坡体 blue、green 要求 8 点全部 green”的组合结果。由于逐点区间 green 定义为 `actual <= p50`，该规则对“绿色为正常状态”的滑坡体输出过严，必须在下一版本中重新冻结 blue/green 的空间语义。
8. 发现一个当前数据未触发的实现缺陷：`minimum_assessable_station_count=3` 只在 green 分支生效；合成情况下仅 2 个有效、跨区 yellow 测点也会返回 `valid yellow`。如果“至少 3 个有效测点”是全局覆盖门禁，必须在所有颜色判断前执行。

因此，本轮最准确的表述是：

> 高程已作为静态地形先验进入 ConvLSTM，使空间输入更符合坡体地形差异；但当前单种子、已查看 test 的结果没有显示预测精度提升，且高等级状态仍由 O1 区间失配主导，所以尚不能声称高程提高了经验预测可信性或预警可靠性。

## 3. 指定 Word 究竟怎样“物理引导”

指定 Word 第四章的做法与当前高程通道有三项本质区别：

1. 其物理信息来自 GeoStudio `SEEP/W + SLOPE/W` 的渗流与稳定性计算，再将稳定性系数 `Fs(t)` 通过 Vulliet–Hutter 半经验关系转换为位移速率或物理位移。相关说明位于 Word 渲染页 63、65（正文页 53、55）。
2. 其空间模型为 GCN、T-GCN（GCN+GRU）和 ST-GCN（GCN+1D 时间卷积），不是 ConvLSTM。相关结构位于渲染页 69–71（正文页 59–61）。
3. 其监测点邻接矩阵主要由位移序列 Pearson 相关构建，并明确指出单纯空间距离存在局限；没有把测点高程作为静态神经网络输入。相关说明位于渲染页 67（正文页 57）。

该 Word 确实比较了“有/无物理模型”的结果，并报告加入物理位移后部分模型和测点 RMSE 降低、区间变宽；相关结果与讨论位于渲染页 78–83（正文页 68–73）。这能支持：

> 经过明确定义且经过对照实验的物理信息，有可能同时改变点误差与不确定性表达。

但它不能支持：

- 静态高程就是该论文的“物理模型”；
- 使用 ConvLSTM 就自然获得物理可信性；
- 高程在任何数据集上必然改善误差、区间或预警；
- 当前 8 点 IDW 高程通道复现了该 Word 的物理引导。

因此，论文写作中应把当前方法称为“**高程感知的时空数据驱动原型**”，不能称为“复现指定论文的机理引导模型”。若未来要使用“物理引导”这一更强表述，应加入可计算的渗流、稳定性或水文—力学状态量，并单独验证约束是否成立。

## 4. 当前高程通道的专家判断

### 4.1 可以增加什么

- 高程是静态地形属性，可向卷积门控提供坡体上、中、下部的空间位置先验；
- 对同一时刻广播的 RWL、降雨等全局外生量，高程通道允许网络学习“同一触发量在不同坡位可能产生不同响应”的交互；
- O1/O2/O3 的平均高程依次约为 `316.7/356.7/462.5 m`，与下部—上部空间分异方向一致；
- 相比只把 8 点位移 IDW 到规则网格，高程至少让网格拥有一个可解释的静态地形字段。

Wang 等（2025）的藕塘研究也报告不同分区的主控因素不同：近河 O1 更受 RWL 影响，较高位置的 O2/O3 对温度和降雨表现出不同响应；但该文通过分区图结构、环境因子和注意力分析表达这种差异，并未把高程作为输入，也明确指出其模型缺少显式物理约束。[期刊原文](https://agupubs.onlinelibrary.wiley.com/doi/10.1029/2025JH000592)

### 4.2 不能增加什么

- **不能增加观测独立性。** 8 个高程值经 IDW 扩展到 `4×7` 网格仍只有 8 个源值，不是新增 28 个地形观测。
- **不能修复位移数据血缘。** 高程不解决发布日序列可能含自然月内插结构、原始测量误差和未知日值生成链。
- **不能自动提供因果机制。** 高程是几何协变量，不是孔压、抗剪强度、稳定性系数或滑面力学状态。
- **不能单独证明泛化。** 当前只有一个滑坡、8 点，且高程与平面位置高度相关：在这 8 点上，`corr(x,elev)≈-0.787`、`corr(y,elev)≈-0.773`。网络可能把高程当作站点/分区身份编码，而不是学习可迁移的高程效应。
- **不能因为 ConvLSTM 而免除消融。** ConvLSTM 只规定怎样编码时空张量；输入是否有用仍要由受控对照、跨时期稳定性、校准和外部数据决定。

### 4.3 当前证据判定

| 可信性维度 | 当前判定 | 理由 |
| --- | --- | --- |
| 输入结构完整性 | 支持 | 高程确实进入第 2 个静态通道，清单和模型输入可核验 |
| 地形表达合理性 | 谨慎支持 | 高程方向与坡体分区相容，且未任意并入三维距离 |
| 预测精度提升 | 不支持 | test RMSE/MAE 均比无高程单种子快照差 |
| 概率校准改善 | 不足 | 未完成同范围、多种子、滚动的 6/7 通道受控比较 |
| 可迁移物理机制 | 不支持 | 单坡体、8 点、坐标/高程混杂，且无显式力学约束 |
| 正式预警可信性 | 阻断 | 区间是观测后状态识别，V0/稳定段仍为草案，缺真实事件标签和确认性数据 |

### 5.3 指标成因

755 条 O1 yellow+ 测点记录中：

- interval+kinematic 双证据族：425；
- interval-only：330；
- `ΔV>0`：201；
- `ΔV<=0`：554；
- 候选等级等于 interval 等级：755；

> 观测位移相对模型预测中位数的右侧偏离等级，经多测点空间规则确认或拒绝；不是同等级速度阈值、切线角和 `ΔV` 的共同结论。

## 7. 规则与代码审查

### 7.1 已正确实现

- 四项输入均要求 valid；
- 速度与切线角取最大后只构成一个运动学证据族，没有双重计票；
- 测点候选为 `max(interval, kinematic)`；
- `ΔV` 只标注 accelerating/not_accelerating；
- yellow–red 要求至少 2 个支撑测点且跨至少 2 个分区；
- 未空间确认的 yellow–red 不会静默降为 blue 或并入 green；
- 每条输出保留测点、分区、候选和确认理由。

### 7.2 P0：有效测点门禁没有作用于非绿色分支

[`operational_v2_fusion.py`](../code/warning/operational_v2_fusion.py) 第 365–367 行只计算 `coverage_complete`，但第 396–487 行在 yellow+ 和 blue 返回前没有检查它。合成反例为：

```text
仅 MJ9(O1) 与 ATU4(O2) 两点有效且均为 yellow
其余 6 点 invalid
当前函数仍返回 valid yellow, coverage_complete=false
```

建议：

1. 将 `minimum_assessable_station_count=3` 解释为所有滑坡体颜色的全局门禁；
2. 同时要求至少 O1/O2/O3 各有 1 个可评估点，才能输出任何完整滑坡体颜色；
3. 覆盖不足时仍保留局部候选，但状态必须是 `insufficient_assessable_coverage`；
4. 增加上述 2 点跨区 yellow 反例测试，以及 3 点覆盖三个分区的边界测试。

这项修复不会改变当前 514 日结果，因为本轮始终为 8/8 点、3/3 分区有效。

### 7.3 P0：滑坡体 green/blue 语义不符合“绿色为正常状态”

当前：

- 只要任一测点最高为 blue，滑坡体就直接 blue；
- 只有 8 点全部 green 才能输出滑坡体 green；
- 514 日实际 green `0`。

推荐下一版采用双轴输出：

```text
site_confirmed_level      = 滑坡体跨区确认等级
local_max_candidate_level = 局部最高候选等级
```

并冻结以下原型规则：

1. 任何 site 颜色先通过“至少 3 点且三个分区均有有效点”的覆盖门禁；
2. blue 也要求至少 2 点、至少 2 区的 blue+ 支撑；
3. 没有跨区 blue+、也没有单区 yellow+ 候选时，滑坡体可为 green；孤立 blue 另记 `localized_blue_attention`；
4. 单区 yellow–red 继续保留 `candidate_not_site_confirmed`，不得并入 green 或降为 blue；
5. yellow–red 继续使用当前 2 点、2 区确认；
6. 无论最终 site 色为何，都保留局部最高候选、测点和分区。

这是项目特有的透明规则建议，不是指定 Word 已给出的公式；若执行，应生成新的 v3 草案而不是覆盖 v2。

### 7.4 解释边界

- 区间指标把已经发布的预测与随后得到的同一时刻观测比较，属于**观测后覆盖/偏离状态识别**，不是严格的未来 onset 预警；
- 31 个 valid yellow 日全部还存在局部 orange/red 候选，论文图表必须同时显示全体确认色与局部最高候选；
- 任何 orange/red 都不能写成“速度与切线角达到 orange/red”，因为当前运动学最高仅 yellow；
- 400 日未确认状态不能按误报率、召回率或 400 次预警事件解释，因为没有独立事件真值。

## 8. 下一步建议

### 8.1 当前藕塘原型应先做

1. 修复全局有效测点门禁并补反例测试；
2. 将 green/blue 的滑坡体规则改成双轴 v3 草案，保留 v2 快照；
3. 生成典型日图时同时画出：
   - 逐点 interval/kinematic/`ΔV`；
   - `site_confirmed_level`；
   - `local_max_candidate_level`；
   - 支撑测点与 O1/O2/O3；
4. 对当前结果统一使用“区间偏离状态”“局部候选”“跨区确认状态”等术语，不使用“正式预警成功”；
5. 不启动 Vajont。

### 8.2 当前藕塘原型暂不做

- 不依据已查看 test 调节高程权重、IDW、网格、网络容量或阈值；
- 不把 6/7 通道单次比较包装成消融结论；
- 不因高程版误差变差而删除高程；它仍可作为导师要求的结构输入保留；
- 不把指定 Word 的物理模型结论转嫁到当前静态高程通道。

### 8.3 最终可追溯数据集上的确认性方案

若论文最终更换数据集，应在查看最终 test 前冻结：

1. 6 通道基线；
2. 7 通道常数零通道容量对照；
3. 7 通道真实高程；
4. 7 通道打乱高程—测点对应的负对照；
5. 相同滚动折、相同种子、相同停止规则和相同概率指标；
6. 点误差、区间校准、事件提前量、误报/漏报和空间一致性共同评价；
7. 若要使用“物理引导”，再加入可解释的水文—力学状态量或损失约束，并逐项做有/无物理信息对照。

只有真实高程稳定优于零通道和打乱通道，并在多个时期/种子及独立事件上保持方向一致，才可以把“高程提高可信性”升级为经验结论。

## 9. Statistical Findings and Warnings

### 9.1 主要统计发现

- 当前高程版相对 persistence：RMSE `0.3378/0.3403 mm`，skill `0.0073`，优势极小；
- 当前高程版相对无高程快照：RMSE `+0.0196 mm`、MAE `+0.0158 mm`；
- 配对 14 日块重采样的差值区间均在 0 以上，但由于 test 已被查看、只有单种子且没有重新抽取训练过程，只可视为当前快照的稳健事后描述；
- 400 日全部集中 O1，说明聚合总数不能替代分区诊断；
- 514 日无 green，说明等级频率受到组合规则结构性控制，不能按风险基准率解释。

### 9.2 十一项推断谬误扫描

| 检查项 | 结论 |
| --- | --- |
| 1. Simpson's paradox | **风险存在**：总体略优于 persistence，但 ATU2/ATU3/ATU4 不优；总体数值会掩盖逐点差异 |
| 2. Ecological fallacy | **风险存在**：滑坡体颜色不能反推每个测点均处于同一等级 |
| 3. Berkson's paradox | **需警惕**：只有一个已发表筛选数据集和 8 个代表点，样本选择机制不完整 |
| 4. Collider bias | **未形成可检验因果模型**：不作无依据的因果调整，因此不宣称已排除 |
| 5. Base-rate neglect | **风险严重**：没有独立滑坡事件真值，不能计算或推断实际报警准确率 |
| 6. Regression to the mean | **未发现直接设计触发**：本轮不是按极端值选日前后比较，但典型日展示不可代替全时序统计 |
| 7. Survivorship bias | **风险存在**：仅使用公开包中的 8 个代表点，未知未公开/废弃测点 |
| 8. Look-elsewhere effect | **风险存在**：test 已参与多轮查看，任何事后挑选的高程方案或代表日都不能作确认性发现 |
| 9. Garden of forking paths | **风险存在**：网格、IDW、高程编码和规则均有多个可选路径；当前版本应冻结，不按 test 继续分叉 |
| 10. Correlation is not causation | **风险严重**：高程与位置/分区相关，静态高程通道不能证明高程因果作用 |
| 11. Reverse causality | **主要风险较低**：静态高程先于位移，但这不消除位置混杂、数据选择和模型失配 |

**Fallacy scan：11/11 completed。**

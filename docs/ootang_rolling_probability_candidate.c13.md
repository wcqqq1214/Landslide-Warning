## 为什么回到均值关系

[冻结误差核对](../results/ootang_rolling_v3/20260913/fourth_review_evidence/signed_errors.json)显示：C8 DATA 后期偏差不是四点一致的恒定单侧偏移。相邻 h30 误差高度相关，但当前起点不能知道前一天尚未兑现的 30 日目标；真正可用的最近同任务误差相隔 30 个起点，描述相关方向不同。这不直接证明可以学好，但明确了一个已有特征未直接表达的输入：**过去真实发出并已经兑现的预测误差**。

目前 C8 用近期位移差异和物理变化特征学习均值；尺度层使用过去误差的平方与覆盖指示，没有把成熟误差的符号及其与未来偏差的关系输入均值回归。新候选只检验这一学习关系，不在全段先拟合自相关系数，不按事后相关符号预设正负。

[FPP3 残差诊断](https://otexts.com/fpp3/diagnostics.html)说明残余相关可提示未利用信息，但本次是多步预测误差且有重叠，不能直接套用其单步创新残差判断或承诺未来改善。正则目标使用 [Ridge 官方定义](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)的平方误差加 L2 惩罚；这里只核读相关公式/解释，不声称文献证明本候选在藕塘有效。

## 信息时序与固定三臂

核心统一为原 C8_ONLINE_DATA，属于机器学习，均值和概率尺度从已核验原件读取。B+ 和 DRIFT14 的参照误差同样来自当时真实发出的保存预测。全部原 C8 对照不变，C13 的新增收益必须对同核心比较，不把原 DATA 均值优势归功新误差头。

定义原模型 a 在起点 r、步长 h 的兑现误差为：

```text
e_a(r,h) = y[r+h-1] - mu_a(r,h)
z_a(r,h) = e_a(r,h) / sigma_a(r,h)
```

起点 n 只见 y[0:n]，最近已兑现的同 h 预测由 r=n-h 发出，其目标为 n-1。输入是该预测**当时的**标准化误差，不用当前尺度回算旧误差。

- 主候选 `C13_INNOV_PHYS`：`f=[z_core(n-h,h), z_B_ANCHOR(n-h,h)]`，两维。
- 配对 `C13_INNOV_TREND`：第二维换为 `z_DRIFT14(n-h,h)`，两维，同复杂度。
- 消融 `C13_INNOV_CORE`：仅第一维，一维，说明是否只靠核心误差记忆起作用。

三臂均按全四点、全步长、完整日期运行，不拼点。B+ 只作为实测兑现后的误差参照，不解释成独立物理观测或力学机制。阶段开始时没有此前阶段的保存起点，故不补造误差输入；可用前令 f=0、修正为 0，未具备有效输入的样本不更新学习器。

## 在线回归和概率输出

每点每步长单独学习 beta，初始化 0，固定 alpha=1、无截距、不遗忘、不截断系数；不搜索 alpha、记忆阶数或窗口。所有特征和目标使用已发尺度无量纲化，alpha=1 是零修正单位 L2 正则的事前选择，不由开发/后期选出，也不冒称唯一正确值。

```text
response(r,h) = e_core(r,h) / sigma_core(r,h)
beta = argmin_beta sum_mature (response - f.T*beta)^2 + ||beta||^2
G = I + sum_mature f*f.T
b = sum_mature f*response
mu_C13(n,h) = mu_core(n,h) + sigma_core(n,h) * f(n,h).T*beta
sigma_C13(n,h) = sigma_core(n,h)
```

监督样本的 f 必须是该样本预测发出时保存的 f；只有其目标 r+h-1 小于当前起点后才追加 G/b。先用旧 beta 预测并锁定，再释放新观测并更新。对同 h，第一次有效输入在阶段内起点索引 h，第一次有效更新在索引 2h-1 的目标兑现后发生。禁止用当日刚释放标签反写之前发出的均值。

输出为真实高斯，其标准差固定等于 C8 DATA 已校准尺度。旧核心反馈基于旧核心误差，本候选不把它改称基于新均值重新校准的结果；所有区间宽度不变，只有中心随新学习修正移动。因此改进不能靠放宽区间实现，也不预先保证覆盖。保存原核心均值/尺度、全部 f、beta、可用标志、修正、G/b 和最后更新目标。

两阶段三臂预计新增 **219,240 次点位小矩阵求解**：开发 124,560、后期 94,680。按 `3*4*sum_h(N-2*h+1)` 计算；零新初始均值拟合、尺度优化、神经更新和物理调用。该计数与旧 Ridge/混合权重分别记录。

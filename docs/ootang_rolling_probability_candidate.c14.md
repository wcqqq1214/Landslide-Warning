## 已验证事实与新假设

C13 独立核验通过但三臂效果明显退步。[不读取标签的尺度核对](../results/ootang_rolling_v3/20260913/c13_normalization_audit.json)和[复算脚本](../scripts/audit_ootang_error_units.py)表明，C13 核心误差项代数上为：

```text
beta * e_core(n-h,h) * sigma_core(n,h) / sigma_core(n-h,h)
```

后期 h30 的尺度比最大值四点分别为 15.2751/8.0600/14.2329/3.3823。仅核心误差对照在 ATU1 的最大绝对均值修正为 148.0625 mm。两个最大值不声称发生在同一天；该事实说明单位还原随时间变化，**不单独证明它是全部失败根因，也不证明固定尺度会成功**。

第四次复盘描述的是毫米误差关系；C13 实际学习每次已发尺度标准化后的关系，又乘当前尺度还原。C14 只检验将这一单位约定固定后，已兑现误差能否产生有用的均值修正；不换滞后阶、不裁剪输出、不调 alpha 或概率覆盖倍率。

## 唯一主要变化及固定数值

全四点、全部步长三臂仍为核心+B_ANCHOR、核心+DRIFT14、仅核心，分别命名 C14_INNOV_PHYS、C14_INNOV_TREND、C14_INNOV_CORE。原核心 C8 DATA、所有 C8/C13 输出原样保留。主候选仍 PHYS，不按点或阶段更换。

每个阶段起点 s，在读取阶段新标签前，固定各参照 a、步长 h、点位 p 的单位常数：

```text
c_a(h,p) = sigma_a(s,h,p)
f_a(n,h,p) = e_a(n-h,h,p) / c_a(h,p)
response(r,h,p) = e_core(r,h,p) / c_core(h,p)
mu_C14(n,h,p) = mu_core(n,h,p) + c_core(h,p) * f(n,h,p).T*beta(h,p)
```

常数取自第一份合法已发预测，因果可用、严格正值，阶段内不变；它只作数值单位，不是新估计的测量噪声，也不声称这是最优缩放。没有使用开发/后期标签选常数。仅核心臂的还原变为 `beta*e_core(n-h,h)`，不再乘随日期变化的尺度比。

依旧最小化 `sum(response-f.T*beta)^2+||beta||^2`，alpha=1、无截距、零初始、不遗忘，且仅追加已成熟且输入可用的监督。固定单位同时改变训练样本的相对加权和还原方式；因此这是两种完整单位约定的比较，不把任何差异只归因于最后一次乘法。原 C13 源码快照与配置保持。

预测标准差始终为对应起点的原 C8 DATA sigma，实际 80/90/95% 区间宽度保持；固定常数不替换概率尺度。保存所有常数及其第一起点来源、完整特征/系数/修正和状态。旧 C13 分布按真实高斯评分，不重算其误差头。

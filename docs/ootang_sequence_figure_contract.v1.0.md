# 本轮图件约定

目的：让导师直接比较两个固定新结构在四个测点的训练拟合、完整 293 日条件预测及区间，核对是否接近实测并优于 B+。图本身不先验承诺收益，最终判断由同窗完整评分支持。

使用 Python/matplotlib；沿用本任务已确认的 Python 后端和用户所给四点 2×2 布局。类型为 quantitative grid，每点对应剖面不同位置的重复核对，四点全部展示；不强行改变为主图/附图层次。
四个新模型各一张 1461 日图，另有一张九方法完整预测窗对比。单模型图显示黑色实测、灰色 B+、一条三种子等权均值及预测期80/95%高斯边际区间；比较图只显示均值以避免九重区间叠加，其不确定性定义与各配套图及CSV一致。

字段映射：日期→横轴完整日历；原位移减同一原始首日 y0→纵轴mm；完整训练/预测数组→模型线；每点固定RMS90误差尺度→预测期区间；最终逐点RMSE→轴外统计注记。
所绘 1461 日只分训练1168/预测293，无删日期；预测比较图293日全部保留。重训模型拟合段没有独立概率区间，不用预测误差带冒充拟合段不确定性。
复用既有同协议绘图源码属于结构适配，导师提供图片仅作布局样式依据，不继承图中QRF身份、曲线或数值。

输出为240×170mm、300dpi PNG和可编辑文字SVG，中文无缺字；对比图图例两行，颜色配合线型区分。蓝/橙背景标记训练/预测期。轴外RMSE注记避免遮盖曲线，必须通过实际1.5pt面板对齐与文字几何检查、SVG图元对源数组核验和五张整图逐面板目视。
区间为逐点边际预测区间，不是三种子置信区间，也不是整条路径同时覆盖保证。三种子是算法重复，不当作三个独立滑坡样本；不提供p值或显著性标记。
源数据、绘图代码、数值注记、导出尺寸/字体/图元审计均保存。用户明确不制作PDF，因此PDF导出及仅适用PDF的审计不运行；静态源检查不能代替本轮实际SVG/PNG几何核验。

## 2. 零训练诊断

- 重载两模型×四前缀612/792/972/1168×三种子×e0/50/100/200，共96检查点。
- 每个前缀n固定128个伪起点：`m_i=432+floor((i+0.5)*(n-432)/128)`；每起点32个距离：`h_j=1+floor((j+0.5)*min(293,n-m_i)/32)`。这是uniform训练分布的确定性分层近似；小支持区间可重复距离，32槽位等权，各起点等权，不冒充独立样本或验证集。
- 所有检查点、骨干、种子用同一面板。教师拟合前缀≤m，历史位移仅取m之前，目标下标m+h−1<n。标准化沿用当前训练前缀n，不能称为伪起点当时独立拟合的预处理。
- 保存逐样本归一化输出q、目标t，逐点/种子MSE、正则项Q、总目标J=MSE+Q、固定面板梯度范数。梯度仅诊断，不创建优化器或更新权重。
- λ=1时核对恒等式`J=2*mean((q−t/2)^2)+0.5*mean(t^2)`；下界只是假设可逐样本自由输出的代数下界，不是当前有限网络必能达到的最优值。MSE与正则项分列，不能把惩罚下降当作位移拟合改善。
- 历史外推诊断仅用截止1168日已完整兑现的既有293日路径：612→905、792→1085。每个检查点读取原保存预测，用三种子均值及逐种子/逐点评分。它们是相应模型训练前缀之外的预测，但此前已暴露、两窗重叠113日，并非独立重复。
- 972完整路径到1265尚未在1168成熟，因此不进入触发判定；最终1168→1461也不进入。两者不被截短、重评分或拿来倒选旧训练次数。本轮零训练阶段解析位移标签最多前1168行；训练面板与历史验证角色分别保存。

## 3. 在看诊断前固定的触发规则

只比较**e100→e200**，e0/e50提供完整曲线背景，不选择曲线中最优点。对Transformer起点版要求以下条件全部成立：

1. 训练支持：四个前缀中至少三个，各自至少2/3同种子在固定面板MSE和J均降低≥1%。
2. 历史平均支持：两个合法历史窗的集成四点平均MAE、RMSE再按窗口等权平均，均降低≥1%。
3. 历史保护：每个历史窗的集成平均MAE、RMSE均不退步超过5%；每窗至少2/3同种子的四点平均MAE、RMSE同时降低。

百分比使用e100作分母，分母保护1e−15；严格降低用于种子方向。1%/5%仅是本次有限诊断的工作条件，不是显著性阈值，也不替换旧效果门。GRU用同一规则完整报告，但单独通过不触发新训练。未触发只能说明没有达到本次追加依据，**不能由此证明优化已充分收敛或Transformer家族无效**。

触发JSON先锁定并独立复算，再允许条件入口读取。未触发则新增拟合/更新为0，完成图表与结论后停止。

旧检查点没有Adam状态。为保持严格可复现，从原初始化重放原200步，在所有参数和预测匹配后保留本次Adam状态追加200步。随机抽样按两个200步块串接：第一块必须与原保存schedule完全相同；第二块由同一随机数发生器在原全部抽样之后继续产生，避免直接改`updates=400`导致旧前200步样本改变。

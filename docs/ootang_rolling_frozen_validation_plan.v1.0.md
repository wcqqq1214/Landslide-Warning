## 3. 概率项审查：明确尺度对应与假设

对每个起点 n、步长 h、点位 p，按源码逐项还原：

\[
\mu_{16}=\mu_{8}+u x^\top\hat\beta,\qquad
A_n=I+\sum_{j\in\mathcal M_n}x_jx_j^\top,
\]

\[
\sigma_{18}^{2}=\underbrace{\sigma_{8,\mathrm{cal}}^{2}}_{\text{C8 的误差校准尺度}}
+\underbrace{u^{2}x^\top A_n^{-1}x}_{\text{新增误差头的方差近似}}.
\]

其中 \(\mathcal M_n\) 只含起点 n 前监督已成熟且输入合法的已发预测；u 是固定响应单位，不是新估计的测量噪声；x 使用已经兑现的一日误差。C18 的均值与 C16 相同。

一次审查只回答四件事：

1. **尺度对应什么误差。** 沿 C8 原始尺度、成熟平方误差及覆盖反馈，记录每项的目标均值和单位。明确第一项没有因 C16 改变均值而改成 C16 剩余误差的尺度。
2. **信息矩阵解释需要什么假设。** 写出单位噪声／单位精度先验下的小回归头模型，核对归一化、先验与响应单位是否一致；不能仅由 A 的逆矩阵存在，就认定得到整个方法的后验预测方差。标准 BayesianRidge 在同一模型中区分噪声精度、权重精度及权重协方差，这只是解释参照，不是要求更换模型。[官方参数与协方差说明](https://scikit-learn.org/1.7/modules/generated/sklearn.linear_model.BayesianRidge.html)
3. **相加是否有统一依据。** 检查基础误差尺度是否已包含参数估计误差或反馈可解释偏差，以及相加所需的条件关系。若本地证据不能区分，结论写“分解未识别、存在重复计量风险”，不写成已经证实重复计算，也不靠整体评分排除风险。
4. **覆盖哪些不确定性。** 新增项仅针对小误差头的工作近似；不宣称完整覆盖基础 Ridge、B+ 参数、未来驱动或空间联合不确定性。

交付是一张“量—来源—单位—条件假设—证据状态”表及明确的方法称谓。当前默认称 **经验性方差增补规则**。复算一致、正方差或覆盖改善不能独立证明分解正确；审查过程中不改公式、不拟合新噪声、不追加尺度版本。

## 4. 信息边界与评价数据身份

### 4.1 每个起点的合法信息

沿用 n 表示已经看见行 `[0,n)`，最后观测为 `y[n-1]`；h 步目标为 `y[n+h-1]`。发出预测前只有目标索引小于 n 的监督可用。生成、锁定预测后才释放第 n 行标签，随后更新已到期监督；不得回写历史预测。

从既有数组、日志及来源清单整理每个起点的审计字段：起点／目标日期、最后可见位移索引与发布状态、教师前缀及参数哈希、实际使用的驱动及时间范围、标准化来源、成熟监督索引、系数／信息矩阵／校准状态、已发均值／尺度哈希、锁定与标签释放事件次序。字段缺失要标缺失，不能伪造真实发布时间。

优先复用已经完成的模型、评分与时序核验，只追查新增疑点。需看数组时只读原 NPZ；边界抽查固定为每阶段首起点、首个合法一日反馈、首个合法 h30 反馈监督成熟起点、最后合法 h30 起点，覆盖四点及 h1/h7/h30，不按误差大小选取。

### 4.2 日值可用时点：针对性核对，不能阻塞全部工作

原论文发布数据按用户要求固定使用，不更换、不补采，也不由微小的一日误差反推数据不真实或经过插值。仅在现有论文说明、数据说明和预处理来源内核对：标记日期对应什么采样，何时可获得，是否存在依赖较晚观测的处理。

将“采样日期”“实际可用时间”“后续修订／处理时间”分列。能证实则给原件定位；没有信息则明确写 **as-of 未核实，现有回放假定起点前日值已可用**。仅 CSV 索引的因果顺序不能证明当时已发布。

没有发布时间材料仍可完成本阶段报告；不再次把取回原始材料或取得新数据作为通用前置条件。只限制现实在线部署的结论，不抹去按发布日值开展的历史探索结果。

### 4.3 已知未来驱动与实际驱动

原协议允许给定未来降雨／库水位，所有臂享有同一信息权限；实际依赖按第 2 节分别列出，不能说每个臂都使用了相同物理输入。涉及 B+ 的条件预测，与只依赖过去位移的 CORE／DRIFT1 应准确描述。

未来若评价真实业务信息条件，必须另行固定驱动预报来源、可用时点、缺测和所有臂的处理。当前不以随意持平或替换驱动启动敏感性实验，也不把条件预测成绩写成未知未来天气的部署成绩。

### 4.4 现有数据不能重新成为盲测

原 C4 唯一后期迁移失败保持；C7—C18 的后期均为暴露后的探索。合法使用逐日起点前标签，与研究者看过整段效果后改结构，是两个不同层次的问题。

当前默认分支是 **已有数据上的冻结可信度审查**。重新切分、打乱或成块重采样不能恢复盲测身份；反复使用有限样本选方法会产生选择偏差，原论文支持这一通用风险，不直接量化本项目偏差大小。[Cawley 与 Talbot，JMLR 2010](https://jmlr.org/papers/v11/cawley10a.html)

只有同一案例中确实存在未参与方法选择、来源清楚的后续观测，才有条件另拟一次前向验证。本次不要求取得它们。若将来提供，须在评分前固定起止日期、最少有效起点、缺测规则、状态延续／初始化、B+ 参数前缀、实际信息条件、单次报告时点及独立预算；这些尚缺字段不以臆定日期补齐。新阶段不自动运行，也不能只因文件是新收到的就称独立数据。

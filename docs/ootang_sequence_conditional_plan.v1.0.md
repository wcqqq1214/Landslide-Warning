## 固定输入与监督目标

每天 22 维：原 B+ 位移减首日 y0（4）、B+ 日增量（4）、雨/水位/水位差（3）、截至当日 7/30 日累计雨（2）、原 moisture（4）、rain_head（4）、reservoir_head（1）。
四点共同作为特征编码，不构造新的空间图；两种结构均从第 0 日接收完整合法驱动及物理特征序列，输出同长度四点轨迹。
不输入观测位移历史；仅在拟合损失和训练前缀归一化中使用当阶段成熟标签。网络每个 t 输出仅依赖 0…t 特征。
输入均值/标准差仅拟合前缀计算，标准差下限 1e-6；输出单位 s_p=max(std(y_p−y0_p),1 mm)，ddof=0。

- DIRECT：y0 + s_p × f(X)；监督 (y−y0)/s_p。
- BRES：原连续 B+ + s_p × f(X)；监督 (y−B+)/s_p。

同结构两臂使用相同输入、初始参数、种子、样本、归一化、损失和选定更新次数，唯一变化是输出基线与目标。
这是残差输出方式配对，不是有无物理信息消融；模型不称 PINN、不宣称神经输出严格满足 B+ 方程。

## 两个小模型（首轮不扫描）

**轻量 Transformer**：22→16 线性输入投影，固定从第 0 日计数的 16 维正弦位置编码（base=10000）；2 个 pre-norm 编码块，每块 2 头因果自注意力、32 维 GELU 前馈层，最后 LayerNorm 和 16→4 输出头。dropout=0，LayerNorm eps=1e-5。每日 token，无 patch 聚合，不将本模型命名为 PatchTST。参考 [PyTorch 编码层文档](https://docs.pytorch.org/docs/stable/generated/torch.nn.TransformerEncoderLayer.html)，因果掩码覆盖全部训练与预测序列。

**CNN-Mamba**：一层左填充因果一维卷积 22→16，核宽 3，SiLU；随后 2 个 pre-LayerNorm＋Mamba-1＋残差块、末端 LayerNorm 和 16→4 头。每个 Mamba d_model=16、d_state=16、d_conv=4、expand=2、dt_rank=1；内部选择性 dt/B/C、负对角 A、D 跳连和 SiLU 门保留。dt 初始化区间 [0.001,0.1]，其余详情写入配置。
本机无 CUDA；实现官方实值 Mamba-1 递推的 PyTorch CPU float64 版本，采用关联仿射前缀扫描。先与官方 `selective_scan_ref` 的 float32 及独立逐步 float64 递推核对前向/梯度，训练后用独立 NumPy 逐日递推重放。精度转换单列，不宣称运行了官方 CUDA 内核。
依据 [官方 Mamba 模块](https://github.com/state-spaces/mamba/blob/e9594ce1c732d97440f0332fdc43170a2294dbfa/mamba_ssm/modules/mamba_simple.py) 与 [参考扫描](https://github.com/state-spaces/mamba/blob/e9594ce1c732d97440f0332fdc43170a2294dbfa/mamba_ssm/ops/selective_scan_interface.py)，原件及 Apache 2.0 许可随来源保存。

旧 `codex/mamba-model` 的 8 点、7 日输入→1 日、空间网格、CUDA/float32/分位数实验保留，只借鉴 CNN＋Mamba 思路，不复用权重或混入同窗成绩。本轮时间卷积＋四点共同通道属于独立适配。

## 训练、锁定与概率层

三个种子 0、1、2；CPU 单线程 float64；Adam lr=0.001、betas=(0.9,0.999)、eps=1e-8、weight_decay=0；输出头初始为 0，无梯度裁剪或额外损失。完整训练前缀等权 MSE，每次更新一个完整序列；不采用窗口随机采样。
内部每臂每种子固定跑到 400 次，保存 e0、50、100、200、400；e0 仅回退核验，不参与选模。
**每个结构单独选一个两臂共用的更新次数**：内部前 90 日三种子均值 RMSE/s_p，跨两臂和四点平均，选择最小；1e-12 内并列取较早更新。
开发和最终各从头拟合至该结构选定次数，保存沿途冻结检查点；不同结构允许不同内部次数，不宣称等算力或等参数量比较。
三种子等权均值为主输出，各种子逐点结果完整保存。新四臂与同协议的 B+、DRIFT1、RR_COND、TCN_DIRECT/BRES 共九方法同表。
开发按均值 MAE→RMSE 和概率 CRPS→90% 区间评分分别选优；并列按配置方法顺序，名单在最终训练/评分前锁定。既有 TCN 固定为原内部选定 100 次，不重新挑检查点。
概率层仍是每点最近 90 条已兑现独立预测误差的 RMS 高斯尺度，下限 1e-6 mm；内部末 90 日→开发，开发末 90 日→最终。没有预测窗内更新、偏差校正、新概率头或方差项。报告 80/90/95% 区间，主概率评价为 CRPS、90% 区间评分/覆盖/宽度。
此尺度由旧前缀模型转移到重训模型，90 条误差有序列相关性，不能据此声称名义覆盖保证。各种子概率诊断共用该臂已发出的集成校准尺度，不作种子独立再选模。

## 事前判断与核验

沿用 TCN 条件实验工作条件：平均 MAE/RMSE 比 B+ 至少改善 1%，每点不退步超过 1e-6 mm；平均 CRPS/90% 区间评分至少改善 1%，逐点两评分退步至多 5%，平均 90% 覆盖≥85%、每点≥80%。这是研究工作门槛，非导师逐项确认的要求。
另行明确超过 DRIFT1、岭回归、旧 TCN 与否，不将某一基线替换成有利门槛。BRES 对 DIRECT 的均值（MAE/RMSE）与概率（CRPS/IS90）分别判断，需集成同向改善及至少 2/3 同种子配对同向；两阶段/逐点限制保留。
不作显著性、因果、真实预警或整个模型家族有效性的推断。高覆盖须结合宽度/区间评分，训练拟合好不等于预测好。

## 1. 实现范围

新增 `code/physics_guided_pinn/equations.py`，提供原参数到力学系数的转换、20 维力学状态
加 4 维背景状态的子步残差，以及四测点观测映射。状态轴为四个物理代表域，观测经原
O 矩阵转换；两轴分开。

残差分别输出运动、基底记忆、接触记忆、体内记忆、背景演化、滑移步长、屈服间隙、
负滑移、负间隙和互补乘积。没有把不同量纲的残差自动加成损失，也没有让背景位移成为
无约束的自由补偿项。默认 dt=1/64 日，与原 C 子步一致。

所有运算保留 previous/current 两个状态的 autograd 路径；原参考参数的指数变换、长度
权重和两个矩阵原样传递，不调用或修改冻结物理求解器。不包含状态网络、PINN 训练器、
概率头、损失权重、参数反演或新的本构偏差设计。

## 2. 实际核验

以下命令完成 5 项合成测试，运行约 1.91 秒，Ruff 及格式检查通过：

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
PYTHONPATH=code:tests .venv/bin/python -m unittest -q test_physics_guided_pinn_equations
```

| 检查 | 输入和判定 | 结果 |
| --- | --- | --- |
| 参数存储 | 54 参数中黏性、硬化、松弛/运动时间及接触/体内时间的指数转换，长度权重 | 通过 |
| 原活动集等价性 | 32 组随机合成局部状态，按原 C 更新顺序构造可行子步；比较新 gap 与 `A dx−rhs` | 通过，断言绝对阈值 2e-12 |
| 不可逆与屈服违反 | 人工负塑性增量和负间隙，分别要求暴露负滑移、负间隙及相关方程误差 | 通过 |
| 跨状态梯度 | previous/current 共 48 个状态变量的有限差分对照，包含互补乘积 | 通过；eps=1e-6、atol=2e-5、rtol=1e-4 |
| 空间观测/首日 | 非平凡 O 矩阵、不同域位移、背景项、首日零状态和错误形状 | 通过 |

测试未用实测标签拟合，未调用原力学前向、优化器或神经更新。随机局部状态并不声称是
从原首日连续演化得到的真实轨迹。上述 2e-12 是混合方程分量的测试容差，不能当作已核验
真实轨迹的 mm 误差或 PINN 物理可行性保证。

## 3. 未完成部分及下一步

原 64 子步完整轨迹尚未逐步送入该接口核验；已有日末状态不能直接用 dt=1 日代替 64 个
原子步，二者离散关系不同。下一步需在独立有限预算中保存子步状态/载荷，检查新残差与
原活动集/观测轨迹一致，再确定可学习的物理偏差、训练内缩放和 PINN 网络。

接口的一部分不明确性。训练方案、真实轨迹核验、概率校准及四点精度目标均仍未完成。
v1.7 的训练与评分继续按其已冻结预算执行，不受本接口的新增文件影响。

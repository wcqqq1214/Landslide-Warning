## 1. 已实现的接口及不变条件

新 `SequenceM1` 使用原来的 23 输入通道、16 hidden 通道、1×3 空间卷积及
1×1 读出，7,569 个参数。历史与未来共享门参数，编码器末端 hidden/cell 传入
未来逐日递推，同一起点的不同预测日继续传递状态。

历史端使用日期 `[o−30,o−1]` 对齐的 B+ 特征及观测残差/日差；差分左端为 o−31。
未来端使用 `[o,o+H−1]` 的 B+ / 已知水文 / 静态特征，观测通道在标准化空间中
置零。最后一通道是 `(日期−o)/179`，历史为负、未来非负。构造函数只接受恰好
o 日的观测前缀，返回不含标签的历史/未来张量和 B+ 基线；未调用新的 scaler 拟合。

相较旧 M1，这同时改变日期组织、有效上下文和状态衔接，不能把后续差异全部归于
某一个因素。原 M2/PINN 的状态及力学递推路径仍保留；本接口也不是完整 DeepAR、
TFT 或新的 PINN 复现。方法依据见 v1.23 的原文审查。

## 2. 固定来源和核验结果

沿用 252B/342A/432B/612B、当前 h 冻结 scaler、ATU1/ATU5/MJ3/MJ1 点序。
对两来源共 3,030 个原查询构造新输入并独立枚举日期与标准化值；再核对 15 个
真实接口案例，总计检查 30,815,400 个输入/基线数值。15 个案例包含三个当前 h
起点、六个 IN paired、六个 OOF paired，没有选择表现较好的案例。

两个未训练权重为 seed=0 零读出及相同门权重的固定非零读出探针。探针读出
16 个权重按 −0.01 到 0.01 等间隔设置，偏置为零；没有使用目标位移确定权重。
差分检查的临时权重扰动结束后严格恢复原值，两个 checkpoint 均未学习或改变。

| 检查 | 结果 |
| --- | --- |
| 零读出均值恢复同教师 B+ | 15/15 严格相等 |
| 完整预测前 30 日与短预测 | 15/15 严格相等 |
| 更改第 31 日以后的未来物理输入 | 15/15 的前 30 日输出不变 |
| 编码一次后分段解码 | 15/15 与整段解码严格相等 |
| 独立 NumPy 卷积/状态更新 | 最大输出差 1.2212e−15 mm |
| 第一预测日四点历史梯度 | 60/60 有限且非零 |
| 历史/门权重方向中心差分 | 120/120 通过，最大绝对差 2.0715e−11 |

NumPy 比对使用原 atol=1e−10 mm、rtol=1e−12；差分使用 epsilon=1e−5，
误差界为 1e−7+1e−5×|自动微分导数|。没有修改门限或根据核验数值重选方向。

主验证约 6.557 秒，含启动/来源检查/收尾约 10.278 秒，exitcode=0。主验证和
一次封存复核**各自**完成 120 次完整 model 调用、285 次 encode/decode 段、
13,920 个 cell 样本步、9,870 个读出样本步、180 次梯度及 2,790 个 NumPy
cell 步，均等于登记预期且小于预算上限；不能把回放当作零神经求值。
两次合计 240 次完整调用和 360 次梯度，均为未训练权重检查。

封存复核独立重建输入和 NumPy 参考，重放相同初始化及固定探针；294,120 个
已保存数组值逐值相等，最大差为 0；所有表格采用保留 float64 往返值的严格比较，
两个 checkpoint 一致。2,787 个保护文件、八个本版来源及源码快照校验通过。
这不是独立重训或模型有效性验证。

15 项合成测试涵盖日期/标准化、未来标签拒绝、所需值与未使用未来尾部的区别、
差分左端、禁止重新拟合 scaler、零基线、双样本 NumPy 参考、空间邻接轴、分段
状态及 autograd、预测前缀隔离、方向导数、零读出梯度和预算提前拒绝。另专门
确认极小非零梯度能往返保存，篡改为零会被拒绝。Ruff 检查及格式检查通过。

6.4232e−39，最大值 7.6362e−2。数学路径存在，但在这组未训练门参数下，远期
输出对近期历史的局部敏感性已经很弱。不能把非零梯度写成长期记忆良好；也
不能据未训练探针断言训练后必然失败，或未经对照将原因归于某个门。

本版按预定规则保留衰减结果，没有修改遗忘门偏置、增加历史上下文通道、训练
权重或按远期响应选择初始化。相同未训练权重在重复历史上的多行读数不构成
独立研究重复；没有显著性、因果或原输入信息上限结论。

## 4. 下一步及备份

接口已具备有限学习对照所需的时序与梯度基础。下一版应先固定预算、样本、目标、
匹配对照和退出条件，再检验训练是否能改善跨期预测；同时记录历史依赖是否
持续衰减，不能仅以训练误差下降宣告成功。若要归因于状态传递，需要保持其他
条件一致的对照；原 B+ 和现有网络仍是必要参考。

checkpoint、调损失权重或校准区间。原始日值 as-of 未知、已知未来雨量/库水位、

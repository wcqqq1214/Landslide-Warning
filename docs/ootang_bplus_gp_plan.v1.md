## 1. 目标与方法定位

检验一个候选：**冻结 B+ 均值，加高斯过程回归学习残差，能否同时改善完整开发窗的均值误差和概率质量。**

| 方法 | 类别 |
| --- | --- |
| ConvLSTM | 卷积与循环神经网络结合的深度学习模型 |
| PINN | 物理信息神经网络方法，通常采用深度神经网络 |
| GP / GPR | 非参数监督机器学习，不是深度神经网络 |
| B+–GP | 物理模型与机器学习结合的概率预测模型；B+ 本身仍是物理模型 |

GP 符合“机器学习或深度学习相关”中的机器学习类别，但不能作为必须使用深度神经网络的交付。
本稿记录用户提供的 GP 候选，不把“方法类别符合”写成已经获得效果、创新性或方法范围的验收。
此前 ConvLSTM/PINN 限定及停止状态仍可由[当前入口](../AGENTS.md)追溯；本次仅整理文档。

对每个测点：

$$
y_j(t)=\mu_{B+,j}(t)+f_j(x_t)+\varepsilon_j(t).
$$

B+ 负责原有物理计算；GP 学习“实测位移减去 B+ 位移”的剩余偏差，并输出预测不确定性。

- 固定为藕塘 **MJ3、MJ1、ATU5、ATU1 四个测点，各拟合一个 GP**，共用同一套建模规则。
- 不同时比较多个核函数、其他神经网络或多个融合版本，不按测点挑选最佳模型。
- 这是四点**边际概率预测**验证，没有学习跨测点残差协方差。
- 修正后的均值不自动满足 B+ 的全部力学约束，不称为 PINN 或完整时空联合概率模型。
- 范围保持为现有藕塘案例的位移预测，不扩展至新案例或预警任务。

## 3. 特征、残差与缩放

### 3.1 五个共同特征

| 序号 | 特征 |
| --- | --- |
| 1 | 时间 |
| 2 | B+ 四代表域含水状态的平均值 |
| 3 | B+ 四代表域雨致水头的平均值 |
| 4 | 滞后库水位与当日库水位之差 |
| 5 | 当日库水位变化 |

这些平均值是**模型状态摘要**，不是实测全坡平均含水率或孔压。
特征标准化只使用 GP 训练段，预测期间不重新估计标准化参数，也不裁剪到训练范围。
字段映射、时间编码、滞后定义和边界处理按第 9 节补齐后固定。

### 3.2 学习目标

$$
r_j(t)=y_j(t)-\mu_{B+,j}(t).
$$

每点残差只按训练段 RMS 缩放，**不减去残差均值**：

$$
s_j=\sqrt{\frac{1}{762}\sum_{t\in T_{\mathrm{GP}}}r_j(t)^2},
\qquad \widetilde r_j(t)=\frac{r_j(t)}{s_j}.
$$

设置 `normalize_y=False`。零均值 GP 先验对应“没有证据时不预设额外位移偏差”。
RMS 为零或接近零时的处理原贴未提供，不能在运行中临时选择。

| 输入维数 | 5，各维独立长度尺度 |
| 优化目标 | 训练段负对数边际似然 |

| 运行环境 | CPU、float64、单线程 |
| 处理顺序 | 四点顺序处理，不并行搜索多个模型 |

## 5. 观测预测区间与方差核验

主结果使用**观测预测区间**，不能仅报告 GP 潜在函数的置信区间：

$$
\operatorname{Var}(y_*)
=\operatorname{Var}(f_*\mid D)+\sigma_\varepsilon^2.
$$

- 同时保存潜在函数方差与观测预测方差，并通过独立矩阵计算核对。
- `WhiteKernel.noise_level` 表示方差；若库返回值已包含该项，不能重复添加。
- 数值稳定用的 `alpha/jitter` 不解释成现场观测噪声。
- 还原单位时，残差均值乘以训练段 RMS，残差方差乘以 RMS 的平方。
- 不增加独立神经尺度头，不在预测后额外放大区间。

预测方差随输入变化，不意味着已经建立完整异方差、物理参数不确定性或未来驱动不确定性模型。
原文提供的 API 参考链接保留于第 10 节；库行为须按实际锁定版本与合成算例核验。

## 6. 执行顺序与产物

**固化配置与来源 → 必要合成测试 → 四点各拟合一次 → 锁定预测 → 开发评分 → 只读复算 → 报告并停止。**

1. 补齐第 9 节配置，记录来源、实际依赖版本、字段映射、预算起止和计数规则。
2. 用合成数据检查残差符号、时间边界、零修正回到 B+、单位还原和噪声不重复添加。
   不把真实数据试训、调参或核筛选隐藏在测试阶段。
3. 四点各拟合一次，保存参数、优化日志及完整拟合/预测分布。
4. 四点输出全部保存并锁定哈希后，评分入口才读取开发段位移；不边评分边改模型。
5. 检查保存模型重载、独立矩阵计算和保存结果复算的一致性。
6. 按固定条件给出去留结论，保留完整输出和失败记录；每个完成、可核验步骤分别 commit 备份。

## 7. 评价与通过条件

必须同时看均值与概率，不能只看拟合曲线或某个测点。

| 方面 | 提供方案中的通过条件 |
| --- | --- |
| 拟合均值 | 四点平均 MAE、RMSE 均改善，每点两项均不退步 |
| 开发均值 | **完整 376 日**四点平均 MAE、RMSE 均改善，每点两项均不退步 |
| 开发概率 | 四点平均 CRPS、90% 区间评分均改善，每点两项均不退步 |
| 覆盖与宽度 | 检查逐点覆盖偏差；区间加宽时区间评分必须改善，不能只靠扩大范围 |
| 计算完整性 | 四点拟合、来源核对、预测锁定、重载和复算均完整通过 |

全部四点的 80%、90%、95% 覆盖率、宽度及区间评分都应输出。
四点 RMSE 的算术平均与合并 RMSE 分列，不相互替代。

误差及评分的数值比较容差为 **`1e-6 mm`**，只用于区分浮点并列，
不代表实际重要性或统计显著性。覆盖偏差的具体阈值与数值核验容差尚缺，见第 9 节。
这些是新候选的拟议规则，不是已经确认的研究验收标准，也不改判旧实验。

出现下列任一情况，保存记录并停止：

- 任一点数值失败、优化未完整结束或资源耗尽。
- 计算完成，但均值与概率未同时达到第 7 节要求。
- 来源、日期、锁定、重载或复算不能完整核对。

不换核、换初值、增加轮数、逐点退回 B+ 或放大区间来把本轮改成成功。
即使全部通过，也不自动进入最终 293 日；最多形成已暴露开发窗上的有限正证据。

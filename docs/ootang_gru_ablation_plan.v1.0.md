**A：具体数学定义及归因边界**

伪起点m的已知残差 `r0=y[m−1]−B[m−1]`，未来残差 `r(h)=y[m+h−1]−B[m+h−1]`；各点训练前缀单位为u。

- A关：可学习量为 `q=fθ(h)`；输出 `B(h)+u q`；目标 `r(h)/u`；损失为目标MSE＋λ=1的 `mean(q²)`。
- A开：可学习量为 `q=fθ(h)−fθ(0)`；输出 `B(h)+r0+u q`；目标 `(r(h)−r0)/u`；损失为目标MSE＋λ=1的 `mean(q²)`。

参考h=0使用当时已知的教师状态m−1和零距离编码，历史上下文相同；没有h=0的未来标签或新增目标样本。由同一网络两次查询之差保证起点可学习变化精确为零。零网络A关回退原B+；A开回退仅起点校正B+。原公共输入接口的h≥1规则不修改，只在新入口构造这个已知参考查询。A开每次多一个解码查询，不增加参数、监督样本或更新次数。

A是“保留已知起点残差、变化监督及变化惩罚”的整组表达改动，**不能只归因于硬边界约束**。其正则化收缩的是后续可学习变化，不把已知r0一起压小；A关/开损失数值不可直接作为相同目标下的优劣。

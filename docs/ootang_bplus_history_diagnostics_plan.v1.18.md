# 藕塘固定历史网络依赖与修正需求诊断 v1.18

## Material Passport

- 日期：2026-09-11；Origin Skill/Mode：academic-research-suite / experiment-agent / plan。
- 依据：持续目标“根据你的建议，一步步推进”及 [v1.17 结果](ootang_bplus_history_learning_results.v1.17.md)。
- 本方案在新诊断求值前固定；范围仍为藕塘四点位移概率预测。诊断不代表精度改进。

## 1. 要回答的问题

v1.17 的 H 相对重新训练的 C 有 7/8 点窗预测收益，却仅 3/8 严格超过 B+。本版检查：
一、固定同一 H 权重后，历史输入实际改变多少输出、这种改变是否降低误差；二、
训练样本里的 B+ 修正需求是否覆盖后续预测需要的方向和幅度，以及步长采样是否充分。
不预设“历史未被使用”或“训练样本错位”已经成立，不重复训练或改变旧结果。

## 2. 固定模型、查询和信息边界

- 仅重载 v1.17 的 h=342/432/612、seed=0/1/2 九个 H/e100 checkpoint，原 scaler、
  物理轨迹、参数、23 通道顺序与 30 日输入全部保持。点序 ATU1/ATU5/MJ3/MJ1。
- H 使用原输入；H0 使用同一 H 权重，把标准化后的第 20、21 通道置零，其他通道
  逐值相同。H0 不是 v1.17 重新训练的 C，也不是候选模型；零值表示训练标准化中心，
  不保证组合对应真实观测历史。此检查只反映模型依赖，不作物理因果或特征重要性证明。
- 每个 h 拼接原训练 pairs 和原逐日 evaluation queries，分别共 627/769/1,052 查询。
  输入只接收前 h 日观测；每个预测起点 h 的历史整段固定，不引入预测期实测。
  三前缀的输出及输入指纹全部锁定后，才另读前 792 日观测计算诊断；更晚位移不解析。
- 保存全部种子及等权均值。h=342 的未来段仅作已暴露的辅助诊断；原正式两窗仍为
  [432,612)、[612,792)。不将三段当成独立重复，不改变原严格四项改善标准。
- 三类读数分开：原 training_pairs；原 fit_readout [30,h)；prediction [h,h+180)。
  fit_readout 的第 30 日仍为零修正，lead=-1，只计入 all，不计入有步长的分段。
  其他 lead 分段预定 0–29、30–89、90–179，对应第 1–30、31–90、91–180 日。
  训练 pairs 是同一全前缀教师上的回顾性样本，不能称为当时可用的逐起点回测。

## 3. 固定输出与判断依据

令需求 r=y−B+，模型修正 d=mean−B+，历史响应 s=d_H−d_H0，单位 mm。

1. 144 行需求表：三前缀×三读数×all/三步长段×四点。保存样本数、需求均值/RMS/
   最小值/最大值，同步长段训练样本的需求范围、越出该范围的次数和最大幅度，以及
   相对训练需求 RMS 的比值。训练 RMS≤1e-8 mm 时比值记 undefined，不偷偷加分母。
2. 576 行模型表：需求表每行对应三种子及等权均值；完整记录 H/H0 的 RMSE、MAE、
   bias、修正均值/RMS，s 的均值/RMS/最大绝对值，以及 H−H0 的 RMSE/MAE 差。
   同时记录反向修正次数（|r|、|d| 均>1e-6 mm 且符号相反）及活动修正次数，
   分母仍为该行全部样本数；零修正不能冒称方向正确。
3. 独立核对 MSE 恒等式：相对 B+ 的变化 mean(d²−2dr)，以及 H 相对 H0 的变化
   mean(s²+2s(d_H0−r))。这些是误差代数，不把分量解释成物理贡献率。
4. 540 行步长计数表：每前缀完整 lead=0…179，列出三类读数的样本数；明确未采样
   步长和长步长样本减少的情况。不把密集日值或随机种子当成独立信息量。
5. 保存逐查询的两种修正和一张四点×三起点的图：需求、H/H0 修正、训练需求范围。

判断采用完整逐点/分段/种子结果，不据均值择优：响应近数值零只表示该探针下弱依赖；
响应非零却不能减少误差，须区分“使用历史”和“历史有预测帮助”。需求跨期变向、
幅度或范围变化是样本可迁移问题的线索，不单凭越界确定失败根因。先结合证据决定
下一版改编码还是改样本；本版不设按预测成绩自动开训的门槛，不选择 H0 替换 H。

## 4. 预算与验证

- 0 神经更新/梯度、0 物理拟合/积分、0 scaler 或概率尺度拟合；不重算新概率区间。
- 主求值 batch=128，共 126 次网络 forward；首次独立回放 batch=53，共 282 次；
  科学执行合计 408 次。封存后一次只读完整复核另 282 次，总共最多 690 次。
  CPU 单线程、一个科学子进程、科学执行硬上限 180 秒；失败原样保留，不自动补跑。
- 单元验证只用合成数组/网络，检查同权重屏蔽、通道不变、输入隔离、查询/步长边界、
  零需求分母、反向次数、MSE 恒等式和预算计数。合成调用不充当实测试跑。
- 独立复核使用已核验的逐日期输入重构及不同批块，检查全部新输入哈希和两种输出。
  H 逐日输出必须复现 v1.17，训练样本损失必须复现原 final_loss；复核旧两窗全部 H
  的 RMSE/MAE。均值门限 1e-8 mm、MSE/需求统计 1e-8（对应单位），rtol=0。
  原始来源、历史失败、九个权重及全部旧产物保持哈希；图表逐点核对。

## 1. 三个问题分别回答

1. **是否超过 B+：是，限于四点平均评分。** 开发和后期的两个TCN在全部1—7天均降低平均MAE、RMSE、CRPS和90%区间评分；这不等于每点保护或概率覆盖均通过。
2. **是否超过简单对照和普通岭回归：否。** 两个阶段、全部七步长，两版TCN上述四个评分均落后于DRIFT1和RR_DIRECT。两版TCN完整工作条件都是0/7。
3. **B+残差输出是否有额外收益：有局部均值收益，缺少稳定整体收益。** 开发两臂集成均值/概率评分均为残差版较好；后期第3—7天集成MAE/RMSE更低，但第1—2天RMSE退步，90%区间评分全部七天退步。后期种子1的平均RMSE全部七天较好，种子0/2全部七天较差，不能用集成局部改善代替跨种子稳定性。

## 4. 实际模型与信息边界

唯一小型TCN为4个双层残差卷积块、16通道、核3、膨胀1/2/4/8，末端线性解码7×4；每种子14,060参数。两臂相同输入、初始化、批次、单位和结构，只改变输出基线及监督目标。内部两臂共同选择400次；三个阶段各两臂×三种子，共18次拟合、7,200次更新。实际优化循环合计 55.79 秒，不含准备、I/O和核验，不作为硬件无关速度基准。
30天观测输入剔除旧表中向前延伸的滚动统计，窗口首日差分为0；B+完整历史水文/力学记忆保留。两臂都读取相同合法物理特征和过去七日平均降雨/末值水位场景，故该配对不能解释为有/无物理信息消融，也不是PINN。
三种子等权合并后，用最近90条已兑现预测误差RMS校准经验高斯区间，不使用拟合误差初始化。每日起点一次给出四点七端点；这是离线逐日回放，每份已发均值/尺度及哈希均保存，包括阶段末未评分端点。模型在阶段内不更新权重；详见[冻结计划](ootang_tcn_plan.v1.0.md)。

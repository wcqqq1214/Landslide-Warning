## A的输出、目标与零输出

令起点m、距离h的同教师B+为B(h)，已知r0=y[m−1]−B[m−1]，训练前缀点单位u。

- A关：q=f(h)，mu=B(h)+u*q，目标r(h)/u，损失MSE(q,target)+mean(q²)。零头回退原B+。
- A开：q=f(h)−f(0)，mu=B(h)+r0+u*q，目标(r(h)−r0)/u，损失同形式。h0查询仅用m−1的已知教师状态与零距离；零头回退仅起点校正B+，h0严格连接已知位移，h1不强制等于实测。

A整体改变基线、监督中心和正则化对象，不能把效果仅归于硬边界。B采样因素本轮全部关闭，训练起点与距离完全复用旧uniform表；不再搜索λ或半残差系数。

# TiDE物理特征分组图件合同

用途为保留可核查的研究结果与失败模式，不制作导师汇报或投稿包。沿用既有Python/matplotlib工作流和nature-figure核验，240×170mm、300dpi PNG与可编辑文字SVG；临时同源PDF仅作字体/碰撞检查，不交付PDF。

问题是：B+位移/速度组K与B+水文状态组H，各自以及组合能否产生跨时段稳定收益？四组DATA、K、H、K+H采用相同模型、样本、种子和更新预算，H关闭仍保留共同降雨/水位驱动。三窗已暴露且部分重叠，以下均为固定训练流程的描述性结果，不作物理因果或显著性声明。

四张quantitative grid图各含四面板：

1. `feature_group_comparison`：a为九方法的三窗平均RMSE；b为K/H各减K+H的集成差和全部同种子差；c为最终B+、起点B+与四组TiDE的逐点RMSE；d为四组90%区间覆盖及原80%逐点工作门槛。
2. `feature_factor_effects`：四点各一面板，共同纵轴；显示加入K在H关/开、加入H在K关/开的四条条件RMSE差。负值为误差降低。全部三种子、平均效应和交互项另存CSV，不将连线视为连续时间回归。
3. `kin_final`：K组四点全部历史实测、B+与293日条件预测、三个种子、80/95%高斯边际区间，附K+H曲线作为固定参照。
4. `hyd_final`：相同布局展示H组。两张路径图共享逐点纵轴，完整容纳四组全部种子和95%区间。

结构适配自上一TiDE小试脚本；字段origin、point、seed保持原定义，method扩为九方法。配对由旧PHYS减DATA改为新K/H各减PHYS；新增因素差严格映射已锁定factorial_effects.csv。绘图源为独立核验后的均值/种子/尺度数组与CSV。累计位移仅减首日观测，评分保持原单位，不抽样、平滑、裁剪、挑选种子或补画不存在的神经训练段重建。

每张验证科学数组、实际SVG坐标、文字可编辑、1.5pt轴对齐、最小5pt字形、碰撞及逐面板目视。较高覆盖同时显示宽度，区间不代表293日同时覆盖。图形初稿失败时留存并只修绘图；研究判断、内部核验与用户/导师验收分开。

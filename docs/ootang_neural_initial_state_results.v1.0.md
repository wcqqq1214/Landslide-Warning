# 神经初态估计与可微 B+ 求解器耦合：本轮结果

**本轮已停止：耦合递推在已核验的训练后轨迹上通过，但预测收益尚未完成评价。** 完整内部期检查发现，零修正 B+ 对照不能满足本轮额外设定的塑性子步容差。没有因此修改容差、跳过对照或继续选模；这属于验收口径未提前对齐造成的中止，不能判作新模型预测失败，也不能宣称精度提高。

依据为事前提交 `d83b740` 的[计划](ootang_neural_initial_state_plan.v1.0.md)、[冻结配置](../config/ootang_neural_initial_state.v1_0.json)与本轮保存产物。单候选 `NIS_BPLUS`；分支 `test`，本地分步备份，未 push。

## 这次实际做了什么

最近 30 天合法历史 → 小型网络输出四维有界迟滞初态修正 → 原 B+ 方程每天严格递推 → 第 1—7 天位移。原 54 参数、塑性状态、三类反力和背景记忆保持；没有学习外力或参数，没有未来状态解码器，也没有求解器之后的可学习位移残差。当前观测锚定沿用 v4.0。

初态修正满足原一个状态尺度以内的边界，并在 z 非负边界进一步收窄；其余 20 维初态精确保持。这里验证的是动态初值的局部可行性和后续方程一致性，未证明新初态可由原确定性历史唯一重建或可辨识。与旧 PINN 的区别是未来状态直接由求解器产生；与历史 M2 的区别是只估计起点 z，不逐日修改蠕变背景。接入可微求解器本身不作为新方法主张。

四点、数据、观测截止、合法起点及未来驱动场景均沿用 v4.0：过去七日平均降雨、最新库水位保持。固定划分为内部 612/180、开发 792/376、后期 1168/293 日。本轮只完成内部三种子各 400 次更新，共 1200 次；未进入开发或后期。共同成熟误差概率校准规则已冻结，但未执行至该阶段。

失败起点为 691，最后观测日 **2018-05-22**，第 7 天第 54 子步，O2 内坐标：

```text
原 C 接受：x = -6.271796e-9，满足 x >= -1e-8
beta = 0.002061642862
塑性子步：delta_p = x / beta = -3.042135e-6 mm
本轮额外门：delta_p >= -1e-8 mm，因此失败
```

原 x 容差在此处换算成塑性增量为约 -4.850501e-6 mm，与新增的 -1e-8 mm 门不等价。原求解器允许的近零负解经除以 beta 后触发了额外门；独立线性子步重建确认同一位置，**日塑性增量最小值仍为 0**。这是模拟内部状态，不能解释为测点发生了实测反向滑移，也不应简单归为机器浮点舍入。

我在冻结验收前没有对完整内部起点先做这项 e0 检查，B 阶段的固定抽检未覆盖反例，导致固定训练后才发现口径不兼容。这是本轮未能进入效果比较的直接原因。失败原件见[异常记录](../results/ootang_neural_initial_state_v1/20260914/inner/failure.json)与[反例](../results/ootang_neural_initial_state_v1/20260914/verification/first_counterexample.json)；原配置、原 C 和旧实验结论保持。训练后的轨迹通过，不能事后成为豁免 e0、重启本轮的理由。

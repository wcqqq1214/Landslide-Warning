# 独立 NGBoost 回归 SHAP 协议

## 目的

该分析回答一个受限问题：独立 NGBoost 回归器在预测下一观测位移增量时，对哪些候选输入表现出模型依赖。

它不解释 ConvLSTM，不输出正式五级预警分类，不识别物理因果“主控因素”，也不构成提前预警性能。

## 模型与标签

- 数据：`data/monitoring_data.csv`，8 个测点，5 个历史滞后；
- 目标：`U_t-U_(t-1)`，单位为每个观测间隔的 mm；
- 输入：位移滞后、逐点速度、原始 `ΔV`、水文气象滞后量、累计降雨和测点 one-hot；
- 模型：独立 NGBoost 回归器，300 trees、学习率 0.03、`minibatch_frac=0.8`、`col_sample=0.8`、随机种子 0；
- 单次解释切分：训练至 2019-09-18，解释 2019-09-19 至 2020-06-30；背景和解释日期均匀抽取，分别为 12 日和 25 日；
- SHAP：permutation explainer，固定种子；输出平均绝对 SHAP 排名。

`ΔV` 在这里是回归模型的一个候选输入特征，和 v4 规则融合中“只审计、不投票”的角色不同；二者不可混写。

## 输出与未开展项目

当前输出仅包括 `figures/shap/ngboost_regression_{metrics,shap_importance,shap_provenance}.csv/json` 和 SHAP 图。五折稳定性、特征组删组和正式预警分类不属于这条精简的原型解释支路；如后续需要比较它们，必须另行冻结时间折、计算预算和解释样本，且不能把结果升级为外部验证。

## 解释规则

- 高 SHAP 值只表示该独立模型在当前数据和切分下使用该输入；
- 高相关滞后量可能互相分配贡献，单项排名不能视为唯一机制；
- 测点 one-hot 的重要性只表示该数据结构中的站点差异，不是地质主控因素；
- 不得由 SHAP 结果反推四指标阈值、正式融合规则或 NGBoost 正式预警有效性。

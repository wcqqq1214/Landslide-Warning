# TCN 结果图合同

- 问题：TCN 是否超过可信简单对照，B+ 残差输出的均值改善是否伴随概率改善。
- 证据：冻结的逐点预测数组和已独立核验的完整日期评分；不使用训练曲线代替效果结论。
- 布局：Python/matplotlib quantitative grid。总览以开发/后期的七步长 RMSE 和 CRPS 显示比较；配对图用 BRES−DIRECT 的逐点 RMSE 与区间评分揭示后期概率退步；14张完整曲线分别覆盖两个阶段、全部7步长和4点。
- 区间：曲线的两种 TCN 阴影为90%经验高斯预测区间，既非种子标准差也非方法效果的置信区间；对照的完整区间保存在CSV。总览是三种子集成预测的实际误差，非种子误差的平均，不添加混淆两者的误差棒。全部种子单独保存与评分。
- 日期：采用原各h合法起点，零删尾、零平滑、零便利抽样。每阶段h的 n 与主表一致。极小普通岭回归误差与较大TCN误差在总览用明确标注的对数纵轴展示。
- 输出：183 mm宽，字体至少6pt，SVG可编辑文字及300dpi PNG；用户明确不制作PDF，因此不生成PDF或宣称PDF专用字体/碰撞检查通过。改用最终Matplotlib渲染文字框检查、1.5pt绘图区对齐检查、全部PNG目视复核及CSV/曲线数值核对。
- 残差输出的局部正结果和后期覆盖/区间评分退步同等保留，C16不进入主图排名和门槛。文档/图像交付不等于导师验收。

# 滚动概率预测简报

2026-09-13。**当前方法属于监督机器学习，符合“机器学习或深度学习相关”的类别要求。已经找到有均值收益的方向，但还没有找到完整达标的物理引导概率模型。** 十七个候选、五次定期路线复盘及最后两轮收尾完成，停止新增模型。

## 现在保留什么方法

保留的探索方向是**在线岭回归（Ridge）＋短步长误差反馈**：先根据最近位移变化预测未来 1—30 日，再用已经兑现的一日预测误差，学习较长步长的修正。所有更新只用当时已经观测到的位移。

C16 CORE 只用位移模型的一日误差；PHYS 还加入 B+ 的一日误差。两者都使用监督机器学习。前面的 C1/C2 使用 ConvLSTM，属于深度学习，本轮没有超过强简单对照。B+ 是物理模型，Ridge 不是经典 PINN；不能为符合名称要求把它改称深度学习。

若课题只要求机器学习或深度学习相关，类别相符；若仍严格限定 ConvLSTM/PINN，或者要求证明物理引导的额外收益，现有结果还不能代替这些要求。

## 这次学到了什么

**较短步长的已兑现误差有用，B+ 的额外收益还不稳定。** C16 CORE 对原 Ridge 的完整两段 RMSE/CRPS 改善，配对成块统计支持这些样本内的差异；开发每隔 30 日的稀疏子集没有改善，不能称稳定独立重复。PHYS 对 CORE 开发退步，后期微小增益的区间跨 0，不能把所有收益归功物理引导。

早期 ConvLSTM、更多跨点输入、遗忘旧样本、反复调整概率分布，都没有完成完整目标。保留这套短步长反馈的机器学习实现和证据，下一次讨论应聚焦**概率可靠性与物理输入的实际增量价值**；现在不再追加网络、扩大区间或反复用同一后期数据挑参数，也无需为同一份结果反复送 6pro。

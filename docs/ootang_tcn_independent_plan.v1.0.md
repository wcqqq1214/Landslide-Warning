对每个模型、点和预测距离H=1…293，使用训练期内最近90份已兑现的**同距离独立递推误差**。合法校准起点为 `n = 1168-H-89,…,1168-H`，每份目标索引 `n+H-1 < 1168`。全部所需起点并集为786…1167，共382个；每个起点只计算在训练期内可兑现的长度，最多293天。

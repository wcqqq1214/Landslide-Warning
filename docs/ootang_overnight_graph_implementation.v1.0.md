# 夜间固定小图实现说明 v1.0

实现依据6e98c86冻结计划/配置，正式训练前形成；不改旧模型或数据。新增代码overnight_graph，复用成熟教师数组，新的物理前向0。

14历史通道按节点独立构造，末GRU状态先聚合再送固定图。A=I与仅MJ3/MJ1相连的A使用相同可训练参数和种子；B+中的既有物理耦合保持。通过全历史GRU的末合法时刻抽取避免填充污染；未来查询点独立，无查询之间递推。零头回退连续B+，日增量/残差差分仅使用左侧当前合法历史。

条件诊断对“同一驱动/滞后/符号”的执行含义明确为：同一个三元组必须在至少两个点各自通过至少3/4历史块；不是把不同驱动/符号的零散相关凑成两点。所有组合仍全部输出，触发仅依据前1152日的因果残差。该解释在诊断读数与训练前固定。

可选双头损失的辅助项是slow MSE与fast MSE之和，再乘0.5；主总残差MSE与λ=1总残差平方保持。分解标签按教师各自的完整已成熟残差前缀因果计算，非STL/双边滤波。

命令顺序：preflight；提交；run train-base / score-base；diagnostic；若触发run train-dual；run score-final；只读独立核验；图/PDF/文档收尾。阶段输出各自锁定，不用新增双头回写base发出记录。

## 1. 决策来源边界

导师已确认“加速度取一样的方法”。这里的“方法”落实为逐测点、逐时间间隔的二阶差分：

\[
v_i=\frac{U_i-U_{i-1}}{t_i-t_{i-1}},\qquad
a_i=\frac{v_i-v_{i-1}}{t_i-t_{i-1}}.
\]

单位分别为 `mm/day` 和 `mm/day²`，时间差使用数据中的真实天数。首个速度值和前两个加速度值保留为暖启动，缺失或非正时间差明确标记为无效，不静默填充。

导师没有给出藕塘的加速度数值阈值。用户随后明确授权本轮“阈值也取相同的”，因此 v4 沿用当前速度比较器的相对带宽；这是一项用户批准的项目操作假设，不应写成指定 Word 论文或导师已经明确提供的加速度阈值。

## 2. v4 阈值与基线

每个测点只用 `fit` 分段的有效加速度估计：

\[
A=\operatorname{mean}(a),\qquad
\sigma_a=\operatorname{std}(a,\,ddof=1),\qquad
A_0=\max(1.5A,\,A+2\sigma_a).
\]

`A0` 非有限或不大于零时，阈值状态为 `failed`，下游等级 fail-closed。冻结的五级映射为：

```text
green   a < A0 - sigma_a
blue    A0 - sigma_a <= a <= A0 + sigma_a
yellow  A0 + sigma_a < a < 5 A0
orange  5 A0 <= a < 10 A0
red     a >= 10 A0
```

负加速度自然落在 green 区域；它不会因为 `delta_v` 的原始符号而被机械升级。`delta_v` 仍保留在审计字段中，但 v4 不把它作为独立五级证据。

## 3. 四指标融合

v4 每个测点、每个有效时刻都输出四项输入：区间、速度、加速度和改进切线角。区间是“预测发布后、目标观测可见时”的逐时刻偏离状态识别，不宣称严格的未来提前量。

- 区间是一个 evidence family；
- 速度与切线角合并为一个运动学 family，取两者局部最大等级，避免确定性重复计票；
- 加速度是独立的 evidence family，能够单独改变候选等级；
- 原始 `delta_v` 只用于审计和趋势说明，不参与五级投票。

测点候选等级为三个 family 局部最大值，并保留各项等级、状态、贡献和一致性理由。滑坡体层继续沿用 v3 的 O1/O2/O3 双轴空间规则，同时保留“局部最高候选”和“跨区确认等级”两个轴；孤立高值不能伪装成整体确认。

## 4. 证据和未决边界

v4 使用 v1 作为证据字段的基础协议，并在 manifest 中同时锁定 v2 加速度扩展的内容哈希。这样既能复用已有证据链，又不会把扩展协议作为未使用的装饰文件。v3 的数值快照保留，不被 v4 覆盖。

以下事项仍不是本次导师回复所解决的正式协议问题：严格 MVIF 初始稳定段和 Word 口径的 `V0`、速度/切线角的 blue 容差、加速度阈值的现场独立验证、非规则采样处置和滑坡体正式融合函数。当前 v4 只能用于先跑通藕塘、审计字段和比较规则变化；`formal_warning_output=false`，`confirmatory_evidence_gate=blocked`。

## 对应的结构限制

`ridge.py` 的 `dynamic_features` 按点构造速度差和物理变化，`beta[h,p,:]` 仅乘本点特征；`OnlineRidge` 逐点更新，没有直接读取其他点当天已知的位移变化。因此现有较好的低维回归，可能没有利用四个测点之间可观测的信息。

这是源码事实，**不是已经证明邻点有可迁移预测信息**。早期 ConvLSTM 已使用空间输入，结果不佳，本次不是把空间建模包装成未尝试的新概念；要检验的是在当前有效的低维线性均值模型上，加入跨点观测的增量价值。

仍是监督机器学习。Ridge 的平方误差加 L2 目标沿用[官方定义](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)，不借该来源证明滑坡预测效果。四点、同剖面和现有 B+ 背景均保持。

## 主要变化与明确对照

保持每点自身的原 C8 特征，在其后追加其他三个点的四个已知位移变化特征：`D1-D3, D1-D7, D7-D14, D14-D30`。它们均由当前起点之前的观测计算，不含邻点未来标签。按配置点位顺序 ATU1/ATU5/MJ3/MJ1 排列其他点，跳过自身；不按相关性筛点、设距离权重或搜索滞后。

- `C15_SPATIAL_FULL`：自身六特征加邻点十二特征，共 18 维，主候选。自身两项 B+ 变化特征保留。
- `C15_SPATIAL_DATA`：自身四项位移特征加邻点十二特征，共 16 维，物理输入消融。
- 原 `C8_ONLINE_FULL/DATA` 及所有同信息对照原样复制，分别检查是否超过对应逐点版本；原 DATA 较好的均值不记为本次新增收益。

FULL/DATA 的参数数相差 2，不是严格等参数数的物理因果实验；它们提供实际增量价值对照。跨点输入来自实测历史，物理特征来自 B+，不得把回归系数或相关性解读为真实力学因果。这仍输出逐点边际概率，**不宣称已建立完整空间联合分布**。

## 固定训练与概率规则

复用 C8 独立核验过的 `initial_training.npz`（511/887 行）、`issued_features.npz`、DRIFT1 基值和原目标；对应教师和训练前缀不变，新增物理调用为 0。跨点变换只重排和追加原特征，不改变日期、教师或标签。每点每步长的特征 RMS 只由训练行计算，下限 1e-6；目标尺度仍是训练段 `target-DRIFT1` 的 RMS，下限 0.01 mm。

均值为 `DRIFT1 + target_scale * (normalized_features @ beta)`。固定 alpha=0.001、无截距；与 C8 的原规则一致，该 alpha 不是在新空间模型上重新选出的最优值。每点每步长一次初始解，后续等权追加成熟监督，正则矩阵固定为 `N_initial*alpha*I`；不遗忘、不重选参数或点位。

为使新模型的概率尺度对应自己的拟合误差，按 C8 原公式重新拟合每点两个尺度参数 a/b，跨步长共享：

```text
q = RMS(本点原四项位移变化特征)
raw_sigma^2 = (a_p*target_scale_h,p)^2 + (b_p*q_h,p)^2 + 0.01^2
```

Gaussian NLL、初值 log(a)=-log(10)、log(b)=0、log 边界 [-10,5]、L-BFGS-B 最大 100 次迭代/200 次调用、ftol=1e-10、gtol=1e-6 全沿用旧值。保留实际收敛记录，不据警告重启或扩大边界。这里新增尺度拟合是同一建模流程对新均值的必要组成，比较的是完整跨点方案，不能将差异全部归因于均值特征本身。

使用 C8 相同的最近 90 条成熟标准化误差、先验计数/平方和各 10、覆盖反馈 rate=0.02、目标 0.9、初始 log_scale=0、界限 ±log(10)。每个新模型的校准只读自己的已发预测和兑现误差；旧对照完全不变。尺度参数拟合一次后不变，不复用 C9/C11/C12 的额外尺度调整。

模型状态须保存原特征来源、确定的点位排列、全部缩放、初始 beta、尺度优化记录，逐起点保存跨点输入、已发 beta/均值/原始及校准尺度，最终保存充分统计量和反馈状态。每个起点先锁定再释放新标签、最后处理所有合法到期目标。

### B1. 尺度对应与条件假设

| 量 | 实际来源和单位 | 时间边界／状态 | 结论 |
| --- | --- | --- | --- |
| C8 DATA 均值 | DRIFT1 加四个趋势差的回归修正，mm | 阶段前初始化，之后只用已到期监督更新系数 | 是监督趋势学习；四趋势差与纯历史位移重建值逐起点相同 |
| C8 原始尺度 | 冻结回归分布的尺度参数、响应单位和趋势差幅度，mm | 沿用既有训练结果，在线不重新优化尺度参数 | 属于模型的经验误差尺度，不是已测得的仪器噪声 |
| C8 校准尺度 | 原始尺度乘成熟标准化误差 RMS 和覆盖反馈因子，mm | 最近最多 90 条成熟误差；计数／平方和先验 10／10，反馈率 0.02、上下界 ±ln10 | 校准目标围绕 C8 当时发出的均值；会包含偏差、误差变化及参数误差的混合影响 |
| C16 输入 x | 核心一日误差，PHYS 另加 B_ANCHOR 一日误差；除以各自历史 RMS 后无量纲 | 一日目标为 n−1，阶段前历史单位固定；首起点无可用误差，x=0 | 数值单位使用正确；输入单位很小不证明仪器精度或未来泄漏 |
| C16 响应单位 u | 阶段首份 C8 预测尺度，按点／步长固定，mm | 来源在阶段开始时已知 | 不是由误差头残差另估的噪声标准差 |
| C16 均值／尺度 | 均值为 μ8＋u·xᵀβ；尺度仍等于 C8 校准尺度 | 误差头 alpha=1、从零更新；不使用未成熟 h30 监督 | 数组确认均值修正后没有重建自身残差尺度 |
| C18 信息矩阵项 | u²xᵀA⁻¹x，mm²；A=I＋Σ成熟 xᵢxᵢᵀ | 新误差头的单位精度先验／单位噪声工作近似，参数未重估 | 代数和时间边界通过，不等于统一后验解释通过 |

两段各四点的一日核心误差 RMS 输入单位约为 1.08e-4—4.44e-4 mm；h30 响应单位 u 约为 0.3330—1.5377 mm。两者在算法中承担不同角色，不应混称同一个噪声尺度。完整数值由冻结 `normalization.json` 及数组证据保留。

若仅把新增小误差头看作 `r_j=(y_j−μ8_j)/u=x_jᵀβ+ε_j`，并假设 β~N(0,I)、独立 ε_j~N(0,1)，则其系数协方差可写作 A⁻¹，查询的系数不确定性项为 u²xᵀA⁻¹x。这说明公式的一个**条件性解释**，没有证明这些假设符合当前跨期误差。

同一简单模型的基础噪声项应与上述单位噪声约定一致；当前 C18 却使用随起点变化、围绕 C8 均值校准的 σ8,cal²。若把该尺度视为误差头的异方差噪声，系数信息矩阵通常也需要与对应噪声权重一致，当前实现没有建立这种统一关系。标准 BayesianRidge 区分噪声精度、权重精度及权重协方差；本方法不能据 A⁻¹ 的形式冒称该算法。[官方定义](https://scikit-learn.org/1.7/modules/generated/sklearn.linear_model.BayesianRidge.html)

**均值发生改变本身不必然使条件方差失效。** 已知历史条件下，确定性的均值修正不会改变同一随机量的条件方差。因此不能仅由“沿用旧尺度”断言公式错误。这里的问题更具体：旧校准基于 C8 的未中心化预测误差平方与覆盖反馈，没有独立识别最终残差噪声或参数协方差；再加新误差头项的联合概率依据尚未建立。重复计量是未排除的风险，不能由评分或本次代数核验确认／否认其具体份额。

本阶段采用的称谓为 **带物理误差参照的滚动趋势回归及经验性方差增补**。C18 是合法可评分的工作预测分布，但不是已经验证的完整贝叶斯后验、不确定性分解或原力学约束解。新增项只涉及小误差头，不完整覆盖 C8 参数、B+ 参数、未来驱动或空间联合不确定性。没有改公式，也没有启动新的尺度学习。

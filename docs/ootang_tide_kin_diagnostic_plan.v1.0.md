## 精确统计口径

训练起点m属于[432,n)，成熟长度L_m=min(293,n−m)，共有M=n−432个起点。期望距离损失系数为

`W_h = (1/M) × Σ_m 1[h≤L_m]/L_m`。

实际抽样系数用已保存前k次更新×8起点替代均匀起点总体。k>0时各距离系数总和为1；k=0实际抽样数和系数为0，期望系数仍可计算。系数不含四点共同1/4因子，不等于最终参数梯度或独立样本数。训练拟合按原全部合法起点重放，逐点/分段报告成熟标签数、支持起点数、MAE/RMSE/偏差及归一化原目标贡献；无成熟标签的单元明确为空，不填0。

## 2. 修正评价重点，保留完整证据

原方案要求完整两窗 8/8 点窗的拟合/预测 RMSE、MAE 全部改善，是项目自行设定的严格判据；
导师没有逐项指定该门槛。今后的具体候选应按本次补充重新定义适用范围，不能继续把该旧门槛
等同于导师要求；也不能将它事后改成“任意几个点改善即可”。

后续分段复核采用以下顺序：

1. 先从原图或原始记录定位导师所指测点及日期，形成一份明确的范围说明；无法可靠定位时，
   只请求缺失的范围信息，不猜一个有利截点。截图中的尾部不自动对应现有 432/612 日窗。
2. **在查看分段模型排名前**固定范围、端点包含规则及来源。对同一测点/窗口，B+/P0 和所有
   被比较模型使用同一日期集合；不按模型误差大小、种子或胜负改变范围。
3. 每点同时列出主要时段、尾段和完整窗口的天数、RMSE、MAE；概率分布已有时，再报 CRPS、
   覆盖率、宽度和区间评分。全窗原指标仍保留，空段记“不适用”，缺失分布记“不可评价”。
4. 按每点报告误差平方和、绝对误差和的尾段贡献，避免直接相加或平均分段 RMSE。
   尾段图、误差和区间漏覆盖保留；不靠整体加宽区间包住尾部来宣称概率改善。

分段结果是**导师反馈后、已暴露历史窗口上的探索性复核**，不称新的盲测或事前验证。
新复核可能解释适用范围，但不能据此将旧标准下的失败改判成功，或认定失败都由尾部造成。
当前没有新分段指标，也没有确定一个新的通过/失败数值门槛；正式训练前须把主体段的具体
均值/概率标准、逐点退步如何处理及停止条件写清。物理可行性与数据泄漏检查仍独立成立，
尾段精度容忍不是放宽原力学容差的依据。

## 3. 当前实施顺序

**暂缓 v2.1 概率 PINN 实现和训练，先做一次已有预测的范围定位与分段复核。**

优先采用同窗 B+/P0、最新 ConvLSTM v2.0 DIRECT 及既有 PINN 主输出作为复核对象，
旧 PINN v1.9 使用 R，v1.12 的共享力学 S 按其原名称单列，不把它改称经典 PINN。
先登记来源和输出语义再评分；没有对应窗口或概率产物时如实记缺失，不另训一个模型补齐，
也不按新成绩挑出某个历史变体作为“代表”。若附图属于另一实验，先说明窗口不一致，
仅对有可靠映射的范围评价，不把截点强行搬到两个 180 日窗。

| 一次复核得到的证据 | 后续实施方向 |
| --- | --- |
| 主体段均值已有稳定改善，概率质量仍不足 | 优先在已限定的神经模型内完善概率输出；具体方法另定，不预设只放宽区间即可 |
| 主体段均值仍存在明显系统偏差 | 再判断 PINN 能学习哪种物理偏差、现有信息是否支持；v2.1 作为候选重新审视 |
| 主体段均值与概率均有改善 | 完成结果解释和适用范围说明，避免为了尾段继续加模型；不自动称导师验收 |
| 范围不清、数据不匹配或证据不足 | 完成可用资料说明后停止该复核；不派生诊断版本或用新训练代替缺失信息 |

实现准备应先复用保存预测和既有评分函数，必要时才增加独立的分段汇总与可视化；
不修改旧模型、训练损失、选模代码、冻结配置或原结果目录。范围明确前不写自动截尾默认值。
只交付一份分段对照及方向判断，不遍历多个尾段长度、重训模型或自动开启下一轮。

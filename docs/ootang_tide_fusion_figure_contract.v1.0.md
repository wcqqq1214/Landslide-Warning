# TiDE分支融合图件合同

研究问题为：H独立编码并限制幅度，是否实际改变分支行为，且收益能否超过旧KIN/PHYS？证据链区分限幅相对无约束版的收益、相对原模型的收益，以及均值改善与区间失败。仅研究图，沿用Python/matplotlib、240×170mm、300dpi PNG及可编辑文字SVG，不交付PDF；临时同源PDF只作字体和碰撞核验。

四张quantitative grid，每张四面板：比较图a完整三个293日窗的十一方法平均RMSE，b为BOUND减SPLIT的全部同种子差与集成差，c最终B+及主要四组的逐点RMSE，d逐点90%覆盖，防止平均收益掩盖失败。分量图四点各一面板，显示四次发报（含612启动）的H贡献最大绝对值：SPLIT实际、BOUND原始与实际、训练段cap；集成和三个种子全保留，以共同纵轴确认限制实际生效，极值来源是完整293日，不作平滑或裁剪。

另两张为SPLIT和BOUND的四点完整路径，历史只显示实测和B+，未来给定驱动且无实测位移反馈；保存三种子、80/95%高斯边际区间，附固定PHYS参照。两图共享每点纵轴，范围完整容纳主要四组全部种子与95%区间。不补画神经训练段重建，末段偏差保留；覆盖与区间宽度同时标注。

比较/路径脚本为上一轮结构适配，origin/point/seed单位与顺序保持，method扩为十一方法；配对改为BOUND−SPLIT。分量图新建统计映射：component_summary.csv的hydro_abs_max/raw_abs_max/cap_mm，单位mm，均为已保存分量的完整窗口归约。源为已锁定数组与独立核验CSV；mean与seed不混作独立样本，分量上界不是概率区间或物理安全界。

四图均核对源数值、实际SVG坐标、最小5pt字形、1.5pt面板对齐、碰撞及逐面板目视；无因美观而删除的日期/点/种子。主要路径的共同坐标和分量的幅度定义明确，不由排版改变研究结论。窗口已暴露且重叠，全部探索性，内部核验不等于用户/导师验收。

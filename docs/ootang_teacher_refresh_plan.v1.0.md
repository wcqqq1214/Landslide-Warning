## 1. 唯一研究问题与旧证据

训练残差采用“伪起点当时重新拟合的B+”，相对“沿用最近的旧教师缓存”，能否改善同一小型起点GRU的跨时段预测？此前教师敏感性诊断、起点表达、边界采样及200/400更新对照均已完成；它们不改判。本轮没有首次引入OOF合法性，旧教师本来合法；新增变量是教师更新政策。

## 3. 新历史教师的固定拟合合同

新增前缀为492、552、672、732、852、912、972、1032、1092、1152，共10次。每次只接收[0,m)的原四点位移与驱动；初始化为G_CACHED在m所用的原冻结合法参数，不串联新拟合、不用1168教师初始化历史拟合、不按预测成绩挑选初始化。

采用原54参数B+、原参数上下界、64子步、完整历史零初态递推。单次固定终点加权更新：`r=(B_theta−(y−y0))/100`，最小二乘残差向量为 `[r.flatten(), sqrt(100*m)*r[-1]]`。SciPy TRF，linear loss，x_scale=jac，max_nfev=800，ftol=1e−9、xtol=1e−10、gtol=1e−7；边界感知前向差分h=2e−6×max(1,|theta_j|)，上界处反向。该阶段与现有历史B+终点加权续拟合形式一致；这是有限预算的单阶段更新，不冒称完全重现导师的全套参数标定或得到全局最优。

保留全部初值、终值、目标分解、调用数、最优性和收敛状态。达到800次上限但数值合法时继续完整神经比较，并明确未收敛；不按B+训练误差或后续效果删除教师。非有限/机械求解失败属于实现有效性问题，不能用旧教师偷偷替代新教师；记录后只完成不依赖该教师的工作。

每个拟合后按同参数从首日重放至m+293，以给定未来驱动生成均值、完整状态及22维物理特征；不读未来位移。先核验拟合前缀重放和来源，再解锁相应阶段神经训练。新增教师仅用于训练样本，外层评价的B+参数和预测不更新。

## 4. 固定网络、外层任务与概率

两臂均为已有1241参数GRU_GRAPH：14维逐点完整历史、GRU(14,8)、固定MJ3—MJ1图、共同解码器。保留起点表达：r0=y[m−1]−B[m−1]，q=f(h)−f(0)，均值=B(h)+r0+u*q；目标=(y_future−B_future−r0)/u，损失MSE+mean(q²)，λ=1。零头回退仅起点校正B+。教师的更换会一起改变B+派生输入、r0和监督目标，效应归于整项教师政策，不能仅归因“标签更新”。

两臂共用按当前外层训练前缀计算的旧外层教师特征归一化；同点单位u≥1mm。种子0/1/2、float64、CPU单线程、Adam lr=.001/betas=.9,.999/eps=1e−8/weight_decay=0；固定200更新，保存e0/50/100/200与Adam状态，主结果固定e200三种子等权均值。总24次神经拟合、4800更新、96检查点，不选轮数。

外层仍为612→905（校准启动）、792→1085、972→1265、1168→1461，各一次发出完整293日四点预测。未来逐日降雨/库水位给定，路径不接收位移反馈；外层教师仍612/792/792/1168。972故意保持旧教师复用协议，因此也是更新政策迁移到旧教师使用场景的检验，不能称972重新拟合发报。所有原对照BPLUS_CONTINUOUS、BPLUS_ORIGIN_ANCHOR、DRIFT1、RR_COND保持。

各方法用自身上一已发出路径第91—180日的90个成熟误差计算逐点RMS，尺度下限1e−6mm，固定高斯80/90/95%边际区间；路径内不更新。最终误差池[1062,1152)，16日间隔。种子使用集成尺度并标明。全部发报/误差池锁定后才释放完整标签统一评分。

## 5. 判定、核验与停止

完整报告三个主窗的四点及平均MAE/RMSE/CRPS/区间评分/覆盖/宽度、全部种子、教师政策配对和四个对照。沿用原门槛：平均MAE/RMSE各改善≥1%，逐点均值不退步（容差1e−6mm）；平均CRPS/90%区间评分各改善≥1%，逐点概率评分最多退步5%，90%平均覆盖≥85%且各点≥80%。同种子MAE/RMSE均改善至少2/3另报。

教师政策具有本轮稳定均值收益，须G_REFRESH对G_CACHED三个主窗均通过均值门且各窗至少2/3种子同向。是否达到替换B+的均值/概率目标独立判断，不能由配对胜出代替；DRIFT1和普通岭回归比较单列。新增起点/距离覆盖、教师终点偏差、分距离误差仅诊断，不更改完整293日主指标。即使效果差也完成全部合法预定拟合与评分。未建立稳定收益则收束这条已检验的教师更新残差路线，不自动加模型/轮数/教师密度/λ/RL；也不推论全部残差方法无效。

验证包括：日期/成熟标签/教师初始化边界；相同抽样/尺度/初始化；未来位移污染测试；h0与零头回退；全部权重重载、独立NumPy前向；B+原C求解状态重放与目标独立分解、原缓存前缀保持；逐点评分/校准/配对独立复算；图形与数组一致。数值容差沿用现有配置，不随结果调整。研究解释完成11项统计谬误检查；不作p值、因果机制或独立盲测声明。

## 1. 已执行的固定对照

四组 IN_CARRY、IN_RESET、OOF_CARRY、OOF_RESET，分别在 h=342/432/612、
seed=0/1/2 上各训练 100 次，共 36 个实例、3,600 次更新。每组均为 7,569 参数，
原 23 通道、原门初始化、零读出、原 Adam 和 v1.21 两块梯度范数平衡不变。
CARRY 将历史编码状态传给未来预测；RESET 只在两端交界清零，未来日之间仍递推。
RESET 仍通过 B+ 教师和训练标签使用历史资料，不是完全无历史的模型。

训练只使用原查询和权重，分别打包为 24/31/45 条序列，填充位置不增加监督。
按前缀递增完成并锁定模型、样本和均值，之后用独立 90/180 日段估计八组常尺度。
全部均值/尺度锁定后再读取 792 日标签评分；第 100 步是唯一输出，没有择优选轮数。
P0 和 v1.21 NORM 的均值、尺度及指标直接复用。0 新物理积分/拟合、scaler 拟合
或尺度网络训练；没有追加 PINN 或其他模型训练。

## 6. 解释边界与下一步

统计解释按 11 类风险逐项检查（11/11）：

| 检查项 | 本版处理及边界 |
| --- | --- |
| 汇总与分组方向（Simpson） | 同时保留点位、窗口和种子；平均值不代替四点判据 |
| 生态谬误 | 单剖面四点不外推至其他滑坡或总体 |
| 选择偏差（Berkson） | 既有案例与有限教师不代表随机、独立总体样本 |
| 碰撞变量偏差 | 未作控制变量的因果回归；不由状态对照推出物理因果 |
| 忽略基率 | 无预警/分类主张；位移区间覆盖不等于滑坡发生概率 |
| 回归均值 | 比较同期 P0 和匹配 RESET，不由较差模型恢复推断稳定收益 |
| 幸存者偏差 | 全部 36 实例完成并保留，未删除失败点位、窗口或种子 |
| 多重探索 | 所有登记组和指标完整报告，不报告选择后的显著性 |
| 分析路径选择 | 执行前固定预算和 e100；历史已暴露，仍属探索性开发 |
| 相关与因果 | 差值和梯度只支持当前模型对照/依赖，不支持物理因果结论 |
| 反向因果与时间先后 | 下游前缀隔离通过；原始日值 as-of 仍未知，不据此证明原始数据无未来信息 |

保留已知未来雨量/库水位、当前 h 预处理和既有历史窗口暴露限制；种子、日值和
36 个训练实例不视为独立案例重复。本版不改变导师目标，也不掩盖旧 M2、PINN、
OOF、目标平衡等已保存负结果。

本版按预算结束，不追加轮数、重调门或损失、拼接点位/种子。下一步建议先另版
固定现有 CARRY 权重的状态开关及按步长修正诊断：比较同一权重是否传入编码
状态，以及预测修正方向/幅度何时偏离需求，再决定是否改变历史上下文表达。
v1.18 检查的是旧滑窗模型的历史通道，本次候选针对新的连续递推及状态边界；
不能把旧诊断或本版局部梯度当成这个有限扰动对照已经完成。当前无下一版训练
预算；整体精度/概率目标仍未实现。

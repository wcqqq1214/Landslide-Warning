## 3. 第三窗的具体问题仍包括方向错误与过度修正

第三窗各点 P0 与 HHS 的完整误差如下，单位 mm：

| 点位 | P0 RMSE | HHS RMSE | P0 MAE | HHS MAE |
| --- | ---: | ---: | ---: | ---: |
| ATU1 | 55.3860 | 119.5784 | 54.5140 | 117.6929 |
| ATU5 | 140.0642 | 137.8826 | 134.6064 | 134.2317 |
| MJ3 | 14.7205 | 9.8387 | 12.5460 | 8.0256 |
| MJ1 | 21.8780 | 21.2279 | 18.1441 | 19.8913 |

- ATU1 事后修正需求均值为 **+54.5140 mm**，HHS 修正却为 **−63.1789 mm**，
  180/180 日方向相反。它是第三窗平均误差上升的主要数值来源。
- ATU5 需求均值为 +134.6064 mm，HHS 修正均值仅 +0.3747 mm，仍明显不足，
  其中 82/180 日方向相反。小幅误差改善不能写成已经跟随该点的位移变化。
- MJ3 两项误差下降；MJ1 修正均值 −37.8803 mm，而需求均值 −17.9890 mm，
  MAE 高于 P0。仅有均值方向一致或 RMSE 下降不足以说明修正合适。

前两窗也存在明显不足：252 日 ATU1/ATU5 需求均值约 +14.45/+12.05 mm，HHS 只有
+0.83/+0.74；342 日 MJ3 需求均值 +17.5235，修正均值 −2.0647，73/90 日反向。

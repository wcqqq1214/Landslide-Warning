## 为什么只检验这个差异

C13/C14 在起点 n 使用 n-h 发出的 h 日预测误差，目标为 n-1。C16 固定使用 n-1 发出的 **1 日**预测误差，同样仅涉及 n-1 的已知位移；它更新得更早，作为所有 h1—30 修正头的共同已知输入。没有读取未兑现的 h30 误差，不扫描反馈步长或滞后阶。

核心一日误差与未来 h30 核心误差在四点/两阶段均呈正相关，见[48 行核对](../results/ootang_rolling_v3/20260913/fifth_review_evidence/feedback_lead.json)。这只是已暴露数据上的候选依据；不证明它超出原速度特征的增量价值或未来可迁移性。物理参照关系不稳定，不预设物理系数符号或非零下限。

## 固定模型与概率对照

均值基值与概率尺度复用 C8 DATA，三臂分别为：

- `C16_FAST_PHYS`：核心一日误差 + B_ANCHOR 一日误差，主候选；
- `C16_FAST_TREND`：核心一日误差 + DRIFT14 一日误差，同维非物理参照；
- `C16_FAST_CORE`：仅核心一日误差，物理输入消融。

仍为监督机器学习 Ridge 误差头，不是深度学习或 PINN。物理误差是模型偏差参照，不是物理机制观测；非零权重不能证明物理贡献。原 C8 FULL/DATA、静态与各简单对照原样保留，不能把旧 DATA 的均值收益记为本次新增收益。

每点每步长一个无截距 Ridge 头，初始 beta=0、Gram=I、rhs=0，固定 alpha=1；只追加已经兑现且发出时输入合法的监督，零遗忘、不裁权重、不按点选模型。主输出：

```text
known_ref_error(n) = y[n-1] - ref_mean(origin=n-1, lead=1)
x_ref(n) = known_ref_error(n) / historical_ref_rms
response(n,h) = (y[n+h-1] - core_mean(n,h)) / core_first_sigma(h)
new_mean(n,h) = core_mean(n,h) + core_first_sigma(h) * dot(beta(h), x(n))
```

`response` 只有目标兑现后才进入拟合。首起点没有阶段内的前次一日预测，输入零且不作为误差头训练行；从第二起点开始各 h 可用同一短步长特征。相较 C14 增加的是及时可得的短步长信息，不回填起点前没有保存的当前模型预测。

概率 `raw_sigma/sigma` 原样保持 C8 DATA，零尺度拟合和新增反馈校准；只检查移动均值能否同时改善误差、评分与覆盖，不靠调宽区间。仍为四点边际高斯分布，无完整空间联合概率。

## 一日输入单位必须由阶段前资料确定

一日核心误差的数值量级约 1e-4 mm，概率 sigma 的 0.01 mm 下限不能代表它的输入尺度。因此固定采用**阶段开始前保存预测的一日 RMSE**作为特征单位，下限沿用原特征 RMS 的 1e-6；不改变观测值或概率 sigma 下限，也不将这些模型残差当作仪器精度。

开发使用原 C3 inner 的 612—791 起点，核心映射为 `C3_RIDGE_DATA`；后期使用已保存 C8 development 的 792—1167 起点，核心映射为 `C8_ONLINE_DATA`。B_ANCHOR/DRIFT14 使用各自同段原预测。全部 h1 目标都早于当前阶段起点，分别 180/376 条，教师前缀不超过对应预测起点；不读取本阶段评价误差来定单位。历史核心模型与当前模型并非完全相同，尺度迁移风险保留；旧 C3 的超参数选择记录不改变，不把此资料声称为新独立在线盲测。

输出响应单位始终采用当前 C8 DATA 第一份已发 sigma(h,p)，与 C14 固定响应单位一致；它与上述输入单位分开保存。C16 同时明确了短步长输入及其合适的事前单位，比较的是这套完整方案，不能将 C16−C14 差异全部归因于反馈时效。

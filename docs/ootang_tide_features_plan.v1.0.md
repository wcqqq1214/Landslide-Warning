## 分组效应、门槛与解释

记各点/窗口/同种子或集成的指标为E00/E10/E01/E11。分别报告：K在H关闭/开启时的条件效应E10−E00、E11−E01；H在K关闭/开启时为E01−E00、E11−E10。K平均效应为两项条件效应平均，H同理；交互为E11−E10−E01+E00。MAE/RMSE/CRPS/区间评分的负差表示降低，覆盖/宽度另按原意义解释。集成指标差与种子指标差分别算，不能混为种子平均指标。因子结果包括全部四点和平均、三个主窗、三种子，不只报告MJ3/MJ1。

各四组均对原五个对照报告全部均值/概率指标与原保护门。平均MAE/RMSE各改善≥1%、逐点不退步（1e−6mm容差）；平均CRPS/90%区间评分各改善≥1%、逐点评分退步≤5%、90%平均覆盖≥85%、各点≥80%。逐窗同种子MAE/RMSE同时改善≥2/3单列。两个新增组对完整PHYS若三个窗均通过原均值门且各窗≥2/3种子同向，才称本轮稳定均值改善；对B+替换目标另判。概率成功不能代替均值，局部平均改善不能覆盖逐点失败。

本轮是预先冻结的2×2输入可用性消融，描述特定训练流程对输入组的依赖，不识别滑坡物理因果。比较已受旧结果启发、窗口重叠并反复暴露，全部探索性；不作显著性、独立重复或普遍网络优越性声明。原数据as-of/预处理、物理未收敛及边际区间距离迁移限制保持。按11项统计解释检查记录结论边界。

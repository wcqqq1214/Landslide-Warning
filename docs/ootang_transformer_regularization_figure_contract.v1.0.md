# Transformer 正则化图件合同 v1.0

问题：固定幅度正则化是否改善四点完整预测，改善是否依赖个别测点？图件须展示实际结果，不预设正结论。

- 原型：quantitative grid，沿用导师参考布局的2×2四点图；每个点是跨测点异质性的一个必要层次，不能用平均成绩掩盖退步。
- 后端：当前任务既定Python/matplotlib，结构适配上一轮同协议图件；原脚本和旧图不修改。没有图像生成、补点、平滑、裁尾或重锚定。
- 图1：REG1前1168日拟合及完整293日预测；实测、连续B+、三种子均值、80/95%冻结边际预测区间。蓝/橙背景划分训练/预测，图内RMSE只来自完整预测窗。
- 图2：五个预定方法在完整293日的均值对照；原Transformer与REG1突出，实测/B+/DRIFT1/RR均保留；区间参见图1及CSV，不在同图堆叠五组区间。
- 映射：日期→日历横轴；observed/BPLUS/各模型mean→原始mm减首日y0；sigma→此前90条成熟误差RMS，单位mm；point顺序固定ATU1/ATU5/MJ3/MJ1。没有分界处平移。种子为技术重复，不是三个独立案例；图线三种子等权均值，区间不是种子标准差。
- 数字依据：独立核验通过的已发出数组与逐点评分。四点都使用1461日完整曲线/293日完整预测；原始表没有删除行。
- 规格：报告用240×170mm，300dpi PNG、可编辑文本SVG，正文最低7.6pt；不声称Nature投稿验收。原用户明确不制作PDF，因此不运行PDF专属检查；改用Matplotlib实际文本/线条几何、SVG坐标/字体与PNG尺寸检查。
- 导出门：实际绘制后，1.5pt面板对齐检查；文本碰撞/出界阻塞；所有SVG曲线和区间端点逆变换与源数组核对，坐标序列化容差1e-4mm单列，原始模型1e-7mm容差保持。

## 3. 新训练如何产生整段预测

### 3.1 连续 B+ 与合法特征

对每个训练前缀 n，使用只由该前缀拟合得到的固定 B+ 参数，从 2016-07-01 开始连续推进到该阶段预测末日。物理求解器读取完整已给定驱动，不读取预测段位移。记输出为 B_n(t,p)，初始位移为 y0(p)。

三阶段分别使用已有 612 日、792 日和原始 1168 日 B+ 参数；实施前逐项核对来源及拟合标签边界。不能用 1168 日参数替代内部或开发教师。新拟合 B+ 参数的次数为 0。

每个日期拟用同一组 **22 个输入特征**：

| 特征 | 通道数 |
| --- | ---: |
| B+ 相对初始位移 B_n−y0、B+ 当日位移增量 | 4+4 |
| 当日降雨、库水位、水位日差、截至当日的 7 日/30 日累计降雨 | 5 |
| B+ moisture、rain_head、reservoir_head | 4+4+1 |

物理状态通道遵循原求解器坐标定义，不把四个力学坐标直接当成四个独立测点。累计降雨在序列开头使用实际存在的历史天数；首日差分取 0。所有时间特征只依赖当日及此前驱动。TCN 不读取实测位移、速度或实测残差历史作为输入；训练标签只用于损失，y0 作为共同输出基准保存。

两臂都能读取相同 B+ 特征，因此配对检验的是**残差输出方式**，不能称为“有/无物理信息”消融。物理特征加神经修正的思路在[早期 ConvLSTM 方案](ootang_bplus_probabilistic_experiment_plan.v1.1.md)中已有尝试；本轮的新假设是 TCN 在这个任务中的表现，不把旧思路重新称作创新证据。

### 3.2 结构与监督目标

| 项目 | 拟定设置 |
| --- | --- |
| 编码器 | 4 个残差块，每块 2 层因果 Conv1d，16 通道，核宽 3，膨胀 1/2/4/8，ReLU |
| 输出头 | 每个日期一个 1×1 卷积头，输出四点；整段输出形状 T×4 |
| 时间感受野 | 61 日；物理状态另保留从起始日累积的记忆 |
| 序列开头 | 固定左侧零填充；保留全部日期进入损失与图表，首 60 日的边界效应注明 |
| 正则与结构搜索 | 不加 dropout、BatchNorm、跨时间归一化或新空间图；首轮不扫描结构 |
| 初始化 | 三种子 0/1/2；同种子两臂编码器一致，输出头权重/偏置为零 |
| 优化 | Adam，学习率 0.001，betas=(0.9,0.999)，eps=1e-8，weight_decay=0；float64 |
| 批量与检查点 | 完整训练前缀为一个序列批次；保存 50/100/200/400 次更新，共同内部选一次 |
| 主输出 | 三种子等权平均；同时保存每个种子，不按点挑种子 |

不载入旧七天 TCN 权重或旧选模结果。新输出头每个时刻直接产生四点轨迹值，训练和推断采用同一个映射，不把自身位移输出重新送回输入。

令 x 的均值和标准差仅由当前训练前缀计算，标准差下限 1e-6。两臂共用同一输入标准化和逐点输出单位：

`s_p = max(std(y[0:n,p] − y0[p], ddof=0), 1 mm)`。

输出定义为：

- DIRECT：`mu_D(t,p) = y0(p) + s_p × f_D(X[0:t],p)`。
- BRES：`mu_R(t,p) = B_n(t,p) + s_p × f_R(X[0:t],p)`。

两臂都优化完整训练前缀、四点等权的 `mean(((mu − y) / s_p)^2)`。残差臂不再单独按残差标准差缩放；未来特征使用已保存的训练尺度，不重新标准化或裁剪。

保存 e0、各检查点的训练损失、逐点拟合误差及梯度有限性记录。若固定预算结束时拟合仍明显不足，报告“此配置和更新预算下拟合不足”；不将运行到第 400 次自动称为已经收敛，也不据此临时加训练轮数。

每次正式预测先计算截至预测末日的合法特征序列，再在一次前向中输出整段位移，截取阶段预测区间并锁定。最终得到完整 **293×4** 均值数组；模型不是固定 293 个输出节点的多步头，也不进行七天自回归拼接。训练段曲线是拟合回代，单列评价，不能称为独立预测。

B+ 教师在本阶段训练前缀上的轨迹是拟合回代，其参数使用了该前缀内全部训练标签；这些残差不冒充逐训练日的 OOF 预测。隔离边界是该阶段预测起点：任何参数、标准化和监督目标都不能读取起点以后的位移标签。

## 4. 时间切分、选模及发出顺序

沿用已有 612/792/1168 日训练边界；内部选择与初始区间校准的划分是本计划提出的新规则。

| 阶段 | 训练段 | 一次发出的预测段 | 用途 |
| --- | --- | --- | --- |
| 内部 | 2016-07-01—2018-03-04，612 日 | 2018-03-05—2018-08-31，180 日 | 前 90 日选更新次数；后 90 日作开发前校准 |
| 开发 | 2016-07-01—2018-08-31，792 日 | 2018-09-01—2019-09-11，376 日 | 完整比较并锁定均值/概率候选 |
| 最终探索评价 | 2016-07-01—2019-09-11，1168 日 | 2019-09-12—2020-06-30，293 日 | 所有预定方法完整评价 |

执行顺序：

1. 内部两臂×三种子各训练至 400 次，保存四个检查点及完整 180 日预测。先锁定预测，再读取 2018-03-05—2018-06-02 的 90 日标签选次数。
2. 对各检查点先算三种子均值，选择使“两臂、四点的 RMSE/s_p 平均值”最小的共同次数。差在 1e-12 内取较早次数。不得分别给两臂挑次数；e0 仅零输出诊断。
3. 选定后，仅用其在 2018-06-03—2018-08-31 的 90 日已发出误差形成开发尺度。该 90 日不参与步骤 2 的选模分数。
4. 开发阶段从头拟合两臂×三种子，严格使用已选次数；锁定完整 376 日均值和尺度后评分。均值候选按四点平均 MAE 最小选，依次以 RMSE、方法表顺序破同分；概率候选按 CRPS 最小选，依次以 90% 区间评分、方法表顺序破同分，数值同分容差 1e-12。
5. 开发全表及两类候选身份锁定后，用开发最后 90 日（2019-06-14—2019-09-11）的原发出误差确定最终尺度。随后只在前 1168 日从头拟合最终模型，先锁定完整 293 日预测，再释放最终标签评分。
6. 即使开发效果差，也完成预算内全部五方法的最终探索评价；不按最终分数换候选、选种子、加更新或删日期。最低分身份和是否达到工作条件分别报告。

内部、开发和最终日期在历史实验中已反复暴露。本轮代码须隔离未来标签，但这不使研究重新成为盲测；开发用于选择、最终用于探索性比较的性质始终注明。

## 5. 五种预定方法与概率层

| 顺序/方法 | 均值方式 | 本轮拟合 |
| --- | --- | --- |
| 1 BPLUS_CONTINUOUS | 原 B+ 完整状态输出 B_n(t,p)，不在分界处贴合实测 | 不重估物理参数 |
| 2 DRIFT1 | `y(n−1,p) + h × [y(n−1,p)−y(n−2,p)]`，h 为距预测起点的第几日 | 无；最后一天速度在全预测期固定 |
| 3 RR_COND | 当前日同组 22 特征的普通岭回归，预测相对 y0 的四点位移 | 每阶段一次；训练标准化、截距，alpha=1 固定 |
| 4 TCN_DIRECT_COND | 初始位移＋TCN 整段相对位移 | 三阶段、三种子 |
| 5 TCN_BRES_COND | 连续 B+＋TCN 整段残差 | 三阶段、三种子 |

DRIFT1 是简单的恒速度外推基线，不是深度学习模型。它只使用预测起点以前最后两日实测位移，整段不更新；其“训练段拟合分数”记为不适用，不伪造重构曲线。

RR_COND 用相同输出单位、全部训练日期及归一化目标，拟合确定性四输出岭回归；只使用当前日特征，不具有 TCN 的 61 日卷积记忆。它是普通机器学习对照，不复用旧 RR_DIRECT 的七天权重。C16、旧 ConvLSTM/PINN 和 Mamba 不参加本轮选模或达标门槛。

概率层先以各方法已发出的四点均值计算误差，再对每点采用 `sigma_p = max(sqrt(mean(error_p^2)), 1e-6 mm)`，不另行偏移均值。开发尺度来自内部选定模型后 90 日误差；最终尺度来自开发最后 90 日误差。三个种子先平均再校准，主分布为该均值与共同尺度构成的高斯分布。

每个预测段发出时即固定四个尺度，整个段内不读取新位移、不更新误差池。保存 80%、90%、95% 区间，复用原 Gaussian CRPS 与区间评分公式。B+ 也使用自己的同规则误差尺度，报告中写为“B+＋统一误差校准”，不把它称为原物理模型固有的概率输出。

**校准限制：** 这是独立整段预测下的新校准安排，不能直接复用七步长在线误差池或上一轮 293 日递推尺度。90 条连续误差相关，且内部→开发→最终发生重新拟合，存在尺度迁移误差；无有限样本覆盖保证。固定尺度意味着同点同段区间等宽，不为模仿参考图形状而人为扩缩。区间为逐日期边际区间，不是整条轨迹同时覆盖带；驱动预测误差未纳入。

## 6. 如何判断训练和预测效果

所有方法报告完整预测段的逐点 MAE、RMSE、CRPS、区间评分、覆盖率和宽度，另报四点指标的等权平均。90% 区间为主要概率评分口径，80%/95% 为补充。平均 RMSE 按“先逐点 RMSE 再平均”，不与全部点日合并 RMSE 混用。

训练段另报 B+、RR 和两臂的拟合 MAE/RMSE，使用同一完整训练日期；不把训练误差下降当作预测收益。主图保留开头 60 日，并说明因果填充，不删难点或末段。

下列为**本计划提出的工作条件，非导师已规定的数值阈值**，实施冻结后不按成绩改变：

- 对 B+ 的均值收益：完整窗四点平均 MAE、RMSE 均至少降低 1%，且各点 MAE/RMSE 不高于 B+（仅允许 1e-6 mm 的复算容差）。训练段是否同样接近实测、优于 B+ 单独给结论。
- 对 B+ 的概率收益：平均 CRPS、90% 区间评分均至少降低 1%；各点评分相对退步不超过 5%；90% 覆盖平均至少 85%、各点至少 80%。宽度同时展示，不把加宽带来的覆盖提升单独称为成功。
- 对简单/普通机器学习对照的收益：分别列相对 DRIFT1、RR_COND 的平均及逐点变化，说明是否两种均值指标、两种概率评分均改善；不能用“超过 B+”替代这两个结论。
- 残差输出收益：完整窗 BRES 对 DIRECT 的平均 MAE/RMSE、CRPS/区间评分分别判断。集成均值两指标均改善且至少 2/3 配对种子方向一致，才记为“本窗残差均值收益”；概率同理另判。开发和最终方向不一致时写为不稳定，不能宣称已普遍有效。

“代码核验通过”“工作条件通过”“导师认可”分别记录。所有数值条件只是有界实验的工作判据，不等价于统计显著性、机制证明或真实预警有效。导师关于尾部可暂不追求的表述未给删日期授权，完整 376/293 日结果和逐日误差都保留。

B+ 的数值检查不等于 TCN 满足物理方程；本模型不称为 PINN。神经输出负增量、误差爆大或区间覆盖差都原样记录，不通过截断、平滑或挑日期修饰。非有限值或来源/隔离失败时先保留失败记录，只阻塞依赖该失败的工作；不得拿有限前半段冒充完整评价。

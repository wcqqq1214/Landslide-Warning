# 2×2消融图件约定 v1.0

在制图前制定；评分已锁定，图件不用于重新选模。后端沿用本任务已确定的Python/Matplotlib。

1. **问题与核心结论**：起点残差表达与边界采样能否降低原GRU误差、能否超过B+？现有锁定结果显示改善原GRU，但最终完整窗仍落后B+。图中同时展示改动效果和基线差距，不将二者混淆。
2. **证据链**：总览a为完整293日RMSE（主要均值目标），b为第1天四点平均绝对误差（预定起点诊断），c为完整窗CRPS（概率目标），d为RMSE两因素主效应与交互（配对归因及非加性）。前三面板展示同样的三种子离散值和三种子平均预测的评分；d展示对应同种子效应与集成效应，不把种子作为独立自然重复。另四图各四点，按事前顺序G00/G10/G01/G11展示最终完整时间轴、所有种子与80/95%边际预测区间，定位点别和时间变化；未画不存在的神经训练段拟合曲线。
3. **类型**：定量2×2网格。总览解释因子效应，曲线图解释误差发生在哪些点/日期。所有三窗、四点、三个种子保留于CSV/数组；四点曲线统一使用最终8:2窗，历史两窗未被删除或用来重选模型。
4. **数据和统计**：四点、293日、种子0/1/2，均值为三种子等权预测后计算各点评分再平均。每个方法使用自己上一条已发路径第91—180日90条成熟误差的逐点RMS，固定高斯区间；种子线复用集成尺度。无独立样本置信区间、显著性检验或p值；历史窗重叠/已暴露。所有曲线仅减去各点初始位移，未平滑、删点或裁去困难尾段。
5. **导出及阻断核验**：面向导师屏幕展示，240×170mm，PNG 300dpi及可编辑文字SVG；不交付PDF。字体至少7pt。相同点在四组曲线中使用共同纵轴范围，包含所有观测/三种子/完整95%区间，图注说明给定未来降雨/水位及无位移反馈。最终绘制后须通过1.5pt多面板对齐、文本边界与碰撞、原数组到实际SVG路径的数值核对，并逐张目视。自动PDF字形/碰撞核验仅用临时目录内的同源QA载体，不作为科研图件交付或提交。

源数据、图形坐标记录、核验回执和每图说明与PNG/SVG一并保留；全部负结果保持。若排版核验阻断，只更改排版后重新核验，不更改数据、模型、区间或评分。

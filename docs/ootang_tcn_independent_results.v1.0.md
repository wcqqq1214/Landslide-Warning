# TCN 8:2 独立预测对比报告

2026-09-14 · 藕塘四监测点 · 完整293天探索性评价

**参照导师图的布局和无位移反馈方式，已完成两版TCN的四点对比图。结果没有达到提高独立预测精度的目标：四点平均RMSE为B+ 10.17 mm、TCN直接版90.73 mm、残差版211.83 mm。** 两版TCN在四个点的MAE、RMSE、CRPS和90%区间评分均落后B+与简单速度外推；残差输出在本次长期递推中进一步变差。

本轮复用此前已训练的固定短期TCN，以自身输出递推293天，新增训练为0。该结果说明**这组固定七天TCN的长期递推方案失败**，不能据此判断所有TCN长期预测方法无效。此前每天接收新观测的1—7天滚动结果单独保留。

## 实验方式与DRIFT1含义

原1461日数据按前1168日（2016-07-01—2019-09-11）与后293日（2019-09-12—2020-06-30）切分。2019-09-11观测结束后一次发出完整预测，预测期不再接收实测位移、降雨或库水位。降雨始终取起点前七日均值，水位始终取起点最后观测值；B+保留起点前完整物理历史及原参数。这里对齐8:2切分与无位移反馈方式，未复现导师图的模型H/QRF及其全部驱动设置，原图数值不用于本轮结论。

TCN_DIRECT预测相对当前历史末值的增量；TCN_BRES预测相对B+增量基线的残差。两臂沿用同一小型因果结构、30日观测输入、float64、三个种子及固定400次检查点，每次输出未来7×4位移。各个种子将自己的七天预测追加为下一块历史，共42块，最后一块使用6天；全部293天轨迹形成后再等权平均。两臂都能读取合法物理特征，配对仍检验残差输出方式，不等于有/无物理信息消融，也不称PINN。

**DRIFT1是“最近一天速度不变”的线性外推基线，不需要训练。** 若最后观测时刻为t，第h天预测为 `y(t)+h×[y(t)−y(t−1)]`。例如昨天99.5 mm、今天100 mm，则按每天0.5 mm外推，第7天为103.5 mm。本次293天始终使用起点的同一速度；此前滚动任务则每天收到新观测后重新计算速度。

每个点、每个预测距离的区间尺度，使用训练期内最近90份已兑现的同距离独立回放误差RMS。所需382个起点786—1167均完整回放，模型训练前缀分别为612/792日，误差目标全部在1168之前；最终预测均值和尺度在读取本轮评分标签前保存锁定。重叠误差相关，90份预测不等于90个独立样本，区间属于经验高斯边际区间，没有联合覆盖保证。

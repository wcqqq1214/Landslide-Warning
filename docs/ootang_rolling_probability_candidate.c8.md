# C8：预测兑现后更新均值回归系数

2026-09-13；同一八小时预算内第八个主要候选。沿用 [C7 追加范围](ootang_rolling_probability_extension.v3.6.md)，原截止 **05:27:52 UTC**、累计最多九候选不变。后期依然是已暴露数据上的探索性复核，不是新的独立迁移。

## 依据与待检验问题

C4 已有平均均值收益，但后期覆盖不足；C5—C7 修改尺度训练或分布形状都没有稳定解决概率覆盖。源码显示，C4 的近期观测每天进入特征，回归系数却在整个评价阶段固定，新到期的预测误差只参与区间校准。本轮检验**把已经兑现的监督样本用于更新均值映射，是否可以降低后续误差并改善概率质量**。

这不是已经证明了参数漂移，也不保证在线更新比固定模型好。[statsmodels 的递归最小二乘说明](https://www.statsmodels.org/stable/examples/notebooks/generated/recursive_ls.html)支持利用不断扩大的样本集更新回归系数；本项目使用带固定正则项的增量充分统计量与小矩阵求解，不调用其 OLS 模型、不套用其统计检验或协方差结论。

## 唯一主要变化

回到 C4 的高斯原始尺度、90 项 RMS 误差校准、固定伪样本和 0.02 延迟覆盖反馈。只改变 FULL/DATA 的均值系数；原 alpha=0.001、四/六输入维度、特征 RMS、目标 RMS、尺度两参数、物理教师与所有规则保持。

每个阶段从该阶段 C4 保存的均值模型开始。用其原训练样本重建归一化特征 X 和目标 z，设 `A=XᵀX+N0*alpha*I`、`b=Xᵀz`；初始系数直接保留原保存值，首个预测必须复现 C4。这里 `N0*alpha` 在本阶段固定，后续没有重新选择正则强度、重新标准化或遗忘因子。

每个起点保存当时的特征 x、DRIFT1 基准 d、步长和四点预测。目标位移 y 兑现后，先为当时发出的区间记录误差，再把该监督样本加入相应点位/步长：`A←A+xxᵀ`，`b←b+x*(y-d)/target_scale`，求解 `A*beta=b`。更新仅供下一起点使用；不重算过去的预测、特征或区间，不把未兑现的 30 日目标当作已知标签。

初始化样本集合严格保持原 C4，不额外补齐短步长已知但原训练未使用的查询。各阶段结束时保存最后一次成熟更新后的系数，但末次更新不会回写之前的输出。开发和后期各自从原 792/1168 日模型初始化，不根据开发效果选择是否更新后期参数。

## 配对对照与公平边界

- 主候选 `C8_ONLINE_FULL`，DATA 保持独立消融。固定系数 `C8_STATIC_FULL/DATA` 直接保留 C4 分布，不能在结果出来后拼点或互换主候选。
- B_ANCHOR、DRIFT1 和全部原简单对照继续使用 C4 完整保存输出；信息条件与当前位移可见范围相同。模型是否用这些已知信息更新参数是算法差异，不声称 B+ 也进行了每日物理重标定；B+ 仍固定阶段参数并更新位移锚点。
- 在线候选的 raw_sigma 与 C4 每起点相同，新的区间差异只来自在线模型实际发出预测后的误差。原均值、物理曲线、固定对照和失败记录不覆盖。
- 不使用 C7 的经验分布，也不追加分布超参数。本候选属于在线监督机器学习，不是 PINN 或已经验证的贝叶斯后验模型。

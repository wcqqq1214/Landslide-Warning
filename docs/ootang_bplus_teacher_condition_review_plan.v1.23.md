# 藕塘教师条件与时序表达审查 v1.23

## Material Passport

- 日期：2026-09-11；Origin Skill/Mode：academic-research-suite / experiment-agent / plan。
- 依据：持续目标“根据你的建议，一步步推进”及
  [v1.22 结果](ootang_bplus_input_transfer_results.v1.22.md)的后续出口。
- 本版为来源/方法审查，不运行新的模型效果对照，不改旧实验设计、结果或概率标准。

## 1. 要回答的问题

1. 当前 23 通道模型显式接收了哪些教师、历史及阶段信息？物理教师参数、教师身份、
   原点日期、预测步长、近期实测和物理状态分别通过什么路径进入；不能把隐式物理
   轨迹信息说成完全没有教师信息，也不能将缺少显式标记认定为已证实根因。
2. 原 paired 与 anchor 含多少不同教师/起点组合？同一个教师是否跨多个外推起点，
   教师与时期是否在该样本设计中可分别比较？重复日期、四点和种子不算独立教师。
3. 物理输入窗口、历史观测窗口及隐藏状态推进的时间含义是什么？与原 M1/M2、
   状态 PINN 和共享力学方法的既有尝试有什么实际区别？不把设计差异自动叫成 bug。
4. 导师 B+ 原稿/完整交付与公开方法原文支持哪种有限改法，其数据和推断条件又有哪些
   不满足？得到有依据的方案取舍，不直接根据外层成绩增加参数或更换最终模型。

## 2. 固定核对范围

- 冻结 v1.22、v1.21 和来源链，保留全部负结果；四点、旧切分、已知未来水文驱动和
  原日值 as-of 未知的条件回测边界保持。零新神经求值/梯度/训练、物理积分/拟合、
  回归/scaler/概率尺度拟合；不做新的距离、邻居、超参数或预测成绩扫描。
- 读取当前源码的输入名称、窗口日期和模型调用路径，记录准确文件/符号位置。
  原方法依据实际读取 `manuscript.pdf` 对应页以及 ZIP 内完整交付的相关文件；先
  核对 PDF 结构读入状态，原稿与同内容 PDF 不算两份独立证据，原件不改。
- 从冻结 `pairs_342/432/612.csv` 与 `teachers.json` 重算两来源、两块的教师/起点
  清单、行数、不同目标日、lead 范围；核对教师参数向量的身份、维数和来源。
  这些仅是样本覆盖审计，不拟合“教师→误差”回归或据维数推断信息上限。
- 显式列出原窗口的物理日期 [t−29,t]、观测日期 [o−30,o−1] 与 lead=t−o，
  核对相应位置日期偏移及状态重置方式，不调用网络寻找效果。
- 公开文献仅使用原论文/作者或出版方原文，限于与本问题有关的时序编码、已知未来
  输入、物理条件表达和概率递推。检索公开书目信息，不上传项目原稿/数据。

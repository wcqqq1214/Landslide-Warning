# 夜间小图图件合同 v1.0

用途：供用户与导师查看的紧凑科学图，不冒称期刊投稿版。沿用当前任务已确定的Python/Matplotlib后端和原导师四点排列，所有图由保存数组生成，无训练或推断。新授权允许PDF；采用Matplotlib原生矢量PDF保持科学图元与SVG一致，不引入另一个绘图后端。

核心结论：全历史GRU仍无跨时段稳定均值改善；仅增加MJ3—MJ1边的收益很小。最终概率评分局部改善保留。预定因果残差诊断没有支持双头模型启动。

## 证据顺序与版式

一份6页PDF，每页240×170mm：

1. 跨时段比较，四面板依次为平均RMSE/B+、图相对本点的同种子RMSE差、最终各点RMSE、最终各点CRPS。前者定位时段依赖，第二项隔离图边增量，第三项说明空间误差，第四项区分均值与概率收益。B+、DRIFT1、旧半残差、旧起点条件化和两版GRU的完整表留在CSV；图中旧候选只作具名上下文，不按点拼接。集成值是三种子平均预测的评分，浅色小点保留所有三种子评分，无显著性符号/置信区间。
2. GRU_GRAPH导师式四点完整历史与最终293日，固定导师纵轴。
3. GRU_LOCAL同样四点、同坐标及区间定义。
4. 因果残差尺度诊断：四点分别展示四块fast方差/总残差方差，统一纵轴及0.1预定参考线；另标同驱动/滞后/符号同时满足方差/相关条件的最多块数。原16方差/96相关记录全部链接，不能把方差比当解释方差或相关当因果。
5—6. 第2—3页的完整纵轴副本；坐标含全部均值、实测和95%区间。第2页95%越界日为0/0/248/1，第3页为0/0/255/1，均值/实测不裁剪；越界不改变任何评分。

导师曲线页固定ATU1/O3、ATU5/O2、MJ3/O1-up、MJ1/O1-down，实测黑线、B+灰虚线、神经预测蓝实线、80/95%浅深蓝阴影；历史淡蓝/预测淡橙背景，完整293日分界。历史区只展示实测+B+，不伪造GRU训练段重构。无顶部三角箭头。逐点RMSE注释放在轴外避免遮挡曲线。

## 导出与QA

PNG300dpi、保留文字的SVG和嵌入字体的原生矢量PDF；PDF字体下限5pt，正文图字通常7.6—12pt。保留图元坐标与源表、逐点裁剪计数、源哈希与图件manifest。每页2×2最终绘图区1.5pt严格对齐；运行源代码静态检查、PDF字体和碰撞检查。以实际SVG顶点/标记独立核对原数组/表，导出的PDF逐页Poppler渲染并逐面板目视。任何真实遮挡先修复导出，不用遮白块掩盖；保留原失败预览与修订原因，不动科研数据。

## 唯一变化及计算定义

原KIN函数记作F(y历史,x协变量)，输出294个起点增量槽位h=0…293，原输出为raw(h)−raw(0)。新`TiDE_KIN_PREFIX`定义为：

`q(h) = F(y历史, P_h(x))[h]`。

P_h完整保留180日历史和未来槽位0…h；未来j>h的标准化驱动/K及known设0，相对距离编码保留，H仍关闭。**同一次P_h输入内同时计算raw(h)和raw(0)**；不能让原全路径raw(0)绕过隔离。由此h293在相同权重下等于完整原F的h293，h0恒为0。各距离可使用截至自身的整段条件驱动，而非只读当天；预测期仍不反馈位移。

新实现复用原全部110392个参数、名称、初值和残差密集块。通过“全掩码未来特征的基值＋逐槽位贡献的前缀和”计算各距离的编码器仿射值；非线性与对应h/0解码权重逐距离应用。这是原F在P_h上的等价加速实现，必须用显式逐h屏蔽再运行原F校验输出和梯度，不能用近似代替。若等价核验不通过，修复实现并留档，不静默更换结构或定义。

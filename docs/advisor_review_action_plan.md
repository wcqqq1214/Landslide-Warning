## 1. 总体判断

本轮意见属于一次跨模块的实质性调整，不是简单补图或润色。十条意见可归并为五条工作线：

1. 统一速度、变形速率增量 `ΔV` 和改进切线角的定义与单位；
2. 补全 ConvLSTM 全测点、全时间段结果，并明确 SHAP 的解释对象；
3. 将预警体系改为“区间、速度、变形速率增量 `ΔV`、改进切线角”四指标并列输入；
4. 以五级透明规则融合为当前正式预警路径，逐时刻输出单测点和多测点综合预警；只有取得独立标签后，才将 NGBoost 作为另行验证的监督分支；
5. 先完成藕塘滑坡全链路重算；Vajont `10d` 数据保留为后续补充案例，不阻塞本轮主线。

这会影响特征工程、阈值与标签、模型输入、类别编码、评估指标、图表、管线产物和论文表述。旧结果不能在更换定义后继续沿用，必须在协议确认后整体重算。

## 3. 已核对的当前实现与主要差距

### 3.1 速度定义并不统一

- `code/features/build_features.py:56-60` 已按日差分计算速度和加速度：`a_i=(v_i-v_{i-1})/Δt_i`。对当前连续日数据而言，速度实现与导师提出的逐点速度一致；但现有加速度不能直接改名为本轮确认采用的 `ΔV`。
- `code/warning/warning_thresholds.py:75-89` 仍使用 `U_t-U_{t-30}` 构造所谓 30 日“速率”，本质是 30 日位移增量，没有除以时间。
- 因此 R1/R7 不是局部改名，而是会改变特征定义、阈值、等级、融合结果、SHAP 分类目标和敏感性分析的跨模块方法变更。

### 3.2 ConvLSTM 已计算 8 个测点，但图只展示 3 个测试段

- `code/convlstm/model.py:30-34` 定义了 8 个位移测点，但 `PLOT_STATIONS` 只包含 `MJ9`、`MJ1`、`MJ3`。
- `code/convlstm/model.py:872-886` 只绘制最后测试段；训练拟合段和独立校准段没有进入当前主图。
- `figures/convlstm/forecast_metrics.csv` 已有 8 个测点的原始/校准指标，说明模型输出不是只有三条线，当前主要缺口是可视化和完整逐时刻预测产物。
- 训练段拟合只能作为拟合诊断，不能与留出段性能混合汇报。

### 3.3 当前 SHAP 并不直接解释 ConvLSTM

- `code/explainability/shap_select.py` 当前重新训练 NGBoost 回归器和分类器，再进行 permutation SHAP。
- 回归目标是位移增量，分类目标是当日动态 V0 状态；当前 SHAP 不是 ConvLSTM 的 SHAP。
- 原意见中的“ConvLSTM+SHAP”没有明确 SHAP 是否必须直接解释 ConvLSTM。按当前代码，本轮采用“ConvLSTM 负责位移区间与覆盖评价、独立解释模型的 SHAP 负责候选主控因素”的实施解释；这不是导师已明确确认的网络解释架构。
- 当前结果必须如实写清被解释模型、目标、样本和局限，不得写成 ConvLSTM-SHAP。若后续决定要求 SHAP 直接解释 ConvLSTM，再新增深度模型解释流程和验证协议，不覆盖本轮独立解释结果。

### 3.4 当前预警结构与导师要求不同

- 当前 `code/warning/warning_fusion.py` 明确采用 V0 主判、切线角只升级不降级、NGBoost 概率仅作旁证。

#### 4.2.1 指定论文与原始切线角文献的核验结论（2026-07-16）

已核对导师指定 Word 论文第五章及仓库中的许强等（2009）原文
[`一种改进的切线角及对应的滑坡预警判据`](../literature/一种改进的切线角及对应的滑坡预警判据_许强.pdf)。可直接采用与必须冻结的内容应严格区分：

### 4.3 已确认的 P0：区间指标的逐时刻偏离状态识别

本轮选择“逐时刻区间偏离状态识别”，而非在 `t` 时刻对 `t+h` 的严格前瞻预警。对每个有效时刻 `t`，执行顺序为：

1. 仅用预测发布时刻以前的历史信息，对目标位移 `U_t` 产生 P10/P50/P90；
2. 在 `U_t` 实际被观测到后，判断其落在预测分布的哪个区域；
3. 输出该时刻的 `interval_level` 和触发依据，作为“区间偏离状态预警/状态识别”。

这与参考论文第五章按当前观测位移相对预测概率密度位置进行分级的实现方式相近，但本轮不据此宣称有 `h` 天提前量。若以后要研究严格前瞻预警，必须另行冻结预测步长 `h`、物理风险阈值 `H`、事件标签和独立评价协议，例如在时刻 `t` 评价 `P(U_{t+h} \ge H \mid \mathcal{H}_t)`；它不属于本轮正式结果。

#### 4.3.1 论文启发的五级映射及适用条件

参考论文的图 5-1 将观测位移相对预测均值 `μ` 的右尾偏离划为五个颜色区域。本轮仅在下列校准门禁全部通过后，采用相同的区域思想：

1. **分位数有效性**：每个有效时刻的分位数均为有限值，满足 `P10_t \le P50_t \le P90_t` 且 `P90_t>P10_t`；
2. **覆盖率校准**：在拟合/校准阶段，P10-P90 的经验覆盖率满足预先写入配置的 80% 区间容差；
3. **近似对称性**：在拟合/校准阶段，`P50_t` 与 `(P10_t+P90_t)/2` 的偏差满足预先冻结的容差。该检验只允许把下述换算当作工程近似，不宣称已经证明完整正态分布。
4. **尾部适配诊断**：在拟合/校准阶段，以标准化残差检验右尾偏离的可解释性，并在配置中预先写明诊断方法、最小有效样本数和接受条件。P10/P90 本身只覆盖中心 80% 区间，不能单独证明 `3σ` 尾部可用；缺少这项证据时不得输出论文启发的 red 区间。

通过门禁后，定义：

```text
μ_t = P50_t
σ_t = (P90_t - P10_t) / (2 × 1.28155)
z_t = (U_t - μ_t) / σ_t
```

其中 `1.28155` 是标准正态分布 90% 分位点；该换算对应 P10/P90 近似为 `μ_t±1.28155σ_t`，而不是 `μ_t±3σ_t`。随后按下表输出五级状态：

| 等级 | 颜色 | 条件 |
| --- | --- | --- |
| 0 | green（正常） | `U_t \le μ_t` |
| 1 | blue（低风险） | `μ_t < U_t \le μ_t+σ_t` |
| 2 | yellow（中风险） | `μ_t+σ_t < U_t \le μ_t+2σ_t` |
| 3 | orange（高风险） | `μ_t+2σ_t < U_t \le μ_t+3σ_t` |
| 4 | red（极高风险） | `U_t > μ_t+3σ_t` |

论文图示将低于预测下界的观测值视为安全；上表的 green 区间同样覆盖该情形。边界归属、指标单位和无效/暖启动状态必须写入版本化配置，并在逐时刻 CSV 中同时保存 `μ_t`、`σ_t`、`U_t` 和触发区间。

#### 4.3.2 未通过校准门禁时的处理

若运行版本未通过任一全局校准门禁，不得为了输出五种颜色而强行将 P10/P50/P90 解释为正态分布，也不得在测试期反调模型、分位数或容差；该版本的正式区间等级应标记为 `interval_level=not_applicable` 并记录失败项。若个别时刻存在非有限分位数、分位数交叉或暖启动，则标记该时刻为 `interval_level=invalid`。若仍需要区间五级状态，必须另立一套经验分位数或额外分位数输出的适配协议，在不含测试集的数据上冻结和校准后重新运行；该方案不能被写成对参考论文 `μ/σ` 映射的直接复现。

### 4.4 Vajont 的验证范围（P2，延后）

Vajont 不阻塞藕塘开发和重算。该阶段设为**用户授权门禁**：即使藕塘协议及结果已经完成，仍须获得用户明确允许后才能启动；未获允许时只保留现有审计记录，不开展数据适配、实验或结果生成。获准后再冻结其空间位置、外部驱动、时间切分和可用独立事件资料；缺少这些信息时，只能验证位移运动学和规则的可迁移性，不能声称完成空间 ConvLSTM 的跨滑坡验证。

### 6.1 数据门禁

### 6.2 科研门禁

- 阈值、标准化、特征选择和超参数仅由拟合/校准阶段确定；
- 区间状态识别的预测必须在目标 `U_t` 被观测前发布；观测后的分级不得表述为 `h` 天前瞻预警或提前量；

- 同日多个测点不可跨训练/测试集合；
- 测试集不得用于选择规则；后续启用 Vajont 时，其外部结果同样不得用于反向选择藕塘规则；
- SHAP 不使用因果语言；
- 训练段拟合不作为泛化性能；
- 本轮透明规则融合不声称获得独立监督预警有效性；若以后引入 NGBoost，必须先取得独立标签并单列评价；

1. 将已确认的 R1/R4/R5/R7/R10 及 R3 的当前实施解释写入配置模板和方法说明，不把独立 SHAP 路径表述为导师已确认的 ConvLSTM 直接解释架构；
2. 建立藕塘重算清单和旧产物快照，核对 8 个测点的输入日期、缺测、单位和当前切分；
3. 开发逐点速度/`ΔV` 特征、全测点预测输出、独立 SHAP 说明和规则融合框架；
4. 建立只包含藕塘的可复现运行清单，列明每个受影响旧产物的替换关系。

### 正式结果前必须冻结

1. 写入并完成区间校准门禁；只有通过后才采用 `μ_t/σ_t` 五级映射，未通过则按冻结协议标记不可用或启用独立适配方案；
2. 使用拟合/校准数据确定速度边界、`ΔV` 的“近零”容差及过程规则、以及规则融合表；
3. 冻结四指标到测点、再到滑坡体的规则函数与缺失/暖启动处理；
4. 生成正式多测点综合预警，并同步藕塘方法、结果和限制文档。

### 延后到藕塘重算完成后

1. 等待用户明确允许启动 R6（Vajont）；未获允许时不开展后续工作；
2. 获准后确认 Vajont 的验证范围，并建立 `10d` 只读数据适配与质量审计；
3. 生成五曲线逐时刻及综合预警结果；
4. 将其作为补充外部案例单独报告，不回调藕塘阈值或模型。

### 不建议现在做

- 在旧四级标签上继续扩搜 NGBoost 参数，或把规则输出再训练成“分类器”；
- 只改 `Vt` 一处公式后保留旧结果；
- 把现有 NGBoost-SHAP 图写成 ConvLSTM-SHAP；
- 为追求更高覆盖率而根据测试集结果调整分位数，或后续用 Vajont 结果反调藕塘方案；
- 将规则融合的内部一致性或分类准确率写成独立监督预警有效性。

# C10：对旧监督逐步减权的在线概率回归

2026-09-13；承接用户同一约八小时自主任务与第三次路线复盘。本文件仅新增第十个主要候选，不改 C1—C9 的配置、结果或判断，也不预先安排 C11。总起点 2026-09-12 21:27:52 UTC、截止 **2026-09-13 05:27:52 UTC** 保持，运行局部上限 20 分钟。所有准备和核验继续计入同一总时间；不以阶段候选上限代替用户任务完成。

## 依据与唯一假设

C7—C9 未完整解决后期概率问题，第三次复盘停止继续改变经验分布/尺度头。C8 的均值确有小幅改善，但其扩展训练集让所有监督等权：开发/后期初始化 511/887 行，在最后一个可评分 30 日起点只新成熟 317/234 行，新监督行的权重占比为 38.29%/20.87%。这属于算法与保存查询的事实，不是独立有效样本数，也不能证明参数漂移就是失败原因。

本候选只检验：**逐步降低旧监督权重，是否使同一 Ridge 映射更有效地利用新观测，并改善完整 30 日均值和概率结果。** 不新增网络、不修改数据、输入特征、预测步长或尺度训练。

Yuan 与 Lamperski 的原始研究讨论了递归最小二乘中的遗忘因子及稳定学习与跟踪变化之间的权衡。本次核读摘要、第 1—2 节与 Algorithm 1（PDF 第 1—4 页）；没有全文复现或核对全部证明。[原文](https://arxiv.org/pdf/1909.03118)。项目采用保留固定正则项的加权平方损失，未核对论文定理所需的全部紧集/梯度等条件，不借用其理论界或声称收益有保证；90 也不是论文推荐的藕塘值。

## 事前固定的学习规则

每点每步长沿用 C8 的原初始化均值、固定特征 RMS、目标 RMS、alpha=0.001、无截距回归和全部原监督。初始化样本仍等权，保持首次预测与 C8/C4 精确一致。

设初始监督数为 N0，原正则矩阵 `R=N0*alpha*I`，原正规矩阵 `G0=X0.T@X0+R`、右端 `b0=X0.T@z0`。每收到一条该步长已经发出且到期的新监督 `(x,z)`，执行：

```text
lambda = exp(-1/90) = 0.9889503892939223
G <- lambda*G + (1-lambda)*R + x*x.T
b <- lambda*b + x*z
beta <- solve(G,b)
```

正则矩阵 R 不衰减，防止把更少数据和正则约束一起抹掉。经历 m 次成熟更新时，原始监督的共同权重为 `lambda**m`，第 i 条追加监督权重为 `lambda**(m-i)`；对应同一显式加权 Ridge 目标。指数衰减保留非零长尾，不等于硬截断 90 日窗口。

唯一遗忘尺度固定为 **90 次成熟更新**，对应已有概率校准使用的约季度量级，属于本次事前工程选择，不是数据估计的最优值。每天最多每步长一次成熟更新；尚无新到期监督时不衰减，尤其长步长初期不伪造历史预测。不试 30/60/180 或其他遗忘尺度，不按点选择参数。

原始概率尺度完全复制 C8，不重新拟合；仍按新均值实际产生的已成熟误差执行原 90 项 RMS 校准、原 0.02 反馈和 0.01 mm 数值下限。没有使用 C9 的拆分尺度或 C7 经验分布，避免同时改变均值与概率结构。

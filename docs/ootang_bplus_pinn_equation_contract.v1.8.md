## 2. 空间、状态和观测对象

原模型是四坐标 Ritz 降阶系统。代表域为 O3、O2、O1_up、O1_down，测点为
ATU1、ATU5、MJ3、MJ1，两种轴不能混用。由原几何构造的 T 把九维几何表示降为四坐标；
观测矩阵 O=`a['observation'] @ T`，四点相对首日位移为 Oq。

采用原 C 代码的状态名称，列向量约定下：

- s：运动响应；p：累积不可逆滑移；b：背景位移；q=s+b；
- r_b、r_c、r_E：基底、接触、体内反力，各为四维；
- y=y0+Oq。只有此式输出四个指定测点，不能把四个 q 直接称为四点观测。

b 完全已知时，需要表示的独立力学状态为 s、p、r_b、r_c、r_E，共 20 维。
若允许学习 b，则状态为 24 维，并且必须另给 b 的演化约束；不能把自由 b 当作未经约束的
逐点残差塞进观测方程。原首日六组四维状态均为 0，y0 只从共同首日观测取得。

此接口是降阶系统，不是新增一套未经资料支持的二维 PDE，也不声称四测点足以辨识完整
二维时空场。当前范围仍只评价四点位移。

## 3. 与原子步更新等价的约束

以下是对原源码的代数整理，尚待独立单元及数值核验。子步长度 dt=1/64 日，原日级
F_t、弹性项 epsilon_t 在当日子步内保持，背景 b 由相邻日值线性插值。

定义：

`alpha_r = 1/(1+dt/tau_rest)`（四维），
`alpha_c = 1/(1+dt/tau_contact)`，
`alpha_E = 1/(1+dt/tau_bulk)`，
`beta = dt/(tau_motion+dt)`（四维）。

eta=`exp(theta[8:12])*length`；k_r=`exp(theta[12:16])*length`；其余时间常数、K_c、K_E
继续使用原参数、几何和变换。`*` 对向量表示逐元素乘；刚度矩阵作用用矩阵乘。
不得混淆原 54 参数中的线性存储与对数存储。

对子步 k→k+1，记 Delta p=p_(k+1)−p_k、Delta q=q_(k+1)−q_k：

1. `s_(k+1)−s_k = beta * (p_(k+1)+epsilon_t−s_k)`。
2. `r_b,(k+1) = alpha_r * (r_b,k + k_r * Delta p)`。
3. `r_c,(k+1) = alpha_c * (r_c,k + K_c Delta q)`。
4. `r_E,(k+1) = alpha_E * (r_E,k + K_E Delta q)`。
5. `g = eta * Delta p/dt + r_b,(k+1)+r_c,(k+1)+r_E,(k+1)−F_t`。
6. `Delta p >= 0, g >= 0, Delta p * g = 0`。
7. `q=s+b`，以及原 b 演化关系或另版明确的本构修正关系。

等价性依据：原活动集变量 dx=beta*Delta p；原代码的 `du=k0+dx` 等于 Delta q。
将三类反力更新代入第 5 式，可整理为原 `A dx−rhs`，因此第 6 条与原互补问题等价。
这一步应通过随机合成状态的代数恒等式及原子步轨迹检验，不能仅凭推导文本宣布实现通过。

原背景为含水慢蠕变积分加 Kelvin 初始松弛项。它可能含下降的初始松弛贡献；约束对象是
不可逆滑移 p，而不是未经区分地要求 q 或每个测点位移每天单调。

## 4. 可学习对象决定是否有超越 B+ 的空间

若保持原参数、驱动、背景关系和初值，且每步互补问题解唯一，则精确满足全部离散约束
会复现 B+。仅用 PINN 替换数值求解器并不能在这种条件下产生另一条更准确的物理解。
这是上述离散系统的条件性推论，不是新实验结果。

因此进入训练前必须明确选择允许学习的对象，例如受约束的本构偏差，或明确范围内的
参数反演；同时说明哪些原方程保持、哪些关系发生了有版本记录的变化。如果只允许物理
残差不为零来换取数据拟合改善，必须定量报告违约程度，不能写成更符合原 B+ 力学。

v1.1 的 M2 已经学习有限的背景蠕变倍率并在求解器内部反馈，它是方程嵌入混合模型。
把该网络改名 PINN、只加入 B+ 特征、只惩罚离 B+ 曲线的距离，或只限制观测修正的幅度，
均不能代替本文件列出的状态方程残差构造。旧 M2 的有限负结果继续保留。

# TiDE分开编码与受限H融合：研究记录 v1.0

## Material Passport

用户在K/H输入消融完成后授权“继续验证假设”。本轮检验将B+运动学K与水文状态H分开编码，再限制H附加贡献，能否得到跨时段收益。输入为四点原数据、原合法B+缓存及1272项冻结来源；未引入新案例或外部有效性结论。分支`codex/tide-hydro-fusion`。UTC日期2026-09-15，本地完成日期2026-09-16；目录继续使用冻结的UTC日期。

**固定实验和核验已完整完成，但“这种融合能稳定超过原KIN/PHYS”的假设未获支持。** BOUND相对SPLIT的平均MAE、RMSE、CRPS与90%区间评分三窗均降低，说明这套限幅训练政策减轻了无约束版本的退步；两个新版本的平均MAE/RMSE三窗仍都高于旧KIN。BOUND最终平均RMSE仅比B+低0.943667%，未到原1%均值门，且逐点均值与区间保护失败。

## 固定比较及边界

新增SPLIT/BOUND均从同初值联合训练主支与H支，不预训练旧KIN再追加。主支保留原KIN的110392参数；H支读取H三列、相对距离、known标记及独立点ID，新增13179参数；两新版均123571参数。BOUND仅把起点化H分量替换为`cap*tanh(H/cap)`，cap为当前训练前缀内30日位移变化的RMS、下限1mm。主支与H支都会在这种训练政策下改变，所以并非事后裁剪同一份预测。零H只回退该模型自身主支，不能当作旧KIN的精确预测。

旧KIN/PHYS的24拟合120检查点精确复用；新增两组24拟合9600更新120检查点。共同180日历史、三种子0/1/2、float64、Adam .001、批量8起点、固定400更新及e0/50/100/200/400，无本轮选模。与旧KIN/PHYS还存在约12%的容量差异，不作容量匹配的单因素结论。

四次发报612/792/972/1168各完整293日，612只启动校准，后三窗全部评分。给定完整未来降雨/水位，没有预测期实测位移反馈；这仍是条件预测，不能当作未来驱动未知时的293日独立预报。全路径驱动可影响较早输出，180日神经历史不是完整历史状态。训练伪起点只用合法历史与已成熟目标，拟合前缀外驱动和标签同时掩码。B+完整状态读原缓存，新增物理前向/重拟合0；972仍用792拟合参数。

概率层沿用各方法自身上一已发报路径第91—180日的90条成熟误差，使用RMS高斯边际区间，预测期间不更新。最终校准池[1062,1152)，保留16日间隔。全部路径与校准锁定后才读取完整标签评分。不能把相邻误差、四点、三种子或重叠窗口视为独立科学重复，也不保证293日同时覆盖。

## 完成情况及研究取舍

训练前472项、1394125数值预检通过；正式24新拟合无失败或重试，完成9600次更新。独立核验1272来源、240份新旧检查点、48565项/188863268数值，最大差2.73e−12；四图16面板/247192图形与数据值、实际SVG、字体/对齐/碰撞及目视通过。图件v2只将分量图“实线为集成分量”更正为“曲线为集成分量”，因为该图也有虚线集成曲线；v1及其源代码/核验保留，预测、评分及图形坐标均不变。11项统计解释检查及图文数值/链接核验另存回执。

独立窗口15:51:35—16:51:35 UTC含准备和核验，实际完成及用时见回执；旧预算和余额不转用。原窗口已反复暴露且重叠、数据预处理/as-of、物理优化未收敛、训练与最终教师差异、612缺乏181—293日监督等限制保持，本轮仍全部是探索性证据。

这次学到的是：限制附加H分量可以缓解一种失败，但没有保住旧KIN的表现，分开编码也没有自动建立可迁移的水文收益。保留原KIN/PHYS作为后续研究对照，不采用本轮新融合为替代模型；也不据此否定整个TiDE家族。若另开实验，优先区分“联合训练改变主支”与“H缺少可迁移的额外信息”，需要先写独立设计；本轮未启动冻结主支、cap搜索、更多轮数或RL。研究实施与核验完成，性能目标未达，用户/导师尚未验收。

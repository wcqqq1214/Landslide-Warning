# 藕塘 v2.4 结果：联合概率 ConvLSTM 未达标，停止本候选

日期：2026-09-13（北京时间；执行记录使用 2026-09-12 UTC）。

**结论：本次固定配置的联合训练没有同时改善 B+ 的预测均值和概率质量，停止 JOINT，保留 B+。**
第一窗四点平均预测 RMSE 几乎不变但略差；第二窗明显变差，且两窗完整拟合误差也变差。
这不是全部 ConvLSTM 或残差学习无效的结论，也不能据此证明“物理模型建得太准”。

实现、模型重载与保存数组复算已通过；效果判据失败；没有新的效果验收记录。

## 冻结输入与实际执行

- 用户在计划交付后要求“根据这个计划，一步步进行”；沿用[冻结方案](ootang_convlstm_joint_plan.v2.4.md)
  和[执行配置](../config/ootang_convlstm_joint.v2_4.json)，固定数据、损失、系数、梯度平衡和停止标准。
- 唯一候选 JOINT 与必要对照 DETACHED 共 12 组均值/尺度模型。两臂同一初值、网络、样本、权重和优化器，
  唯一开关为概率路径中的均值是否 detach；同时切断或保留均值经尺度特征的间接梯度。
- 保留 B+ 保存教师 252/B、342/A、432/B、612/B，以及原 v1.25 特征 scaler、v2.0 查询。
  神经均值为 B+ 加直接多步 ConvLSTM 修正，尺度为随查询变化的高斯标准差；不重新求解或标定 B+。
- 均值使用原两块归一化 MSE 及梯度平衡，概率使用 OOF 块归一化高斯 NLL，两项系数均为 1。
  OOF 仅指物理教师未用目标期观测标定；它仍是本次神经模型的训练样本，不是神经模型的独立校准集。
- 每前缀三个种子 0/1/2、每臂固定 e100；三种子等权高斯混合。P0 原件只有一个固定分布，
  不补造三种子；其均值为 B+，概率分数属于 P0，不能回填给不带概率输出的 M0。

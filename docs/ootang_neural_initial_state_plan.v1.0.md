## B. 唯一结构与初态约束

继续使用 24 维状态 `S=[z(4),p(4),rb(4),rc(4),rE(4),b(4)]`。每起点的 B+ 状态来自 v4.0 已核验的完整历史缓存，不重新标定、不清零。训练和预测使用同一逐日 64 子步 C 映射：

```text
a_j = min(U_z,j, max(z_B,j, 0))
delta_z = a * tanh(MLP(history))
S0* = S0_B + [delta_z, 0, 0, 0, 0, 0]
Sh = Day_Bplus(Sh-1, frozen_background_h, force_h, elastic_h), h=1,...,7
mu_h = y[n-1] + obs @ ((z_h+b_h)-(z0*+b0))
```

`U_z` 完全沿用 v4.0 算法：当前训练查询中 B+ 七日状态变化 RMS，数值下限 `1e-6`。一个原尺度的对称界限保留；只在非负边界收窄为 `min(U_z,z_B)`，不扩张正向范围。`max(z_B,0)` 仅定义修正半径，绝不覆盖原状态；原状态明显为负仍判失败。零网络输出严格回到锚定 B+。当前观测锚定与 v4.0 相同，不能追加求解器之后的可学习位移修正。

初态可行性定义为：全部有限，z 和 p 不小于 `-1e-8 mm`；`|delta_z|<=U_z+1e-12 mm`；z 非负边界成立；p、三类反力、背景与原历史**精确相同**；原系数有限、松弛系数位于 (0,1)、互补矩阵对称正定；之后每一子步的解满足原互补条件及本轮不可逆门槛。反力允许有符号，不施加来源没有规定的统一非负约束。

这是起点处对潜在动态状态的条件估计，**不宣称改写后的 z 与原确定性过去轨迹完全一致，也不宣称可辨识**。松弛反力与 z 没有必须即时重算的代数等式；以独立初值继续动态方程，不模拟一次物理冲击，不补算虚构施力历史。若这套局部可行性在 B 无法成立，本轮停止，不扩大状态集合。

网络只保留旧候选历史编码器：25×4 历史通道的末日、近 7 日均值和近 30 日均值，300 维摘要→32 tanh→32 tanh→4；最后一层零初始化。删除未来状态解码器；未来场景只进物理求解器，不进修正头。CPU float64、单线程。梯度沿七次完整 Day 反向，保留每个子步活动集；不要求对冻结外力求导。

区别：旧 v4.0 PINN 独立输出未来 20 维状态并用软损失逼近日映射；本候选只输出起点 4 维状态，未来状态来自硬递推。历史 M2 每天根据内部状态学习蠕变倍率并改变背景演化；本候选不改变背景、外力和参数。这是同类物理与神经耦合思想下的针对性假设检验。

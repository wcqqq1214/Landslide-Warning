## 2. 位移修正与误差需求

令 D=y−B+ 为事后实测修正需求，C=S−B+ 为实际修正。D 只在诊断中可见，不作为
预测时输入。逐点、逐种子及等权均值、逐段保存以下统计，共 96 行：

- D/C 的有符号均值与 RMS、原 B+/S 的 RMSE/MAE、修正最大绝对值；
- 活跃天数：|D| 和 |C| 均大于 1e-6 mm；其中 D*C<0 的反向比例，以及同向但
  |C|>2|D|+1e-6 的过度修正比例。零需求/零修正不算“方向正确”，分母为零记 NA；
- C² 均值与 −2DC 均值，及两者之和 ΔMSE。独立核对恒等式
  MSE(S−y)−MSE(B+−y)=mean(C²)−2mean(DC)，单位 mm²，不把相关当作因果；
- 直接背景响应 Cb=(bS−bB)Oᵀ 与其余日末 s 响应 Cs=(sS−sB)Oᵀ 的均值/RMS，
  核对 C=Cb+Cs。两个响应可能抵消，RMS 不可相加，不报告“贡献百分比”。

此分解来自原 C 源码第 57 行 u=s+background 与保存的观测矩阵。已实际查阅 ZIP

SHA 为 `1abe8a83e1566d18b0f89404f018c8ec30d0e9eb8a3ce9add05ca8a65698ff95`。
不把直接背景响应范围当作包含塑性和记忆作用的完整模型可达范围。

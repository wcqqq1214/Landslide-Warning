## 固定两个新版本

保留旧TiDE_KIN和TiDE_PHYS的原检查点/预测作主要对照；B+、起点B+、DRIFT1、RR_COND、G_CACHED及旧DATA/HYD也完整保留。新增两组均从头联合训练，无旧KIN预训练再追加的预算优势：

- `TiDE_SPLIT`：主支为原TiDE_KIN相同结构，历史位移与共同驱动/K输入；新增H支只读取H三列、相对距离和known标记及自己的点ID。两支独立编码，在位移增量层相加，不限制H输出幅度。
- `TiDE_BOUND`：与SPLIT相同结构、初始化、样本、优化器和参数量，只对H的起点化输出作固定tanh幅度限制。

主支110392参数，保留原180日历史、12维协变量框架与所有网络宽度；内部将H列7/8/9置零。H支的残差稠密层为特征5→8→1、完整474时刻展平后加4维点ID的编码478→8→8、路径解码8→8→294，独立点嵌入4×4；新增13179参数，两新版均123571参数（相对原版约增12%）。H支输出的两条末端仿射映射零初始化。主支按原seed初始化，H支用独立seed+10000序列，不改变主支初值；SPLIT/BOUND初值完全相同。无概率头、新空间图或可学习门控系数。

记主支起点化输出qK(h)，H支原输出rH(h)，qH(h)=rH(h)−rH(0)，单位均为原训练前缀位移标准差u。SPLIT输出`y[m−1]+u*(qK(h)+qH(h))`。BOUND输出`y[m−1]+u*(qK(h)+a*tanh(qH(h)/a))`，a=cap_mm/u。两者h0严格回到当前观测，e0为持久预测。

每点cap_mm在当前训练前缀内固定为所有已观测30日位移变化的RMS，即`max(1 mm, sqrt(mean((y[t]−y[t−30])²)))`，t=30…n−1。30日尺度与1mm下限先固定，不扫描幅度，不参考预测窗标签。它只是训练数据决定的工程幅度尺度，不是物理安全界。BOUND的H贡献绝对值逐点≤cap_mm；总预测不受此界约束，也不保证单调或满足B+。SPLIT和BOUND共享相同尺度记录。零H输出回退本模型当前主支，联合训练后主支可能与独立旧KIN不同，不能声称精确回退旧KIN。

主要配对BOUND−SPLIT隔离固定幅度变换的作用；新模型对旧PHYS同时改变编码方式与约12%的容量，对旧KIN新增H及容量，均不作为纯容量匹配消融。不按最终点成绩拼接赢家，也不追加容量消融。

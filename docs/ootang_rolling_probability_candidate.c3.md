# 滚动候选 C3：学习近期速度变化的概率正则回归

## Material Passport

## 为什么尝试

C2 显著优于锚定 B+，但其均值几乎等于固定初始组合；DRIFT1 的开发平均 RMSE 1.2779 mm 又优于 DRIFT14 的 1.6744 mm。这里的正证据是近期速度可预测；尚未验证的假设是：**用近期速度变化估计未来加速度，可比保持当天速度再前进一步**。不把“滚动任务好预测”当成神经学习效果。

采用带 L2 正则的监督回归作为复杂度对照，属于机器学习，不称深度学习或 PINN。[Ridge 原理说明](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)支持正则最小二乘的定义，不提供当前案例的收益证据。

## 均值与物理输入

令 `D_w = y[n-1] + h*(y[n-1]-y[n-1-w])/w`。预测均值为 `D_1 + X beta`，无截距。每个点、每个步长分别拟合，所有超参数通过一个共同的内部选择规则确定。

FULL 主候选的六个输入均为 mm：

1. `D_1 - D_3`；
2. `D_1 - D_7`；
3. `D_7 - D_14`；
4. `D_14 - D_30`；
5. `B[n+h-1]-B[n-1] - h*(B[n-1]-B[n-2])`；
6. `B_TREND14 - D_14`。

前四项表达近期速度变化；后两项为 B+ 相对自身近期速度的未来变化，沿用共同已知的未来驱动。单独拟合 DATA 对照，仅使用前四项；不把 FULL 失败后最好的点拼到 DATA，也不自动把 DATA 改称主候选。

输入按当前训练样本 RMS 缩放，不中心化、不加截距，使零变化对应零修正；目标是 `y_target-D_1`，按当前训练样本 RMS 缩放。每点/步长最小化 `mean((X_std beta-r_std)^2) + alpha*||beta||²`。固定 alpha 为 0.001/0.01/0.1/1/10，内部 612/792 段按原 RMSE 比值 + CRPS 比值选择；并列取较大的 alpha。FULL/DATA 各自独立选一次，之后用前 792 日重拟合。

这与 C2 是完整模型方案比较，除了均值函数也改变了概率参数化，不是严格单因素因果实验。

## 概率尺度

以 `q = sqrt(mean(X_first4²))` 表示起点已有的速度变化强度；`s[h,point]` 为上述训练目标 RMS。原始高斯标准差固定形式为：

`sigma_raw² = (a_point*s[h,point])² + (b_point*q)² + 0.01²`。

每点的正参数 a/b 通过当前训练残差的 Gaussian NLL 拟合，四点独立、各步长规范化后等权。log(a)/log(b) 初值 log(0.1)/log(1)，边界 [-10,5]，L-BFGS-B 最大 100 次迭代、200 次函数调用、ftol=1e-10、gtol=1e-6；显式梯度。保存未收敛状态，不自动增加迭代或重启。尺度使用训练残差估计，有拟合误差偏乐观的限制；不将它称为独立预测校准。真正在线的误差校准仍只读已成熟的保存预测。

C1/C2 的 90 个成熟误差、10 个固定伪样本先验规则原样保留，不在本候选同时调整滑动校准。0.01 mm 仍只是数值下限，不是仪器精度。FULL/DATA 和全部简单对照保持同一评价起点与成熟误差规则。
